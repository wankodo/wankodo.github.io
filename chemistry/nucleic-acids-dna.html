核酸とDNA

化学の考え方辞典 ― 高分子（高校化学・3年）

化学ツール集トップ ＞ 高分子 ＞ 核酸とDNA

高校化学・3年 高分子

どんな時に使えるか 核酸は、リン酸・糖・塩基からなるヌクレオチドが長くつながった高分子で、DNAとRNAがある。DNAは2本の鎖が塩基どうしの水素結合で結ばれた二重らせん構造をもち、AとT、GとCが相補的に組み合わさることで、塩基の並び方そのものが遺伝情報になる。DNAとRNAは糖（デオキシリボースとリボース）と塩基（チミンとウラシル）が違い、エネルギーの受け渡しに使われるATPもヌクレオチドの仲間である。

どんな問題に使うか

タンパク質とならぶ生体高分子である核酸の構造を、構成単位から積み上げて理解するための項目です。次のような場面で使います。

  • ヌクレオチドの構成（リン酸・糖・塩基）を見て、DNAのものかRNAのものかを判断する問題
  • 一方の鎖の塩基配列から、相補的なもう一方の鎖の配列を書く問題
  • 塩基の割合（A＝T、G＝C）や、水素結合の本数を数える問題
  • 二重らせん構造が、遺伝情報の保存と複製にどう結びつくかを説明する問題

核酸は「単位の名前」「DNAとRNAの違い」「塩基の相補性」の3点を押さえれば全体像がつかめます。この項目ではその3点を、構造式と模式図で確認しながら整理します。

公式・考え方

構成単位ヌクレオチド ― リン酸・糖・塩基の3点セット

核酸は、ヌクレオチドという単位が長く鎖状につながった高分子（ポリヌクレオチド）です。ヌクレオチド1個は、リン酸・五炭糖・塩基の3つの部分からできています。糖と塩基が結びついた部分をヌクレオシドといい、そこにリン酸が付いたものがヌクレオチドです。鎖の中では、あるヌクレオチドの糖と次のヌクレオチドのリン酸が結びついて（ホスホジエステル結合）、「糖―リン酸―糖―リン酸…」という背骨（主鎖）ができ、塩基がその横に並びます。

ヌクレオチドの模式図。左からリン酸、五炭糖、塩基の3部分が結びついた単位で、この単位がリン酸と糖の結合で長くつながって核酸の鎖になります。

塩基は4種類 ― プリン塩基とピリミジン塩基

核酸の塩基は、窒素を含む環状の有機化合物（含窒素塩基）です。環が2つつながったプリン塩基としてアデニン（A）とグアニン（G）、環が1つのピリミジン塩基としてチミン（T）・シトシン（C）・ウラシル（U）があります。DNAが使うのは A・T・G・C の4種、RNAでは T の代わりに U を使います。

核酸の塩基5種の構造式。チミンとウラシルの違いは、環に付いた CH3（メチル基）があるかないかだけです。塩基は糖の炭素に、プリン塩基では9位の窒素、ピリミジン塩基では1位の窒素で結びつきます。

DNAとRNAの違い

核酸にはDNA（デオキシリボ核酸）とRNA（リボ核酸）の2種類があり、違いは糖と塩基と鎖の本数の3点です。

  • 糖：DNAの糖はデオキシリボース、RNAの糖はリボース。違いは糖の2位の炭素に付く基で、リボースにはヒドロキシ基 −OH が、デオキシリボースには水素 H が付いています（「デオキシ」は酸素が1つ欠けた、という意味です）
  • 塩基：DNAは A・T・G・C、RNAは A・U・G・C（チミンの代わりにウラシル）
  • 鎖の本数：DNAは通常2本の鎖が組み合わさった二本鎖、RNAは基本的に1本鎖

リボースとデオキシリボースの模式図。糖の2位の炭素に付くのが −OH か −H かという、原子1個分の違いが DNA と RNA を分けます。デオキシリボースの方が化学的に安定で、長期保存に向くことも、DNAが遺伝情報の保存役を担う理由の1つとされています。

塩基の相補性と二重らせん

DNAの2本の鎖は、内側に向いた塩基どうしが水素結合で結ばれて組み合わさっています。このとき組み合わせは決まっていて、AはTと、GはCとだけが対を作ります。これを塩基の相補性といいます。A−T対の水素結合は2本、G−C対は3本です。プリン塩基（環2つ）とピリミジン塩基（環1つ）が常に対になるため、2本の鎖の間隔はどこでもほぼ一定になり、全体が規則正しくねじれた二重らせん構造になります。

塩基対：A ＝ T（水素結合2本）、G ≡ C（水素結合3本）　／　二本鎖DNA全体では A の数 ＝ T の数、G の数 ＝ C の数

Aの数とTの数、Gの数とCの数が等しくなるという関係は、エルヴィン・シャルガフが多くの生物のDNAを分析して見いだした経験則（シャルガフの規則）で、二重らせんモデルの重要な手がかりになりました。相補性があるため、一方の鎖の塩基配列が決まれば、もう一方の配列は自動的に決まります。これが、細胞分裂のときにDNAが正確に複製され、遺伝情報が受け継がれる仕組みの土台です。

二重らせんの模式図。糖とリン酸からなる2本の主鎖がらせん状にねじれ、内側で塩基が相補的に対を作ります。実際のDNAでは、らせんが1回転する間に約10塩基対が入ります。

遺伝情報とタンパク質合成の入口

DNAの塩基の並び方（塩基配列）そのものが遺伝情報です。タンパク質を作るときは、まずDNAの一部分の情報がRNAの一種（伝令RNA、mRNA）に写し取られ（転写）、その配列をもとにアミノ酸が順番につながれてタンパク質が合成されます（翻訳）。塩基3個の並びが1つのアミノ酸を指定する対応表（遺伝暗号）を使うのが要点で、詳しい代謝の流れは「生体内の化学（代謝の入口）」で扱います。ここでは「核酸の塩基配列 → RNA → アミノ酸の配列 → タンパク質」という情報の流れの入口だけを押さえてください。

ATPもヌクレオチドの仲間

生体内のエネルギーの受け渡しに使われるATP（アデノシン三リン酸）は、アデニンとリボースからなるヌクレオシド（アデノシン）に、リン酸が3個つながった物質で、ヌクレオチドの仲間です。末端のリン酸どうしの結合（高エネルギーリン酸結合）が切れてADP（アデノシン二リン酸）になるときにエネルギーが放出され、筋肉の収縮や物質の合成など、体内のさまざまな仕事に使われます。核酸の材料とエネルギーの通貨が、同じヌクレオチドという部品でできている点は、生体化学の面白い統一性の1つです。

ATPの模式図。アデニン＋リボース＋リン酸3個という構成は、RNAの材料であるヌクレオチドと基本的に同じ部品の組み合わせです。

解き方の手順

  1. 単位を確認する。リン酸・糖・塩基の3点セットがヌクレオチドです。リン酸がなければヌクレオシドとして区別します。
  2. 糖と塩基で DNA か RNA かを判断する。糖がデオキシリボースで塩基にチミンがあればDNA、糖がリボースで塩基にウラシルがあればRNAです。
  3. 相補性で対を作る。A↔T（RNAが相手ならA↔U）、G↔C の対応で、相補鎖の配列や相手側の塩基の数を求めます。
  4. 割合と水素結合を数える。二本鎖DNAでは A＝T、G＝C の関係から割合をそろえ、水素結合は A−T対×2本＋G−C対×3本で合計します。

例題

問題1：ある二本鎖DNAの一方の鎖の塩基配列が A T G C C G T A の順に並んでいた。相補的なもう一方の鎖の塩基配列と、この区間の水素結合の総数を答えよ。

答えと解説を見る

相補性にしたがって A→T、T→A、G→C、C→G と置き換えると、相手の鎖は T A C G G C A T となります。水素結合は、A−T対が4組（A・T・T・A の位置）で 4×2＝8本、G−C対が4組（G・C・C・G の位置）で 4×3＝12本、合計 20本 です。

答え：相補鎖は T A C G G C A T、水素結合は合計20本。

問題2：ある生物の二本鎖DNA全体を分析すると、アデニンが全体の28 %を占めていた。チミン、グアニン、シトシンの割合をそれぞれ答えよ。

答えと解説を見る

二本鎖DNAでは相補性のため A の数＝T の数、G の数＝C の数になります（シャルガフの規則）。よってチミンは 28 %。残りは 100−28×2＝44 %で、これを G と C が半分ずつ分け合うので、グアニン 22 %、シトシン 22 % です。検算：28＋28＋22＋22＝100 %で、全体と一致します。

答え：チミン28 %、グアニン22 %、シトシン22 %。

問題3：100塩基対からなる二本鎖DNAがあり、そのうち30塩基対が G−C 対、残りが A−T 対であった。このDNAの塩基対を結ぶ水素結合の総数を答えよ。また、このDNAを構成するヌクレオチドの総数も答えよ。

答えと解説を見る

A−T対は 100−30＝70 対で、水素結合は 70×2＝140本。G−C対は30対で 30×3＝90本。合計は 140＋90＝230本です。ヌクレオチドは1塩基対につき2個（2本の鎖に1個ずつ）あるので、総数は 100×2＝200個 です。

答え：水素結合は230本、ヌクレオチドは200個。

問題4：あるヌクレオチドを調べると、糖はリボースで、塩基はウラシルであった。このヌクレオチドはDNAとRNAのどちらの材料か答えよ。また、理由を糖と塩基の両面から述べよ。

答えと解説を見る

糖がリボースである点と、塩基にウラシルを含む点のどちらから見ても、DNAではなく RNA の材料です。DNAの糖はデオキシリボースで、塩基は A・T・G・C の4種に限られ、ウラシルは含まれません。

答え：RNAの材料。糖がリボースで、チミンの代わりにウラシルを含むため。

現場での使われ方

PCR検査 ― 相補性を利用したDNAの増幅

感染症の検査などで使われるPCR法は、調べたいDNAの特定の区間だけを、相補性を利用して大量に複製する技術です。温度を上げて2本の鎖をほどき、目印となる短いDNA（プライマー）を相補的に結びつけて新しい鎖を合成する、というサイクルを繰り返すことで、ごく微量のDNAからでも検出できる量まで増やせます。新型コロナウイルス感染症の検査で広く知られるようになった、核酸の性質そのものを使った実在の技術です。

DNA鑑定と個人識別

塩基配列や、短い配列の繰り返し回数には個人差があり、その違いを読み取ることで個人を識別できます。犯罪捜査でのDNA型鑑定や、親子関係の確認などに実際に使われています。DNAが「塩基の並び方＝情報」という性質をもつからこそできる応用です。

DNAデータバンクと遺伝子検査

ヒトゲノム（全遺伝情報）の解読以降、塩基配列を高速に読む技術（シーケンサー）が発達し、病気に関連する遺伝子の検査や、医薬品の効き方の個人差を調べる研究が進んでいます。医療機関での遺伝子検査は、DNAの配列という化学情報を読み取る作業そのものです。

考え出した人

ジェームズ・ワトソン（1928〜2025、アメリカの分子生物学者）、フランシス・クリック（1916〜2004、イギリスの物理学者・分子生物学者）、ロザリンド・フランクリン（1920〜1958、イギリスの化学者）

1953年、アメリカの分子生物学者ジェームズ・ワトソンとイギリスのフランシス・クリックは、DNAが二重らせん構造をもつというモデルを発表しました。このモデルは、AとT、GとCが対を作る相補性を備え、遺伝情報の複製の仕組みまで一気に説明できるものでした。モデルの構築には、イギリスの化学者ロザリンド・フランクリンらが撮影したDNAのX線回折写真（らせん構造を示す決定的なデータ）や、シャルガフの規則（A＝T、G＝C）が重要な手がかりになっています。ワトソンとクリックは、この業績で1962年にノーベル生理学・医学賞を受賞しました（フランクリンは1958年に亡くなっていたため受賞対象になりませんでした）。なお、核酸そのものは1869年にスイスのフリードリヒ・ミーシェルが細胞の核から発見しており、「核酸」という名前はこの出発点に由来します。
