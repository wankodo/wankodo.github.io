等式・不等式の証明と相加相乗平均

数学解法辞典 ― 数と式（高校）

数学ツール集トップ ＞ 数と式 ＞ 等式・不等式の証明と相加相乗平均

高校 数と式 計算機あり

どんな時に使えるか容積が決まった容器の材料費を最小にする形や、和が固定のとき積を最大にする条件は、相加相乗平均で言い当てられる。缶や箱の設計、経済学の効用最大化、情報理論の評価まで、『制約のもとで最大・最小を探す』最適化の入口になっている考え方である。

どんな問題に使うか

2つの正の量について、「和が決まれば積の上限が決まる」「積が決まれば和の下限が決まる」という関係を使って最大・最小を言い当てる問題と、差を取って平方の形に持ち込む等式・不等式の証明に使います。微分を使わずに最大・最小が求まるのが強みです。

  • 2つの正の量について「和が固定 → 積の最大」「積が固定 → 和の最小」を求める問題
  • x + c/x 型（x > 0、c > 0）の最小値を求める問題
  • 差を取って平方の和に持ち込む等式・不等式の証明問題（両辺の差を作り、因数分解や平方完成で符号を判定する問題）
  • 等号が成り立つ条件（2つの量が等しいとき）まであわせて答える問題

相加相乗平均は「2つの量が等しいときに積が最大（または和が最小）になる」という最適化の直感を、そのまま不等式にしたものです。等号条件を必ず確認するのが、この解法の作法です。

公式・考え方

(a + b) / 2 ≧ √(ab)　（a, b > 0、等号は a ＝ b のとき）

相加相乗平均：左辺 (a + b) / 2 を相加平均（普通の平均）、右辺 √(ab) を相乗平均（幾何平均）といいます。「相加平均は相乗平均以上」というこの不等式から、a + b が固定なら ab は ((a + b) / 2)2 以下、ab が固定なら a + b は 2√(ab) 以上、という最大・最小が読み取れます。

相加相乗平均の証明：差を取って変形するのが基本の型です。(a + b) / 2 − √(ab) ＝ (a − 2√(ab) + b) / 2 ＝ (√a − √b)2 / 2 ≧ 0。平方は 0 以上なので差は 0 以上となり、不等式が示せます。等号は √a ＝ √b、すなわち a ＝ b のときです。

証明の一般の型：等式の証明は「片辺を変形してもう片辺にする」か「両辺の差を取って 0 になることを示す」、不等式の証明は「差を作る → 因数分解・平方完成する → 各因数や平方の符号を判定する」という流れが基本です。平方の和の形（○2 + △2 ≧ 0）に持ち込めれば、符号の判定が一目で済みます。

解き方の手順

  1. 対象の2つの量が正であることを確認する。相加相乗平均は a, b > 0 のときだけ使える。x + c/x 型なら、2つの量は x と c/x で、どちらも正であることを押さえる。
  2. 固定されているのが「和」か「積」かを見分ける。和が固定なら積の最大、積が固定なら和の最小が相加相乗平均から読み取れる。
  3. 相加相乗平均 (a + b) / 2 ≧ √(ab) を適用する。固定された側の値を代入し、もう片側の最大値・最小値を不等式の形で書き下す。
  4. 等号条件 a ＝ b を解いて、等号が実際に成り立つことを確認する。等号が成り立つ値が存在しないと、その値は最大値・最小値とは言えないので、この確認は省略できない。
  5. 最大値・最小値と、それを取る値を答える。証明問題では、差を作って平方の和や因数分解の形に変形し、符号を判定して締める。

例題

問題：x > 0 のとき、x + 4/x の最小値を相加相乗平均で求めよ。

答えと解説を見る

x > 0 なので、2つの量 x と 4/x はどちらも正です。この2量の積は x ・ (4/x) ＝ 4 と一定なので、相加相乗平均が使えます。

  1. 相加相乗平均より、x + 4/x ≧ 2√(x ・ 4/x) ＝ 2√4 ＝ 4。
  2. 等号は x ＝ 4/x のとき。x2 ＝ 4 で、x > 0 なので x ＝ 2。このとき実際に x + 4/x ＝ 2 + 2 ＝ 4 となり、等号が成り立つ。

答え：最小値 4（x ＝ 2 のとき）（検算：x ＝ 1 なら 1 + 4 ＝ 5、x ＝ 4 なら 4 + 1 ＝ 5 で、どちらも 4 より大きい）。

現場での使われ方

容器の設計と材料費の最小化

容積が決まった容器について、材料費は表面積にほぼ比例します。「容積（3辺の積）が固定のとき、表面積（辺の積の和）を最小にする」という問題は、相加相乗平均の典型的な応用で、辺の長さがそろう形に近づくほど表面積は小さくなります。飲料缶の寸法が、容積に対して表面積が最小に近い形に設計されているのは、この最適化の考え方が背景にあります。

経済学の効用最大化・予算配分

予算の制約のもとで効用を最大化する問題では、コブ＝ダグラス型の効用関数（2つの財の量の積の形）の最大化に相加相乗平均が使われます。「支出の和が固定のとき、積の形の効用が最大になるのは支出を一定の割合に配分したとき」という結論が、不等式ひとつで導けます。限られた予算をどう配分するかという判断の土台です。

情報理論や誤差評価での不等式評価の土台

情報理論では、情報量や確率の積と和を評価する場面で相加相乗平均の考え方が土台になります。また誤差評価でも、「2つの誤差の和が一定のとき積が最大になるのは誤差が等しいとき」といった評価に同じ不等式が現れます。複雑な最適化や評価の入口として、相加相乗平均は今も広く使われています。

考え出した人

ユークリッド／コーシー（1789〜1857、フランスの数学者）

相加相乗平均の不等式は古代から知られ、ユークリッド『原論』にも幾何学的な形で現れます。半円に垂線を下ろして得られる長さが幾何平均（相乗平均）になるという図形的な表現で、当時から平均の大小関係は意識されていました。一般の n 個の場合まで含めて証明したのは、フランスの数学者コーシー（Augustin-Louis Cauchy、1789〜1857）で、著書『解析教程』（1821）の中で示しました。2つの場合の不等式自体は特定の誰かが「発明」したというより、古代から受け継がれてきた知恵をコーシーが一般化して証明した、というのが正確なところです。
