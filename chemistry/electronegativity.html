電気陰性度と結合の極性

化学の考え方辞典 ― 化学結合（高校化学基礎・1年）

化学ツール集トップ ＞ 化学結合 ＞ 電気陰性度と結合の極性

高校化学基礎・1年 化学結合

どんな時に使えるか 電気陰性度は、原子が共有電子対を引きつける強さを数値化したもので、フッ素が最大である。2つの原子の電気陰性度の差が大きいほど結合は極性をもち、差がおよそ1.7を超えるとイオン結合的になる。結合の極性と分子の形を合わせると、分子全体に極性があるかどうかも判断できる。

どんな問題に使うか

共有結合の中で電子の偏りがどれくらいあるかを、数値で比べるときの考え方です。次のような場面で使います。

  • 2つの原子の電気陰性度の差を計算し、その結合が無極性の共有結合か、極性のある共有結合か、イオン結合に近いかを判断する問題
  • 極性のある結合で、どちらの原子が δ−（少しマイナス）で、どちらが δ＋（少しプラス）になるかを答える問題
  • 水 H2O や二酸化炭素 CO2 のように、結合の極性と分子の形から、分子全体が極性分子か無極性分子かを判断する問題
  • 「似たものどうしはよく溶ける」という溶解の傾向を、分子の極性から説明する問題

ポイントは、電気陰性度そのものよりも2原子の差に注目することです。差が結合の性質を決め、さらに分子の形と組み合わさって分子全体の極性が決まります。

公式・考え方

電気陰性度は、共有結合で結ばれた原子が、共有電子対を自分の方へ引きつける強さを数値化したものです。アメリカの化学者ポーリングが結合エネルギーのデータから定めた物差し（ポーリングの電気陰性度）が最も広く使われ、基準の取り方により単位はなく、相対的な数値です。代表的な値は次の通りです。

  • F：4.0、O：3.5、Cl：3.0、N：3.0、Br：2.8、C：2.5、H：2.1、Na：0.9（ポーリングの値。教科書によって小数第1位までの丸め方が少し異なる）
  • フッ素 F が全元素で最大で、周期表では右上ほど大きく、左下ほど小さい傾向がある（同周期では右へ、同族では上へ大きくなる。イオン化エネルギーや電子親和力と同じ向きの傾向である）

結合の性質は、2原子の電気陰性度の差 Δ（大きい方から小さい方を引いた値）で読みます。

Δ ＝（大きい方の電気陰性度）−（小さい方の電気陰性度）
  • Δ ＝ 0（同じ原子どうし）：電子対は真ん中にあり、偏りのない無極性共有結合。例：H−H、Cl−Cl
  • Δ が小さい（およそ 0.5 未満）：偏りがごく小さい共有結合。例：C−H 結合は Δ ＝ 2.5 − 2.1 ＝ 0.4 で、ほぼ無極性として扱われることが多い
  • Δ が中くらい（およそ 0.5〜1.7）：電子対が電気陰性度の大きい原子側に偏った極性共有結合。大きい方の原子が δ−、小さい方の原子が δ＋ になる。例：H−Cl 結合は Δ ＝ 3.0 − 2.1 ＝ 0.9
  • Δ が大きい（およそ 1.7 超）：電子がほぼ相手に移りきった状態に近く、イオン結合的になる。例：NaCl は Δ ＝ 3.0 − 0.9 ＝ 2.1

ただし、1.7 という境目はきっぱりした境界ではなく目安です。共有結合とイオン結合の間は連続的につながっていて、Δ が大きくなるにつれてイオン性（イオン結合らしさ）の割合が増えていきます。たとえば H−F 結合は Δ ＝ 4.0 − 2.1 ＝ 1.9 と 1.7 を超えますが、気体の HF は電子を完全に移し合ったイオン結晶ではなく、極性の非常に大きい共有結合をもつ分子として扱われます。数値だけで機械的に決めず、「境目はグラデーション」と理解しておくことが大切です。

分子全体の極性は、結合の極性だけでは決まりません。各結合の極性（向きと大きさ）が分子の形の中で打ち消し合うかどうかで決まります。

  • 水 H2O：O−H 結合は Δ ＝ 3.5 − 2.1 ＝ 1.4 の極性共有結合で、分子は折れ線形（H−O−H の角度は約104.5°）であるため、2つの結合の極性は打ち消し合わず、酸素側が δ−、水素側が δ＋ の極性分子になる
  • 二酸化炭素 CO2：C＝O 結合は Δ ＝ 3.5 − 2.5 ＝ 1.0 の極性共有結合だが、分子は直線形（O＝C＝O）で、2つの結合の極性が正反対を向いて打ち消し合うため、分子全体では無極性分子になる
  • メタン CH4：C−H 結合の Δ は 0.4 と小さく、分子も正四面体形で対称性が高いため、無極性分子である

極性分子は極性分子どうし、無極性分子は無極性分子どうしで混ざりやすい（「似たものどうしはよく溶ける」）ため、水に油が溶けないことや、物質の溶けやすさ・沸点の高さの違いも、分子の極性から説明できます。

解き方の手順

  1. 2原子の電気陰性度の値をそろえる。問題文や周期表の表から、結合する2つの原子の値を読み取ります。
  2. 差 Δ を計算し、結合の性質を判断する。Δ ＝ 0 なら無極性共有結合、およそ 0.5〜1.7 なら極性共有結合、およそ 1.7 超ならイオン結合的、と目安を当てはめます。境目は連続的だという留保も忘れずに。
  3. δ− と δ＋ を決める。極性共有結合では、電気陰性度の大きい原子が δ−、小さい原子が δ＋ です。
  4. 分子全体の極性を問われたら、分子の形を確認する。極性のある結合があっても、直線形や正四面体形のように対称な形で打ち消し合えば無極性分子、折れ線形のように偏りが残れば極性分子です。

例題

問題1：電気陰性度を H＝2.1、Cl＝3.0、Na＝0.9 として、H−H 結合、H−Cl 結合、Na と Cl の結合について、それぞれ Δ を求め、結合の性質を答えよ。問題2：電気陰性度を C＝2.5、O＝3.5、H＝2.1 として、水 H2O（折れ線形）と二酸化炭素 CO2（直線形）は、それぞれ極性分子か無極性分子か答えよ。

答えと解説を見る
  1. 問題1：H−H 結合は Δ ＝ 2.1 − 2.1 ＝ 0 で、電子対に偏りのない無極性共有結合です。
  2. H−Cl 結合は Δ ＝ 3.0 − 2.1 ＝ 0.9 で、およそ 0.5〜1.7 の範囲にあるため極性共有結合です。電気陰性度の大きい Cl が δ−、H が δ＋ になります。
  3. Na と Cl は Δ ＝ 3.0 − 0.9 ＝ 2.1 で、およそ 1.7 を超えるためイオン結合的です。実際、塩化ナトリウム NaCl は Na+ と Cl− からなるイオン結晶です。
  4. 問題2：水では O−H 結合の Δ ＝ 3.5 − 2.1 ＝ 1.4 で極性があり、分子が折れ線形のため2つの結合の極性が打ち消し合わず残るので、極性分子です。
  5. 二酸化炭素では C＝O 結合の Δ ＝ 3.5 − 2.5 ＝ 1.0 で結合自体には極性がありますが、分子が直線形で、2つの結合の極性が正反対を向いて打ち消し合うので、分子全体では無極性分子です。

答え：問題1は H−H が無極性共有結合（Δ＝0）、H−Cl が極性共有結合（Δ＝0.9、Cl が δ−）、Na−Cl がイオン結合的（Δ＝2.1）。問題2は水が極性分子、二酸化炭素が無極性分子。「結合に極性がある」と「分子に極性がある」は別の話で、分子の形まで見て初めて分子全体の極性が決まる点が、この考え方の一番の要点です。

現場での使われ方

クロマトグラフィーによる混合物の分離・分析

物質を分離・分析するクロマトグラフィーでは、固定相（シリカゲルなど）と移動相（溶媒）の極性の組み合わせで、成分ごとに移動の速さが変わります。極性の大きい成分は極性の大きい固定相に強く引きつけられて遅く進む、という極性の釣り合いが分離の原理であり、試薬や溶媒の選択には電気陰性度から見積もる分子の極性が土台になっています。医薬品や食品の分析で日常的に使われる手法です。

フッ素樹脂（PTFE）の撥水性と耐薬品性

フライパンのコーティングなどに使われるフッ素樹脂 PTFE は、炭素の骨格をフッ素原子が取り囲んだ構造です。電気陰性度が最大のフッ素と炭素の C−F 結合は非常に強く、分子全体としては対称で極性が表面に現れにくいため、水も油も寄せつけず、薬品にも侵されにくい性質が生まれます。電気陰性度と分子の形の両方から説明できる、極性の応用例です。

溶媒の選択と「水に溶けるかどうか」の予測

化学実験や製造の現場では、溶かしたい物質に合わせて溶媒を選びます。水のような極性溶媒には極性分子やイオン性の物質が溶けやすく、ヘキサンのような無極性溶媒には無極性分子が溶けやすい、という「似たものどうしはよく溶ける」原則が目安になります。塗料や洗浄剤、抽出工程の溶媒選びでも、この極性の考え方が実務の出発点になっています。

考え出した人

ライナス・ポーリング（1901〜1994、アメリカの化学者）

電気陰性度の物差しを作ったのは、アメリカの化学者ライナス・ポーリング（1901〜1994）です。ポーリングは1932年、さまざまな分子の結合エネルギーのデータを比べ、共有結合で電子を引きつける強さを元素ごとに数値化した電気陰性度を提案しました。フッ素を最大（約4.0）とするこの物差しは、結合のイオン性と共有性の度合いを見積もる道具として広まりました。ポーリングは化学結合の研究で1954年にノーベル化学賞を受け、後には核実験に反対する平和活動でも知られ、1962年にはノーベル平和賞も受けています。なお、電気陰性度の定め方はポーリングの方法だけではなく、イオン化エネルギーと電子親和力の平均を取るマリケンの方法などもあり、目的に応じて使い分けられています。
