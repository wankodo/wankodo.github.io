炭化水素（アルカン・アルケン・アルキン）

化学の考え方辞典 ― 有機化学（高校化学・3年）

化学ツール集トップ ＞ 有機化学 ＞ 炭化水素（アルカン・アルケン・アルキン）

高校化学・3年 有機化学

どんな時に使えるか 炭化水素は炭素と水素だけからなる化合物で、炭素どうしの結合の種類によって性質が決まる。単結合だけのアルカンは一般式 CₙH₂ₙ₊₂ で置換反応や燃焼をし、二重結合をもつアルケンは CₙH₂ₙ で付加反応と付加重合をしやすく、三重結合をもつアルキンは CₙH₂ₙ₋₂ で付加反応をする。分子式を一般式と見比べることが、反応の種類と生成物を予測する入口になる。

どんな問題に使うか

炭素と水素だけからなる化合物＝炭化水素の分類と反応を扱うときの考え方です。有機化学の入口であり、次のような場面で使います。

  • 分子式（C5H12、C3H6 など）を一般式と照らして、アルカン・アルケン・アルキンのどれに当てはまるかを判定する問題
  • メタンと塩素の置換反応、エチレンへの水素や臭素の付加反応など、反応の種類を区別し、生成物の構造式を書く問題
  • プロペンに臭化水素を付加させたときの主生成物を、マルコフニコフ則で予測する問題
  • エチレンの付加重合でポリエチレンができる仕組みや、アセチレンを炭化カルシウムから作る反応式を書く問題

ポイントは、炭素どうしの結合が単結合だけか、二重結合を含むか、三重結合を含むかで3つのグループに分け、それぞれの一般式と代表的な反応を結びつけて覚えることです。

公式・考え方

アルカン：単結合だけの炭化水素

アルカンは炭素どうしがすべて単結合でつながった鎖状の炭化水素で、一般式は CnH2n+2 です（n は炭素原子の数）。水素がこれ以上増やせない「飽和」なつくりなので、反応性は低く、代表的な反応は次の2つです。

  • 燃焼：十分な酸素のもとでは完全に燃えて二酸化炭素と水になります。CH4 ＋ 2O2 → CO2 ＋ 2H2O
  • 置換反応：光を当てると、水素原子がハロゲン原子に1つずつ置き換わります。CH4 ＋ Cl2 → CH3Cl（クロロメタン）＋ HCl
アルカン：CnH2n+2（単結合のみ）　例：メタン CH4、エタン C2H6、プロパン C3H8

メタン・エタン・プロパンの構造式。炭素は常に4本の結合の手をもち、アルカンではそのすべてが単結合です。炭素が1つ増えるごとに CH2 が1つ増えるため、一般式が CnH2n+2 になります。

アルケン：二重結合を1つもつ炭化水素

アルケンは炭素どうしの二重結合を1つもつ鎖状の炭化水素で、一般式は CnH2n です。二重結合は単結合より反応しやすく、二重結合の片方が開いて、相手の分子が両側の炭素に分かれて付く付加反応が特徴です。

  • 水素の付加（ニッケル触媒）：C2H4 ＋ H2 → C2H6
  • 臭素の付加：C2H4 ＋ Br2 → C2H4Br2（臭素水の赤褐色が消えるため、二重結合の検出に使われます）
  • 水の付加（リン酸触媒・高温・高圧）：C2H4 ＋ H2O → C2H5OH（エタノール）
  • 塩化水素などの付加では、マルコフニコフ則（後述）が生成物を決めます

また、エチレンの二重結合が次々に開いて多数の分子がつながる付加重合では、ポリエチレンができます（n CH2＝CH2 → −(CH2−CH2)n−）。重合そのものは高分子の項目で詳しく扱いますが、その入口はここです。

アルケン：CnH2n（二重結合1つ）　例：エチレン（エテン）C2H4、プロペン C3H6

アルキン：三重結合を1つもつ炭化水素

アルキンは炭素どうしの三重結合を1つもつ鎖状の炭化水素で、一般式は CnH2n−2 です。代表はアセチレン（エチン）C2H2で、三重結合に段階的に付加反応をします（C2H2 ＋ H2 → C2H4、さらに ＋ H2 → C2H6）。臭素とも付加し、C2H2 ＋ 2Br2 → C2H2Br4 のように臭素水を脱色します。アセチレンは酸素と燃やすと高温の炎が得られ、金属の溶接・切断に使われてきました。

アルキン：CnH2n−2（三重結合1つ）　例：アセチレン（エチン）C2H2

エチレンとプロペンは二重結合、アセチレンは三重結合をもちます。多重結合の数が増えるほど、同じ炭素数でも水素の数が減ります（一般式の H の係数 2n＋2／2n／2n−2 の違いはここから来ます）。

マルコフニコフ則（入口）

プロペン CH2＝CH−CH3 のように左右非対称なアルケンに HBr のような H−X 型の分子が付加すると、生成物が2通り考えられます。このとき主生成物は、H が「すでに H の多い方の炭素」に付くという経験則（マルコフニコフ則）で決まります。プロペン ＋ HBr では H が端の CH2 に付き、Br が中央の炭素に付いた 2-ブロモプロパン が主生成物になります（C3H6 ＋ HBr → C3H7Br）。理由づけ（中間体の安定性）は大学で学びますが、高校では「H は H の多い方へ」で予測できれば十分です。

アセチレンの製法（教科書レベル）

実験室では、炭化カルシウム（カーバイド）CaC2 に水を加えるとアセチレンが発生します。

CaC2 ＋ 2H2O → C2H2 ＋ Ca(OH)2

アセチレンは空気と混合すると爆発しやすい可燃性の気体です。発生した気体への引火や、密閉容器での発生には十分な注意が必要です。

※ ここで紹介する実験・製法を実際に行うときは、学校の授業や専門家の指導のもとで、安全に十分注意し、自己責任で行ってください。

シクロアルカンと芳香族との区別（入口）

炭素が輪（環）になった炭化水素もあります。単結合だけで環を作るシクロアルカンは、環の分だけ水素が2個減り、一般式はアルケンと同じ CnH2n になります。つまり C3H6 はプロペン（アルケン）ともシクロプロパン（シクロアルカン）とも読めるため、分子式だけでは区別できず、構造式や反応性（臭素水を脱色するかどうか）で判断します。一方、ベンゼン C6H6 に代表される芳香族化合物は、六角形の環の中に二重結合と単結合が交互に並ぶ特別な環構造をもち、付加反応より置換反応をしやすいという別格の性質を示します。芳香族は独立した項目で扱うので、ここでは「環＋多重結合の特別な仲間がいる」ことだけ押さえてください。

環構造の例。シクロプロパンとプロペンは分子式が同じ C3H6 でも構造と反応性が違います。ベンゼンの詳しい性質は芳香族化合物の項目で扱います。

解き方の手順

  1. 炭素の数 n を数え、H の数を一般式と比べる。H が 2n＋2 ならアルカン、2n ならアルケン（またはシクロアルカン）、2n−2 ならアルキンが候補です。
  2. 構造式で多重結合の有無を確認する。分子式が CnH2n のときは、二重結合があるか環があるかでアルケンとシクロアルカンを区別します。
  3. 反応の種類を決める。アルカン＋ハロゲン＋光 → 置換反応、アルケン・アルキン＋小分子 → 付加反応、アルケンどうしの連結 → 付加重合、炭化水素＋酸素 → 燃焼、という対応で見分けます。
  4. 付加反応では、二重・三重結合を開いて相手を両側に分けて付ける。非対称なアルケンに H−X が付くときは、マルコフニコフ則（H は H の多い方の炭素へ）で主生成物を決めます。
  5. 反応式の両辺で原子の数を数え直す。C・H・O・ハロゲンの数が左右で一致しているかを必ず検算します。

例題

問題1（分類）：次の分子式の炭化水素は、アルカン・アルケン・アルキンのどれに当てはまるか。一般式と照らして答えよ。（a）C5H12（b）C3H6（c）C4H6

問題2（反応の種類と生成物）：次の反応の種類（置換・付加・燃焼・付加重合）を答え、生成物を書け。（a）メタンと塩素の混合物に光を当てる（b）エチレンに臭素を加える（c）エチレンに水を付加させる（d）メタンを十分な酸素で燃やす

問題3（マルコフニコフ則）：プロペンに臭化水素 HBr を付加させたときの主生成物の名前と構造を答えよ。

問題4（アセチレン）：炭化カルシウムからアセチレンを作る反応式を書け。また、アセチレンに水素を十分に付加させたときの最終生成物を答えよ。

答えと解説を見る
  1. 問題1：（a）n＝5 のとき 2n＋2＝12 となり H の数が一致するのでアルカン（ペンタン）。（b）n＝3 のとき 2n＝6 となりアルケンまたはシクロアルカン（プロペン、またはシクロプロパン。分子式だけでは決まらず、構造式か反応性で区別します）。（c）n＝4 のとき 2n−2＝6 となりアルキン（1-ブチンなど）。
  2. 問題2：（a）置換反応。CH4 ＋ Cl2 → CH3Cl（クロロメタン）＋ HCl。H が Cl に1つ置き換わります。（b）付加反応。C2H4 ＋ Br2 → C2H4Br2（1,2-ジブロモエタン）。二重結合が開いて Br が両側の炭素に付きます。（c）付加反応。C2H4 ＋ H2O → C2H5OH（エタノール）。（d）燃焼。CH4 ＋ 2O2 → CO2 ＋ 2H2O。どの式も両辺の原子数を数えると C・H・O・Cl・Br の数が一致します（検算済み）。
  3. 問題3：マルコフニコフ則により、H は H の多い方の炭素（端の CH2）に付き、Br は中央の炭素に付きます。よって主生成物は 2-ブロモプロパン CH3−CHBr−CH3 です。反応式は C3H6 ＋ HBr → C3H7Br で、両辺とも C3H7Br となり一致します。
  4. 問題4：製法は CaC2 ＋ 2H2O → C2H2 ＋ Ca(OH)2（両辺とも Ca・C2・H4・O2 で一致）。アセチレンへの水素の付加は2段階で進み、C2H2 ＋ H2 → C2H4（エチレン）、C2H4 ＋ H2 → C2H6 となるため、十分な水素のもとでの最終生成物はエタン C2H6 です。

答え：問題1は（a）アルカン、（b）アルケンまたはシクロアルカン、（c）アルキン。問題2は（a）置換・クロロメタン、（b）付加・1,2-ジブロモエタン、（c）付加・エタノール、（d）燃焼・CO2 と H2O。問題3は 2-ブロモプロパン。問題4は CaC2 ＋ 2H2O → C2H2 ＋ Ca(OH)2、最終生成物はエタン。

例題に登場する化合物の構造式。ペンタンは問題1（a）、1-ブチンは問題1（c）の候補、クロロメタン・1,2-ジブロモエタン・エタノールは問題2の生成物、2-ブロモプロパンは問題3の主生成物です。問題4のアセチレンとエタンは前掲の図にあります。

現場での使われ方

燃料としてのアルカン

天然ガスの主成分はメタンで、都市ガスや発電用燃料として使われます。プロパンとブタンを主成分とする LPガス（液化石油ガス）は家庭用・業務用の燃料やカセットコンロの燃料です。ガソリンは炭素数およそ5〜12の炭化水素の混合物で、アルカンの「燃焼しやすさと反応性の低さ」が燃料としての扱いやすさを支えています。

プラスチック原料としてのアルケンと付加重合

エチレンは石油化学の最も基本的な原料で、付加重合でポリエチレン（袋・容器・フィルム）になり、水の付加でエタノールを作るなど、多くの製品の出発点です。プロペンの付加重合ではポリプロピレン（自動車部品・食品容器・繊維）が得られます。「二重結合が開いてつながる」というこの項目の反応が、そのまま樹脂産業の土台になっています。

アセチレン溶接とエチレンの熟成作用

アセチレンを酸素と燃やす酸素アセチレン炎は約3000 ℃に達し、金属の溶接や切断に使われてきました。発生には炭化カルシウムと水の反応（この項目の製法）が長く使われています。またエチレンは植物ホルモンとして果実の熟成を促す働きがあり、バナナなどの追熟に利用されます。同じ炭化水素でも、結合の種類と分子の形が違えば現場での顔はまったく変わります。

考え出した人

ウラジーミル・マルコフニコフ（1837〜1904、ロシアの化学者）、アウグスト・ケクレ（1829〜1896、ドイツの化学者）

付加反応の生成物を予測する経験則は、ロシアの化学者ウラジーミル・マルコフニコフが1869〜1870年ごろに発表した観察に基づき、後にマルコフニコフ則と呼ばれるようになりました。「水素は、すでに水素の多い炭素に付く」という本文の規則がその内容です。また、ベンゼンの環構造は、ドイツの化学者アウグスト・ケクレが1865年に六角形の環に単結合と二重結合が交互に並ぶ構造を提案したことが出発点で、芳香族化合物を通常のアルケンとは別の仲間として扱う考え方はここから始まりました。
