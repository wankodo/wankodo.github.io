溶解平衡と溶解度積

化学の考え方辞典 ― 溶液（大学）

化学ツール集トップ ＞ 溶液 ＞ 溶解平衡と溶解度積

大学 溶液 計算機あり

どんな時に使えるか 難溶性の塩が水に溶ける溶解平衡では、飽和溶液中のイオン濃度の積が温度ごとに決まった値になり、この値が溶解度積 Ksp である。Ksp が分かれば塩の型（AB型・AB2型など）ごとに溶解度へ換算でき、実際のイオン濃度の積であるイオン積 Q と Ksp を比べれば沈殿が生じるかを予測でき、共通イオンがあると溶解度が下がる共通イオン効果も説明できる。

どんな問題に使うか

難溶性の塩（水にごくわずかしか溶けない塩）が飽和溶液中でつり合う溶解平衡を扱う解法です。次のような場面で使います。

  • 溶解度積 Ksp から、その塩が水にどれだけ溶けるか（モル溶解度）を求める問題
  • 測った溶解度から、逆に Ksp を求める問題
  • 2つのイオンを含む溶液を混ぜたときに、沈殿が生じるかどうかを予測する問題
  • 共通イオンを含む溶液中で、溶解度がどれだけ下がるかを求める問題（共通イオン効果）

沈殿が実際にどんな色で生じ、どのイオンの検出に使われるかは沈殿反応とイオンの検出の項目と連携しています。この記事では、その沈殿が「生じるかどうか・どれだけ溶けるか」を数値で決める考え方を扱います。

公式・考え方

難溶性の塩 AB が水に溶けると、一部がイオンに分かれ、やがて「溶ける速さ」と「固体に戻る速さ」がつり合います。この溶解平衡は次のように書けます。

AB（固体） ⇌ A+ ＋ B−

飽和溶液（これ以上溶けない溶液）では、イオン濃度の積が温度ごとに決まった一定値になります。この値が溶解度積 Ksp です。一般に塩 AmBn については次の式になります。

Ksp ＝ [A]m × [B]n（飽和溶液中、温度一定）

各記号の意味と単位は次の通りです。

  • [A]、[B]：飽和溶液中の各イオンのモル濃度 [mol/L]
  • Ksp：溶解度積。温度によって変わる定数で、この記事の値はすべて 25 ℃ のもの
  • s：モル溶解度 [mol/L]。塩が 1 L の水に何 mol 溶けるかを表す
  • Q：イオン積。今その溶液で実際に成り立っているイオン濃度の積（Ksp と同じ形の式で計算する）

Ksp と溶解度 s の換算（塩の型ごと）

純粋な水に塩を溶かした場合、溶けた塩の量 s から各イオンの濃度が決まるため、Ksp と s は塩の組成（型）ごとに次のように換算できます。

  • AB型（AgCl、BaSO4 など）：[A] ＝ [B] ＝ s なので Ksp ＝ s2、s ＝ √Ksp
  • AB2型（CaF2、PbCl2 など）：[A] ＝ s、[B] ＝ 2s なので Ksp ＝ s × (2s)2 ＝ 4s3、s ＝ (Ksp ÷ 4)1/3
  • A2B型（Ag2CrO4 など）：[A] ＝ 2s、[B] ＝ s なので AB2型と同じく Ksp ＝ 4s3
  • AB3型（Fe(OH)3 など）：[A] ＝ s、[B] ＝ 3s なので Ksp ＝ s × (3s)3 ＝ 27s4、s ＝ (Ksp ÷ 27)1/4
  • A3B2型（Ca3(PO4)2 など）：[A] ＝ 3s、[B] ＝ 2s なので Ksp ＝ (3s)3 × (2s)2 ＝ 108s5

注意点として、Ksp の大小はそのまま溶解度の大小にはなりません。型が違う塩どうしでは、換算して s で比べる必要があります（例題2を参照）。

代表的な塩の Ksp（25 ℃）

  • 塩化銀 AgCl：1.8×10−10（AB型）
  • 臭化銀 AgBr：5.0×10−13（AB型）
  • ヨウ化銀 AgI：8.3×10−17（AB型）
  • 硫酸バリウム BaSO4：1.1×10−10（AB型）
  • 炭酸カルシウム CaCO3：3.8×10−9（AB型）
  • フッ化カルシウム CaF2：3.9×10−11（AB2型）
  • 水酸化カルシウム Ca(OH)2：5.5×10−6（AB2型）
  • 水酸化マグネシウム Mg(OH)2：5.6×10−12（AB2型）
  • 塩化鉛(II) PbCl2：1.7×10−5（AB2型）
  • 水酸化鉄(III) Fe(OH)3：2.8×10−39（AB3型）

Ksp の値は資料によって多少異なることがあります。計算では、問題やページで示された値を使うのが原則です。

イオン積 Q と Ksp の比較による沈殿予測

今の溶液のイオン濃度から Ksp と同じ形の積 Q を計算し、Ksp と比べます。

  • Q ＞ Ksp：飽和を超えている（過飽和）ので、Q が Ksp に等しくなるまで沈殿が生じる
  • Q ＝ Ksp：ちょうど飽和。沈殿は生じない（平衡状態）
  • Q ＜ Ksp：まだ溶ける余裕がある（不飽和）ので、沈殿は生じない

溶液どうしを混ぜる問題では、混合によって各イオンの濃度が薄まる（体積が増える）ことを忘れずに、混合後の濃度で Q を計算します。

共通イオン効果

塩と共通のイオンをすでに含む溶液では、ルシャトリエの原理により溶解平衡が固体側へ寄り、溶解度が下がります。これが共通イオン効果です。AB型の塩で共通イオン B− の濃度 c が溶解度 s よりずっと大きい場合、[B] ≒ c と近似でき、s ≒ Ksp ÷ c で見積もれます。

解き方の手順

  1. 塩の型を確認する。化学式から AB型・AB2型などの型を決め、Ksp と s の換算式を選びます。
  2. Ksp から s を求める。型ごとの式（AB型なら s ＝ √Ksp、AB2型なら s ＝ (Ksp ÷ 4)1/3 など）に代入します。
  3. 沈殿予測では Q を計算する。実際の（混合後なら混合後の）イオン濃度を Ksp と同じ形の積に入れて Q を求め、Ksp と大小を比べます。
  4. 共通イオンがある場合は近似を使う。共通イオン濃度 c が s より十分大きいとき、そのイオンの濃度を c のままとして s を求めます。
  5. 結果の向きを確認する。Ksp が小さい塩ほど s は小さく、共通イオンがあると s は純水中より小さくなるはずです。

例題

問題1：塩化銀 AgCl の Ksp ＝ 1.8×10−10（25 ℃）である。純粋な水に対する AgCl のモル溶解度 s [mol/L] を求めよ。問題2：フッ化カルシウム CaF2 の Ksp ＝ 3.9×10−11（25 ℃）である。モル溶解度 s を求め、AgCl とどちらが溶けやすいか比べよ。問題3：[Ag+] ＝ 1.0×10−4 mol/L、[Cl−] ＝ 1.0×10−3 mol/L の溶液では、AgCl の沈殿が生じるか。問題4：0.010 mol/L の塩化物イオンを含む溶液に対する AgCl のモル溶解度を求めよ。

答えと解説を見る
  1. 問題1：AgCl は AB型なので Ksp ＝ s2。s ＝ √(1.8×10−10) ＝ 1.3×10−5 mol/L。
  2. 問題2：CaF2 は AB2型なので Ksp ＝ 4s3。s ＝ (3.9×10−11 ÷ 4)1/3 ＝ (9.75×10−12)1/3 ＝ 2.1×10−4 mol/L。Ksp は CaF2 の方が小さいのに、溶解度は CaF2 の方が約16倍大きい。型が違う塩は Ksp の大小だけで溶けやすさを比べられません。
  3. 問題3：Q ＝ [Ag+][Cl−] ＝ 1.0×10−4 × 1.0×10−3 ＝ 1.0×10−7。Ksp ＝ 1.8×10−10 より Q が大きいので、沈殿が生じます。
  4. 問題4：共通イオン Cl− の濃度 0.010 mol/L は s より十分大きいので [Cl−] ≒ 0.010 mol/L と近似でき、s ≒ Ksp ÷ 0.010 ＝ 1.8×10−10 ÷ 1.0×10−2 ＝ 1.8×10−8 mol/L。純粋な水のとき（1.3×10−5 mol/L）の約740分の1まで下がります。これが共通イオン効果です。

答え：問題1は s ＝ 1.3×10−5 mol/L、問題2は s ＝ 2.1×10−4 mol/L で CaF2 の方が溶けやすい、問題3は沈殿が生じる、問題4は s ＝ 1.8×10−8 mol/L。

現場での使われ方

イオンの定性分析と分離

金属イオンの混合物から特定のイオンだけを沈殿させて分ける定性分析は、Ksp の違いを利用しています。たとえば塩化物イオンを加えると Ag+ などが塩化物として沈殿し、pH を調整すると水酸化物の Ksp の違いでイオンごとに沈殿する順序を制御できます。沈殿の色や溶け方の観察と組み合わせる方法は沈殿反応とイオンの検出で扱っています。

水質・環境分析での硫酸イオンの定量

試料水に塩化バリウムを加え、硫酸バリウム BaSO4（Ksp ＝ 1.1×10−10）として沈殿させて、その質量から硫酸イオンの量を求める重量分析は、水質検査などで使われる古典的な定量法です。BaSO4 の Ksp が非常に小さいため、硫酸イオンをほぼ完全に沈殿させられることがこの方法の根拠になっています。

医療用造影剤の硫酸バリウム

消化管の X 線検査で使われるバリウム造影剤は硫酸バリウム BaSO4 です。バリウムイオン自体には毒性がありますが、BaSO4 は Ksp が 1.1×10−10 と極めて小さく、水にも胃酸にもほとんど溶けないため、イオンとして吸収されずに使えます。溶解度積の小ささそのものが安全性を支えている例です。

水道水の軟水化とスケール防止

カルシウムイオンを多く含む水を加熱すると、炭酸カルシウム CaCO3（Ksp ＝ 3.8×10−9）が沈殿してボイラーや配管の内側にスケール（湯あか状の付着物）としてたまります。水処理では、炭酸カルシウムなどをあらかじめ沈殿させて取り除く沈殿軟化法が使われており、どの条件で沈殿が始まるかの判断に Ksp と Q の比較が使われます。

考え出した人

ヴァルター・ネルンスト（1864〜1941、ドイツの物理化学者）

溶解度積の考え方は、ドイツの物理化学者ヴァルター・ネルンスト（1864〜1941）が1889年に提唱したとされます。難溶性塩の飽和溶液ではイオン濃度の積が一定になるという「溶解度積の原理」で、沈殿が生じる条件を数値で予測できるようになりました。その土台には、平衡時の濃度の関係を定式化したギュルドベリとボーゲの質量作用の法則（1864〜1867年）があります。ネルンストは電極電位のネルンストの式でも知られ、1920年にノーベル化学賞を受賞しました。
