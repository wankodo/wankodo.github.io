電気分解の生成物と優先順位

化学の考え方辞典 ― 酸化還元・電池と電気分解（高校化学・2年）

化学ツール集トップ ＞ 酸化還元・電池と電気分解 ＞ 電気分解の生成物と優先順位

高校化学・2年 酸化還元・電池と電気分解

どんな時に使えるか 電気分解で各電極に何が出るかは、陰極では陽イオンのイオン化傾向、陽極では陰イオンの種類と電極の材質で決まる。陰極ではイオン化傾向の小さい金属のイオンが金属として析出し、イオン化傾向の大きい金属のイオンは析出せず、水が還元されて水素が発生する。陽極ではハロゲン化物イオンがハロゲンの単体になり、それ以外の陰イオンの場合は水が酸化されて酸素が発生し、溶けやすい金属電極では電極自身が溶ける。

どんな問題に使うか

電気分解で各電極に何が析出・発生するか（何が出るか）を予測するときの判定法です。次のような場面で使います。

  • 水溶液を電気分解したとき、陰極・陽極で発生する気体や析出する金属を答える問題
  • 陰極・陽極で起こる反応を、電子 e− を含む電極反応式（半反応式）で書く問題
  • 電極の材質（白金・炭素か、銅などの金属か）を変えたとき、生成物がどう変わるかを答える問題
  • 2つの電極反応式を足して、電気分解全体の反応式を書く問題

この項目は「何が出るか」の判定に特化します。出た物質が何 g・何 L かという量の計算は、電気量とファラデーの法則を使う電気分解とファラデーの法則で扱います。まず生成物を正しく判定し、次に量を計算する、という順序で考えます。

大前提として、電気分解では電源の負極につないだ陰極で還元（電子を受け取る反応）、電源の正極につないだ陽極で酸化（電子を放出する反応）が起こります。陽イオンは陰極へ、陰イオンは陽極へ引き寄せられますが、溶液中に複数の候補があるときは、どれか1つが優先して反応します。その優先順位を覚えるのがこの項目の中心です。

公式・考え方

陰極（還元）の優先順位

陰極では、溶液中の陽イオンが電子を受け取って還元されます。金属イオンについては、その金属のイオン化傾向（金属が電子を放出して陽イオンになろうとする性質）の大きさで判定します。イオン化傾向が小さい金属は、イオンのままでいるより金属に戻る方が安定なので、そのまま金属として析出します。逆にイオン化傾向が大きい金属のイオンは水溶液中で安定で、無理に金属に戻そうとしても、代わりに水が還元されて水素が発生します。

陰極：イオン化傾向の小さい金属のイオン → 金属が析出／イオン化傾向の大きい金属のイオン → 水が還元されて H2 が発生

境界の目安は次の通りです。

  • 金属が析出する：Zn2+、Fe2+、Ni2+、Sn2+、Pb2+、Cu2+、Ag+ など（イオン化傾向が水素以下の金属のイオン）。代表例：Cu2+ ＋ 2e− → Cu、Ag+ ＋ e− → Ag
  • 水素が発生する：K+、Ca2+、Na+、Mg2+、Al3+ など（イオン化傾向の大きい金属のイオン）。これらの金属は水と激しく反応するほどイオンになりやすいため、水溶液の電気分解では金属として取り出せません

水が還元される反応は、中性・塩基性の水溶液では次の式で書きます。

2H2O ＋ 2e− → H2 ＋ 2OH−

このため、水素が発生した陰極のまわりの水溶液は OH− が増えて塩基性になります。なお、酸性の水溶液では H+ が多く存在し、2H+ ＋ 2e− → H2 と書くこともありますが、起こっていることは同じ水素の発生です。

陽極（酸化）の優先順位

陽極では、溶液中の陰イオンが電子を放出して酸化されます。こちらは陰イオンの種類で判定します。ただし、電極自身が溶ける場合が最優先になることがあるため、最初に電極の材質を確認します。

陽極：①溶けやすい金属電極（Cu・Ag など）→ 電極自身が溶ける／②ハロゲン化物イオン → ハロゲンの単体が発生／③それ以外の陰イオン → 水が酸化されて O2 が発生
  • ①電極自身が溶ける：陽極が銅 Cu や銀 Ag のような金属の場合、白金 Pt や炭素 C の電極と違って電極自身が酸化されて溶け出します。代表例：Cu → Cu2+ ＋ 2e−。この場合は溶液中の陰イオンは反応しません
  • ②ハロゲンの単体が発生する：Cl−、Br−、I− などのハロゲン化物イオンは電子を放出しやすく、ハロゲンの単体になります。代表例：2Cl− → Cl2 ＋ 2e−、2I− → I2 ＋ 2e−
  • ③酸素が発生する：OH−、SO42−、NO3− の場合は、これらの陰イオン自身は酸化されにくく（OH− の場合は下記の通り水の酸化とまとめて書けます）、水が酸化されて酸素が発生します

水が酸化される反応は、酸性・中性の水溶液では次の式で書きます。

2H2O → O2 ＋ 4H+ ＋ 4e−

このため、酸素が発生した陽極のまわりの水溶液は H+ が増えて酸性になります。水酸化物イオン OH− が多い塩基性の水溶液では、同じ酸素の発生を 4OH− → O2 ＋ 2H2O ＋ 4e− と書きます。

各記号の意味は次の通りです。

  • e−：電子。還元（陰極）の式では左辺に、酸化（陽極）の式では右辺に書く
  • 陰極・陽極：電気分解では、電源の負極につないだ電極が陰極（還元）、正極につないだ電極が陽極（酸化）。電池とは極の符号と反応の対応が逆になる点に注意する
  • イオン化傾向：金属が水溶液中で電子を放出して陽イオンになろうとする性質の大きさ。K ＞ Ca ＞ Na ＞ Mg ＞ Al ＞ Zn ＞ Fe ＞ Ni ＞ Sn ＞ Pb ＞（H）＞ Cu ＞ Hg ＞ Ag ＞ Pt ＞ Au の順に大きい

代表例の電極反応式

塩化ナトリウム NaCl 水溶液（白金または炭素電極）：陰極では Na+ のイオン化傾向が大きいため金属ナトリウムは析出せず、水が還元されます。陽極では Cl− が塩素になります。

陰極： 2H2O ＋ 2e− → H2 ＋ 2OH−（H2 が発生）
陽極： 2Cl− → Cl2 ＋ 2e−（Cl2 が発生）

硫酸銅（II）CuSO4 水溶液・白金電極：陰極では Cu2+ が銅として析出します。陽極では SO42− は反応せず、水が酸化されて酸素が発生します。

陰極： Cu2+ ＋ 2e− → Cu（Cu が析出）
陽極： 2H2O → O2 ＋ 4H+ ＋ 4e−（O2 が発生）

硫酸銅（II）CuSO4 水溶液・銅電極：陰極は白金電極の場合と同じく銅が析出しますが、陽極では水ではなく銅電極自身が溶けます。陽極で溶けた分だけ陰極に銅が析出するので、水溶液中の Cu2+ の濃度はほぼ変わりません。

陰極： Cu2+ ＋ 2e− → Cu（Cu が析出）
陽極： Cu → Cu2+ ＋ 2e−（Cu 電極が溶ける）

水酸化ナトリウム NaOH 水溶液（白金電極）：陰極では Na+ は析出せず水が還元され、陽極では OH−（水）が酸化されます。全体として水が水素と酸素に分解される反応になります。

陰極： 2H2O ＋ 2e− → H2 ＋ 2OH−（H2 が発生）
陽極： 4OH− → O2 ＋ 2H2O ＋ 4e−（O2 が発生）

塩化銅（II）CuCl2 水溶液（白金または炭素電極）：陰極では銅が析出し、陽極では塩素が発生します。両方の電極反応に溶けている塩のイオンがそのまま使われる、最も単純な例です。

陰極： Cu2+ ＋ 2e− → Cu（Cu が析出）
陽極： 2Cl− → Cl2 ＋ 2e−（Cl2 が発生）

解き方の手順

  1. 水溶液中のイオンと電極の材質を書き出す。溶けている物質が電離してできる陽イオン・陰イオンと、陽極が白金・炭素か、銅などの金属かを確認します。陽極の材質は生成物を変えるので、見落とさないことが第一歩です。
  2. 陰極を判定する。陽イオンの金属のイオン化傾向を見ます。小さければ（Zn2+、Cu2+、Ag+ など）金属が析出し、大きければ（Na+、K+、Ca2+、Al3+ など）水が還元されて水素が発生します。
  3. 陽極を判定する。まず電極自身が溶けるかどうかを確認し、溶けない電極なら陰イオンを見ます。ハロゲン化物イオン（Cl− など）があればハロゲンの単体、それ以外（SO42−、NO3− など）なら水が酸化されて酸素が発生します。
  4. 両極の電極反応式を書く。原子の数と電荷が両辺でそろうように係数を付けます。陰極の式は電子を左辺に、陽極の式は電子を右辺に置きます。
  5. 必要なら全体の反応式を作る。両極で出入りする電子の数を最小公倍数でそろえて2式を足すと、電子が消えて電気分解全体の反応式になります。

例題

問題1：塩化ナトリウム NaCl 水溶液を白金電極で電気分解すると、陰極・陽極ではそれぞれ何が発生・析出するか。電極反応式も書け。問題2：硫酸銅（II）CuSO4 水溶液を電気分解するとき、(a) 白金電極の場合と (b) 銅電極の場合で、陽極の反応はどう違うか。問題3：水酸化ナトリウム NaOH 水溶液を白金電極で電気分解すると、陰極・陽極ではそれぞれ何が発生するか。問題4：硝酸カリウム KNO3 水溶液を白金電極で電気分解すると、陰極・陽極ではそれぞれ何が発生するか。問題5：塩化銅（II）CuCl2 水溶液を炭素電極で電気分解したときの、全体の反応式を書け。

答えと解説を見る
  1. 問題1：陰極では、Na+ のイオン化傾向が大きいため金属ナトリウムは析出せず、水が還元されて水素が発生します：2H2O ＋ 2e− → H2 ＋ 2OH−。陽極では Cl− が酸化されて塩素が発生します：2Cl− → Cl2 ＋ 2e−。
  2. 問題2：(a) 白金電極では SO42− は反応せず、水が酸化されて酸素が発生します：2H2O → O2 ＋ 4H+ ＋ 4e−。(b) 銅電極では電極自身が優先して溶けます：Cu → Cu2+ ＋ 2e−。陰極はいずれの場合も Cu2+ ＋ 2e− → Cu で銅が析出します。
  3. 問題3：陰極では Na+ は析出せず、水が還元されて水素が発生します。陽極では OH− が酸化されて（水の酸化として）酸素が発生します：4OH− → O2 ＋ 2H2O ＋ 4e−。全体では水が水素と酸素に分解されます。
  4. 問題4：K+ はイオン化傾向が大きく陰極では析出せず、水が還元されて水素が発生します。NO3− はハロゲン化物イオンではないので陽極では反応せず、水が酸化されて酸素が発生します。つまり両極とも水が反応し、陰極で水素、陽極で酸素が発生します。
  5. 問題5：陰極：Cu2+ ＋ 2e− → Cu、陽極：2Cl− → Cl2 ＋ 2e−。電子の数はどちらも2個でそろっているので、そのまま足して電子を消すと、全体の反応は CuCl2 → Cu ＋ Cl2 となります。

答え：問題1は陰極で水素、陽極で塩素。問題2は (a) 酸素が発生、(b) 銅電極が溶ける。問題3は陰極で水素、陽極で酸素。問題4は陰極で水素、陽極で酸素。問題5は CuCl2 → Cu ＋ Cl2。判定のコツは、陰極は陽イオンのイオン化傾向、陽極は「電極の材質 → 陰イオンの種類」の順に確認することです。特に問題2のように、電極を変えるだけで陽極の生成物が変わるケースがよく出題されます。

現場での使われ方

銅の電解精錬

銅の電解精錬は、陽極に不純物を含む粗銅、陰極に純銅の薄板を使い、硫酸銅（II）水溶液を電気分解する方法です。陽極では銅が Cu → Cu2+ ＋ 2e− と溶け出し、陰極では Cu2+ ＋ 2e− → Cu と純粋な銅が析出します。粗銅に含まれるイオン化傾向の大きい金属（亜鉛や鉄など）の不純物はイオンとして溶け出しても陰極には析出せず、イオン化傾向の小さい金や銀などは陽極の下に沈殿（陽極泥）として回収されます。この項目の優先順位そのものが、純度 99.99％ 級の電気銅を作り分ける仕組みになっています。

アルミニウムの溶融塩電解

アルミニウムはイオン化傾向が大きいため、水溶液を電気分解しても陰極では水が還元されて水素が出るだけで、金属アルミニウムは得られません。そこで工業的には、水溶液ではなく、酸化アルミニウム Al2O3 を高温で溶かした溶融塩（氷晶石を加えて融点を下げたもの）を電気分解し、陰極に金属アルミニウムを取り出します（ホール・エルー法）。水溶液では取り出せない金属は溶融塩電解で作る、という優先順位の裏側の応用です。大量の電力を必要とすることから、アルミニウムは「電気の缶詰」とも呼ばれます。

食塩水の電気分解と電気めっき

塩化ナトリウム水溶液の電気分解は、陽極で塩素、陰極で水素と水酸化ナトリウムが得られる反応で、水酸化ナトリウムや塩素を製造する工業プロセス（イオン交換膜法）の基礎になっています。また、金属イオンが陰極に金属として析出する性質は、装飾品や電子部品の表面に金属の薄膜を付ける電気めっきに使われています。どちらの現場でも、目的の物質だけを出すために、電極の材質や溶液の組み合わせが優先順位をもとに設計されています。

考え出した人

マイケル・ファラデー（1791〜1867、イギリスの物理学者・化学者）

電気分解という現象そのものを体系化したのは、イギリスの物理学者・化学者マイケル・ファラデー（1791〜1867）です。1833〜34年に電気分解の法則を実験から見いだし、電極で変化する物質の量が電気量に比例することを示しました。また、「電極（electrode）」「陰極（cathode）」「陽極（anode）」「イオン（ion）」「電気分解（electrolysis）」といった、生成物の判定で今も使う基本用語は、ファラデーが学者ウィリアム・ヒューウェルと相談して作った言葉です。どのイオンがどちらの電極へ向かい、そこで何に変わるかという考え方の土台は、彼の研究によって築かれました。電気量と生成物の量の関係（ファラデーの法則）については、電気分解とファラデーの法則で詳しく扱います。
