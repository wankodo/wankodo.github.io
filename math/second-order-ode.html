二階線形微分方程式

数学解法辞典 ― 微分・積分（大学）

数学ツール集トップ ＞ 微分・積分 ＞ 二階線形微分方程式

大学 微分・積分 計算機あり

どんな時に使えるか車のサスペンションのばねとダンパーの効き具合や、地震で建物がどう揺れるかは、二階の微分方程式で表される振動の問題である。楽器の弦の振動や電気回路の応答も同じ形で、解き方の型がそのまま設計に使われる。

どんな問題に使うか

未知関数 y とその1階導関数 y'、2階導関数 y'' が1次式の形で結ばれた方程式です。ここでは係数が定数の同次形 y'' ＋ p y' ＋ q y ＝ 0 を扱います。加速度が位置と速度で決まる運動は、どれもこの形になります。

  • ばねにつないだおもりの振動（減衰がある場合・ない場合）を表し、解く問題
  • RLC回路の電流や電圧の時間変化を求める問題
  • 初期位置と初速度を与えて、振動の様子（周期や減衰の速さ）を具体的に求める問題
  • 特性方程式の根の形から、解が振動するか・減衰するか・発散するかを判定する問題

解き方の型は1つで、特性方程式という2次方程式を解くだけで一般解の形が決まります。根が実数か複素数かで、解の見た目が大きく変わるのがポイントです。

公式・考え方

y'' ＋ p y' ＋ q y ＝ 0　→　特性方程式 r2 ＋ p r ＋ q ＝ 0

なぜ指数関数で試すのか：y ＝ erx と置くと、y' ＝ r erx、y'' ＝ r2 erx となり、方程式は erx(r2 ＋ p r ＋ q) ＝ 0 となります。erx は 0 にならないので、r が特性方程式の根であれば解になります。

判別式 D ＝ p2 − 4q による3つの場合分け：

D ＞ 0：y ＝ C1 er1x ＋ C2 er2x　／　D ＝ 0：y ＝ (C1 ＋ C2x) erx　／　D ＜ 0：y ＝ eαx(C1 cos βx ＋ C2 sin βx)

D ＜ 0 の場合、根は α ± βi（α ＝ −p/2、β ＝ √(−D)/2）という複素数になり、オイラーの公式を通して三角関数の振動の形に書き直せます。α が振動の減衰・増幅を、β が振動の速さを決めます。

解き方の手順

  1. 特性方程式 r2 ＋ p r ＋ q ＝ 0 を立てる。y'' を r2、y' を r、y を 1 に置き換えた2次方程式です。
  2. 判別式 D ＝ p2 − 4q を計算し、符号で場合分けする。
  3. 特性方程式の根を求める。D ＞ 0 なら異なる実数根、D ＝ 0 なら重根、D ＜ 0 なら α ± βi の形に書く。
  4. 場合に応じた一般解の形に当てはめる。任意定数 C1、C2 を含んだ形が一般解です。
  5. 初期条件があれば、C1、C2 を決める。y と y' に初期値を代入して連立方程式を解きます。

例題

問題：ばねの振動を表す方程式 y'' ＋ 4y ＝ 0 を、初期条件 y(0) ＝ 1、y'(0) ＝ 0 のもとで解け。

答えと解説を見る

p ＝ 0、q ＝ 4 の場合です。特性方程式から順に解きます。

  1. 特性方程式は r2 ＋ 4 ＝ 0。判別式は D ＝ 02 − 4×4 ＝ −16 ＜ 0。
  2. 根は r ＝ ±2i なので、α ＝ 0、β ＝ 2。
  3. 一般解は y ＝ C1 cos 2t ＋ C2 sin 2t（変数を t として書く）。
  4. y(0) ＝ C1 ＝ 1。また y' ＝ −2C1 sin 2t ＋ 2C2 cos 2t なので、y'(0) ＝ 2C2 ＝ 0、よって C2 ＝ 0。

答え：y ＝ cos 2t。減衰のない単振動で、周期は 2π/2 ＝ π です。

現場での使われ方

車のサスペンション設計

車のサスペンションは、ばねとダンパー（減衰器）の組み合わせで表され、その動きは二階線形微分方程式になります。特性方程式の根の形から、段差を越えたあと車体が何回揺れて収まるか、揺れが速く収まるか（過減衰・臨界減衰・不足減衰）を判定し、乗り心地と安定性のバランスを設計します。

建物の耐震設計

地震で建物がどう揺れるかも、建物を質量・ばね・ダンパーで近似した振動の方程式で解析します。固有周期（β に対応する量）が地震の揺れの周期と重なると共振して揺れが大きくなるため、固有周期をずらす設計や、ダンパーで減衰を加える設計にこの計算が使われます。

楽器の弦と電気回路

楽器の弦の振動は、張力と線密度から決まる固有振動数の重ね合わせとして解析され、音の高さの設計に結びつきます。また、抵抗・コイル・コンデンサからなるRLC回路の電流も同じ形の方程式で表され、共振周波数の設計に使われます。

考え出した人

レオンハルト・オイラー（1707〜1783）は、定数係数の線形微分方程式を特性方程式で解く方法を確立しました。指数関数を試すという発想と、複素数の根を三角関数で表すオイラーの公式が、この解法の土台になっています。弦の振動の問題は、ダランベール（1717〜1783）ら同時代の数学者が競って研究したテーマで、振動現象の数学的な理解がこの時代に大きく進みました。
