大学 微分・積分

どんな時に使えるか 微分も積分も、「限りなく近づく」という極限の考え方の上に成り立っている。コンピュータで方程式の答えを少しずつ近づけて求める計算（数値計算）でも、どこまで近づければ十分かを決める物差しになる。

どんな問題に使うか

極限とは、数を限りなく近づけていったときに、値がどこへ近づくかを考えることです。微分も積分も、この極限の上に成り立っています。次のような場面で使います。

  • 数列 an が n を大きくしたときに、ある値に近づくかどうか（収束するか）を調べる問題
  • 関数 f(x) で x をある値に限りなく近づけたときの、f(x) の近づき先を求める問題
  • 0/0 のような「そのまま代入すると計算できない」形の極限を求める問題
  • 微分の定義（接線の傾き）や、定積分の定義（面積）を理解する土台として

「近づく」という日常の言葉を、数学として正確に扱うための考え方が極限です。

公式・考え方

「限りなく近づく」とはどういうことか

数列 1, 1/2, 1/3, 1/4, … は、項を進めるほど 0 に近づきます。このように「どんどん近づいて、どんなに小さい幅の中にも入り続ける」ことを、極限値 0 に収束すると言い、limn→∞ 1/n ＝ 0 と書きます。

ε-δ（イプシロン・デルタ）の入口

「近づく」を厳密に言う言い方が ε-δ 論法です。考え方はシンプルで、「結果の側でどれだけ近いか（ε）を指定されたら、それに応じて入力の側の近さ（δ）を答えられる」という形で近さを保証します。「近ければ近いほど良い」ではなく、どんな近さの要求にも応えられることが「極限である」ことの意味です。ここでは入口の考え方だけ押さえれば十分です。

はさみうちの原理

求めたい列や関数が、上下から別の列・関数にはさまれていて、上下の両方が同じ値に収束するなら、はさまれた方も同じ値に収束します。直接計算しにくい極限を、計算しやすいもので挟んで決める強力な考え方です。

an ≦ bn ≦ cn、an → α、cn → α なら bn → α

ロピタルの定理の入口

lim f(x)/g(x) が 0/0 や ∞/∞ の形（不定形）になるとき、分子と分母を別々に微分した極限で求められる場合があります。これがロピタルの定理です。使える条件（不定形であることなど）を確認してから使うのが約束です。

解き方の手順

  1. まずそのまま代入してみる。関数の極限なら、近づける値を代入して計算できる形かどうかを確認します。計算できればそれが極限です。
  2. 数列の極限は、一番強い項で割る。分母・分子を最も大きくなる項（例：n の最高次）で割ると、1/n の形が現れて 0 に近づく部分が見えてきます。
  3. 不定形なら変形する。因数分解して約分する、有理化するなど、0/0 の形を崩してから改めて代入します。
  4. はさみうちが使えないか考える。sin や絶対値を含むものは、−1 ≦ sin x ≦ 1 のような不等式で挟むのが定石です。
  5. それでも難しければロピタルの定理を検討する。不定形であることを確認した上で、分子・分母を別々に微分します。

例題

問題：数列の極限 limn→∞ (2n ＋ 1)/(n ＋ 3) を求めよ。

答えと解説を見る

そのまま n → ∞ とすると ∞/∞ の形で決められません。分母・分子を n で割ります。

  1. 分母・分子を n で割る：(2 ＋ 1/n)/(1 ＋ 3/n)
  2. n → ∞ のとき 1/n → 0、3/n → 0 だから、分子は 2、分母は 1 に近づく
  3. よって極限は 2/1 ＝ 2

答え：2。n が大きくなると、＋1 や ＋3 の影響は相対的に消えていく、という見方ができます。

問題：limx→0 (sin x)/x ＝ 1 であることを、はさみうちの考え方で説明せよ。

答えと解説を見る

単位円の上で、角度 x に対して面積を比べると、0 ＜ x ＜ π/2 の範囲で次の不等式が成り立ちます。

  1. 面積の比較から：cos x ＜ (sin x)/x ＜ 1
  2. x → 0 のとき、左辺の cos x は 1 に近づく。右辺は 1 のまま
  3. 両側がどちらも 1 に近づくので、はさみうちの原理から (sin x)/x も 1 に近づく

答え：極限は 1。この極限は sin x の微分を求める土台になる、大切な結果です。

現場での使われ方

微分・積分すべての土台

微分は「差の割り算の極限」、積分は「細かく刻んだ合計の極限」として定義されています。速度や面積といった実用的な計算が正しく行えるのは、その土台に極限の考え方があるからです。微積分を使うすべての現場は、間接的に極限を使っています。

数値計算の収束の考え方

コンピュータで方程式の解やシミュレーションの答えを求めるとき、計算は「少しずつ近づける」繰り返しで行われます。そのとき「どこまで近づければ十分か（許容誤差）」や「本当に答えに近づいているか（収束するか）」を判断する物差しが、極限の考え方です。このページの先にあるニュートン法も、収束するかどうかが極限の問題です。

考え出した人

オーギュスタン＝ルイ・コーシー（1789〜1857）極限の考え方を厳密に定義し直し、微積分を「限りなく近づく」という曖昧な言い方から、確かな論理の上に置き直したフランスの数学者です。

カール・ワイエルシュトラス（1815〜1897）コーシーの考え方をさらに進め、極限を ε-δ論法の形に完成させたドイツの数学者です。今の教科書の厳密な極限の定義は、主にこの形に基づいています。

関連項目

  • 微分（導関数） ― 微分は、差の割り算の極限として定義されます。
  • 定積分 ― 定積分は、細かく刻んだ合計の極限として定義されます。
  • 等差数列・等比数列 ― 数列の極限は、数列の知識の先にある考え方です。
  • ニュートン法 ― 繰り返し計算が答えに収束するかどうかは、極限の問題です。
