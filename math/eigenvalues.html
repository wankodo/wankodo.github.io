固有値・固有ベクトル

数学解法辞典 ― 線形代数（大学）

数学ツール集トップ ＞ 線形代数 ＞ 固有値・固有ベクトル

大学 線形代数

どんな時に使えるか 建物や橋にはそれぞれ揺れやすい振動の速さ（固有振動数）があり、固有値を求めることで地震の揺れと共振する危険を調べる。Googleの検索順位を決めるPageRankや、大量のデータの要点をつかむ主成分分析も、固有値の考え方が土台になっている。

どんな問題に使うか

行列 A でベクトルを変換すると、ふつうベクトルの向きは変わってしまいます。ところが特別なベクトルでは、向きが変わらず長さだけが λ 倍になります。この特別なベクトルを固有ベクトル、倍率 λ を固有値といいます。

A x ＝ λ x （x ≠ 0）
  • 変換しても向きが変わらない「軸」の方向を見つけたい問題
  • 建物や機械がどの速さで揺れやすいか（固有振動数）を調べる問題
  • 行列を対角化して、行列の累乗 An を簡単に計算したい問題
  • たくさんのデータの中から、ばらつきの大きい方向（主成分）を取り出す問題

公式・考え方

固有方程式

A x ＝ λ x を移項すると (A − λE) x ＝ 0 となります。x ≠ 0 という解を持つためには、行列 A − λE に逆行列があってはいけない、つまり行列式が 0 でなければなりません。

det(A − λE) ＝ 0

この方程式を固有方程式といいます。2×2 行列なら λ の二次方程式になり、その解が固有値です。固有値が求まったら、それぞれの λ を A x ＝ λ x に戻して、連立方程式を解くと固有ベクトルが得られます。

対角化の考え方

固有ベクトルを列に並べた行列 P を使うと、A ＝ P D P−1（D は固有値を対角に並べた行列）と変形できる場合があります。これを対角化といいます。対角化できれば、An ＝ P Dn P−1 と、対角成分を n 乗するだけの簡単な計算に置き換えられます。「変換を、固有ベクトルの向きを軸に見ることで、ただの伸び縮みの集まりとして捉え直す」ことが対角化の考え方です。

固有値の性質

  • 固有値の合計は、行列の対角成分の合計（トレース）に等しい。
  • 固有値の積は、行列式に等しい。
  • 固有値がすべて相異なれば、対応する固有ベクトルは独立で、対角化できる。

解き方の手順

  1. 固有方程式を立てる。A − λE の行列式を計算し、det(A − λE) ＝ 0 と置きます。
  2. 方程式を解いて固有値を求める。2×2 なら二次方程式を因数分解や解の公式で解きます。
  3. 各固有値ごとに固有ベクトルを求める。λ を (A − λE) x ＝ 0 に入れ、連立方程式を解いて x の方向を決めます（長さは任意なので、簡単な整数比で表すのが普通です）。
  4. 必要なら対角化する。固有ベクトルを列に並べて P を作り、P−1AP が対角行列になることを確認します。

例題

問題：行列 A ＝

21
12
の固有値と固有ベクトルを求めよ。

答えと解説を見る
  1. 固有方程式：det(A − λE) ＝ (2 − λ)2 − 1 ＝ λ2 − 4λ ＋ 3 ＝ (λ − 1)(λ − 3) ＝ 0
  2. 固有値は λ ＝ 1 と λ ＝ 3。（検算：合計 1 ＋ 3 ＝ 4 ＝ 対角成分の合計 2 ＋ 2 ✓、積 1 × 3 ＝ 3 ＝ 行列式 2 × 2 − 1 × 1 ✓）
  3. λ ＝ 3 のとき：(A − 3E) x ＝ 0 は −x ＋ y ＝ 0、つまり y ＝ x。固有ベクトルは (1, 1) の定数倍。
  4. λ ＝ 1 のとき：(A − E) x ＝ 0 は x ＋ y ＝ 0、つまり y ＝ −x。固有ベクトルは (1, −1) の定数倍。

答え：固有値 3 に対して固有ベクトル (1, 1) 方向、固有値 1 に対して固有ベクトル (1, −1) 方向。(1, 1) の向きのベクトルは、この変換で向きを変えずに3倍に伸びます。

現場での使われ方

建物や橋の振動解析（固有振動数）

建物や橋には、構造ごとに決まる「揺れやすい振動の速さ」＝固有振動数があります。これは質量と硬さを表す行列の固有値問題を解いて求めます。地震の揺れの速さと固有振動数が一致すると共振して揺れが大きくなるため、設計では固有値を計算して危険を避けます。

Google の PageRank

検索順位を決める PageRank は、「たくさんのページからリンクされているページは重要」という考え方を、ページ同士のリンクを行列で表し、その固有ベクトル（最も大きな固有値に対応するもの）を求める問題として定式化したものです。固有ベクトルの各成分が、そのままページの重要度になります。

主成分分析（データの要点をつかむ）

主成分分析は、身長・体重・血圧のようにたくさんの項目を持つデータから、「ばらつきが大きく、情報量の多い方向」を取り出す統計手法です。データの散らばりを表す行列（分散共分散行列）の固有ベクトルがその方向、固有値がその方向のばらつきの大きさを与えます。画像の圧縮やデータの可視化にも使われています。

考え出した人

固有値・固有ベクトルには特定の考案者はいません。回転する物体の主軸や天体の運動などを調べる研究の中で、オイラーやコーシーら多くの数学者の仕事を経て、少しずつ形になっていきました。

オーギュスタン＝ルイ・コーシー（1789年〜1857年）1829年の論文で、対称な行列（二次形式）の固有値にあたる値がすべて実数になることを示すなど、理論の基礎を築きました。

ダフィット・ヒルベルト（1862年〜1943年）1904年の積分方程式の研究で「固有値（Eigenwert）」という語を使い、この語が後に広まりました。

この解法を計算機で試す → 固有値・固有ベクトル 計算機：2×2行列の固有値と固有ベクトルを、固有方程式を解く手順で求めます。

関連項目

  • 行列式 ― 固有方程式は「行列式 ＝ 0」の方程式です。
  • 逆行列・掃き出し法 ― 固有ベクトルを求める連立方程式や、対角化の P−1 で使います。
  • 行列の積 ― A x ＝ λ x の左辺は行列とベクトルの積です。
