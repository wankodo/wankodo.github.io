行列のランクと線形独立

数学解法辞典 ― 線形代数（大学）

数学ツール集トップ ＞ 線形代数 ＞ 行列のランクと線形独立

大学 線形代数 計算機あり

どんな時に使えるか連立方程式に解があるか、解が1つに決まるかを判定するのがランクである。センサーが何台あっても実質何個分の情報しかないか、データの実質的な次元を見抜く場面でも使われる。

どんな問題に使うか

行列に対して「中身の情報が実質何行分（何列分）あるか」を数えるのがランク（階数）です。行列の行や列の中に、他の行や列の定数倍や和で作れてしまう「重複」があれば、その分だけランクは小さくなります。

  • 連立方程式に解があるか、解が1つに決まるか、無数にあるかを判定する問題
  • ベクトルの組が線形独立か線形従属かを判定する問題
  • 行列が逆行列を持つか（正則か）を判定する問題
  • データの表が実質何次元の情報を持っているかを見抜く問題

ベクトルの組について、どれか1本が他のベクトルの組み合わせで表せるとき、その組は線形従属、1本も表せないとき線形独立といいます。ランクはこの独立な本数の最大値と一致します。

公式・考え方

ランク ＝ 行基本変形で作った階段形の、0でない行の数（＝ピボットの数）

行基本変形はランクを変えない：行の入れ替え、行の定数倍（0倍を除く）、ある行に別の行の定数倍を加える操作では、行同士の「重複の関係」は変わりません。だから自由に変形して、左下が0ばかりの階段形に持ち込めます。

線形独立・従属との関係：n 本のベクトルを列に並べた行列のランクが n なら、その組は線形独立です。ランクが n より小さければ線形従属で、少なくとも1本は他のベクトルの組み合わせで表せます。

連立方程式との関係：係数行列のランクと、定数項まで含めた拡大係数行列のランクが一致すれば解があり、さらにランクが未知数の個数と一致すれば解は1つに決まります。2つのランクが食い違えば、解はありません。

解き方の手順

  1. 判定したいベクトルを列に並べて行列を作る。連立方程式なら係数行列（必要なら拡大係数行列）を用意します。
  2. ガウス消去（掃き出し法）で階段形にする。左の列から順に、ピボット（基準になる0でない成分）を選び、その下の成分を「行に別の行の定数倍を加える」操作で0にしていきます。ピボット候補が0のときは下の行と入れ替えます。
  3. 0でない行の数を数える。それがランクです。ピボットの数がそのままランクになります。
  4. 結論を読み取る。ランクがベクトルの本数と一致すれば線形独立、小さければ線形従属です。連立方程式では、係数行列と拡大係数行列のランクを比べて解の有無と個数を判定します。

例題

問題：ベクトル (1, 2, 3)、(2, 4, 6)、(1, 0, 1) を列に並べた行列のランクを求め、この3本が線形独立か線形従属かを判定せよ。

答えと解説を見る

行列は1行目が (1, 2, 1)、2行目が (2, 4, 0)、3行目が (3, 6, 1) です。行基本変形で階段形にします。

  1. 2行目から1行目の2倍を引くと (0, 0, −2)、3行目から1行目の3倍を引くと (0, 0, −2) になる。
  2. 3行目から2行目を引くと (0, 0, 0) になり、3行目はすべて0になる。
  3. 0でない行は2行だけなので、ピボットは2個。

答え：ランク2。2本目のベクトル (2, 4, 6) は1本目 (1, 2, 3) の2倍なので従属であり、この3本は線形従属です。3本あっても実質2本分の情報しかない、というのがランク2の意味です。

現場での使われ方

連立方程式の解の判定と制御工学

大規模な連立方程式を解く前に、解があるか・1つに決まるかをランクで判定するのは数値計算の基本です。制御工学では、システムの状態をどれだけ観測・制御できるか（可観測性・可制御性）を、行列のランクで判定します。ランクが不足していれば、センサーや操作量をいくら増やしても届かない状態がある、という設計上の警告になります。

センサーの実質的な情報量

温度・圧力・加速度など多数のセンサーを並べても、互いに強く連動して動くセンサー同士は実質1台分の情報しか持ちません。各センサーの時系列を並べた行列のランク（の近似）を見れば、「見かけの台数」と「実質の情報の個数」の差が分かります。冗長なセンサーの削減や、故障で情報が欠けていないかの確認に使われます。

データの実質的な次元と圧縮

大量の変数を持つデータでも、ランクが小さければデータは低次元の構造の上に乗っています。この考え方は、特異値分解（SVD）による画像圧縮や、推薦システムの「行列の欠けた部分を埋める」処理（行列補完）の土台です。ユーザーの評価行列を低ランクで近似することで、まだ見ていない作品への評価を予測します。

考え出した人

ゲオルク・フロベニウス（1849〜1917、ドイツの数学者）

階数（ランク）の概念と用語は、ゲオルク・フロベニウス（1849〜1917、ドイツの数学者）が1879年に導入しました。行列式の理論を整理する中で、行列の「実質の大きさ」を測る量として階数を定義したのです。線形独立・従属の考え方は、19世紀に線形代数が形作られていく中で確立したもので、特定の1人の発明ではありません。ベクトルや行列の言葉が整うにつれて、多くの数学者の手で少しずつ明確になっていきました。
