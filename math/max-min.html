高校 関数

どんな時に使えるか 限られた予算や材料で、囲える面積や得られる利益をいちばん大きくしたいとき、二次関数の頂点と区間の端を比べる最大・最小の考え方が使われる。条件の中でいちばんよい答えを探す最適化の入口になる考え方。

どんな問題に使うか

関数の最大・最小は、決められた範囲（定義域）の中で、関数の値がいちばん大きく・小さくなる点とその値を求める解法です。

  • 定義域（例：0 ≦ x ≦ 3）が付いた二次関数の最大値・最小値を求める問題
  • 長さや個数に制限がある条件で、面積や量を最大にする問題
  • 頂点が定義域の外にあるため、答えが端点になる問題

公式・考え方

二次関数 y ＝ a(x − p)2 ＋ q の頂点は (p, q) です。定義域つきでは、次の3つを比べて最大・最小を決めます。

  • 頂点が定義域の中にある場合：a ＞ 0 なら頂点で最小、a ＜ 0 なら頂点で最大になります。
  • 頂点が定義域の外にある場合：最大・最小はどちらも定義域の端点で起こります。
  • 頂点と反対側の最大・最小：頂点から遠い方の端点で起こります。軸からの距離で比べます。

軸の位置と定義域の関係で場合分けするのが、この解法の中心です。

解き方の手順

  1. 平方完成して、頂点と軸を求める。y ＝ a(x − p)2 ＋ q の形にします。
  2. 頂点が定義域の中か外かを確認する。これが場合分けの分かれ目です。
  3. 候補の値を計算する。頂点の値（定義域内の場合）と、両端点の値を出します。
  4. 比べて最大・最小を決める。値だけでなく、そのときの x も答えます。

例題

問題：長さ12mのロープで長方形の花壇を囲む。面積がいちばん大きくなるのは、縦・横が何mのときで、面積は何m2 か。

答えと解説を見る
  1. 縦を x m とすると、横は (6 − x) m（縦＋横がロープの半分12 ÷ 2 ＝ 6m）。定義域は 0 ＜ x ＜ 6。
  2. 面積 S ＝ x(6 − x) ＝ −x2 ＋ 6x。
  3. 平方完成する：S ＝ −(x − 3)2 ＋ 9。頂点は x ＝ 3 で、定義域の中にある。
  4. 上に開く向き（a ＝ −1 ＜ 0）なので、頂点で最大になる。最大値は 9。

答え：縦・横とも3m（正方形）のとき、面積は最大で 9m2。

現場での使われ方

限られた材料で最大の効果を出す最適化

決まった長さの材料で囲える面積を最大にする、決まった予算の中で効果を最大にするなど、「制限の中でいちばんよい答え」を探すのが最適化です。量が二次式で表せる場面では、頂点と端点を比べる最大・最小の考え方がそのまま使えます。

利益を最大にする量や価格の検討

販売量や価格と利益の関係が二次式で近似できる場面では、頂点が利益最大の目安になります。ただし実際の販売には定義域にあたる制限（在庫や営業時間など）があるため、端点との比較も欠かせません。

考え出した人

ピエール・ド・フェルマー（1607〜1665。生年には1601年説もあり、諸説あります）1636年頃、関数の最大・最小を求める方法を考案しました。後の微分の考え方の先駆けにあたる方法です。

ただし、正直に言うと、このページで扱う高校範囲の最大・最小はフェルマーの方法そのものではありません。微分を使わず、平方完成で頂点を求め、定義域の端点と比べる方法です。「制限の中でいちばんよい答えを探す」という問題意識は、フェルマー以前の古代からありました。

この解法を計算機で試す → 関数の最大・最小 計算機：二次関数と定義域を入れると、頂点と端点を比べて最大値・最小値を求めます。
