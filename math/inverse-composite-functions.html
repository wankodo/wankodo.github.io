高校 関数 計算機あり

どんな時に使えるか逆関数は、摂氏と華氏の換算やデータの正規化と復元、暗号化と復号のように「元に戻せる変換」を扱うときに使う考え方で、分数関数は酵素反応の速度（ミカエリス・メンテン式）のように「増えるがやがて飽和する」量のモデルになる。

どんな問題に使うか

分母に x を含む分数関数、根号の中に x を含む無理関数、そして関数を「逆向きにたどる」逆関数と、関数を「つなげる」合成関数を扱う単元です。次のような手がかりがあったら出番です。

  • 分数関数のグラフをかく問題（漸近線がどこにあるかを先に調べる）
  • 無理関数で、根号の中が0以上になる範囲（定義域）を求める問題
  • 「x と y を入れ替えて解く」逆関数を求める問題、逆関数の存在を判定する問題
  • f(g(x)) のように関数を合成する問題、合成の順序で結果が変わることを確かめる問題

公式・考え方

y ＝ (a x ＋ b)／(c x ＋ d) の漸近線は x ＝ −d／c、y ＝ a／c

分数関数のグラフは双曲線で、分母が0になる x の値が縦の漸近線、x を限りなく大きくしたときに近づく値が横の漸近線になります。定義域は「分母≠0」の範囲、値域は「横の漸近線の値以外」です。

無理関数（例：y ＝ √(x−1)）では、根号の中は0以上でなければならないので、定義域は x ≧ 1 のように制限されます。値域も根号の性質（0以上）から決まります。

逆関数は、元の関数の x と y を入れ替えて y について解いたものです。グラフは直線 y ＝ x に関して元のグラフと線対称になります。逆関数が存在するのは、元の関数が1対1（単調に増加、または単調に減少）で、入力と出力が一通りずつ対応するときだけです。

合成関数 (f∘g)(x) ＝ f(g(x)) は「先に g を計算し、その結果を f に入れる」操作です。一般に f∘g と g∘f は異なるので、順序に注意します。

解き方の手順

  1. 分数関数は、まず分母＝0となる x を外す（定義域）。その x が縦の漸近線、a／c が横の漸近線です。
  2. 無理関数は、根号の中 ≧ 0 を解いて定義域を決める。グラフは定義域の端点から始まります。
  3. 逆関数は、x と y を入れ替えて y について解く。解いた式が元の定義域を値域として持ちます。1対1でない関数は逆関数を持ちません。
  4. 合成関数は、内側の関数の結果を外側へ代入する。(f∘g)(x) なら g(x) を先に計算します。

例題

問題：f(x) ＝ (x＋1)／(x−2) の逆関数を求めよ。

答えと解説を見る

y ＝ (x＋1)／(x−2) とおき、x と y を入れ替えます。

  1. 入れ替え：x ＝ (y＋1)／(y−2)
  2. 両辺に (y−2) をかける：x(y−2) ＝ y＋1、つまり x y − 2x ＝ y ＋ 1
  3. y の項を左辺へ集める：x y − y ＝ 2x ＋ 1、つまり y(x−1) ＝ 2x ＋ 1
  4. y について解く：y ＝ (2x＋1)／(x−1)

答え：逆関数は y ＝ (2x＋1)／(x−1)（定義域は x ≠ 1）。検算として元の関数に代入すると x に戻ることが確認できます。

現場での使われ方

変換とその逆変換

摂氏と華氏の換算は、片方がもう一方の逆関数です。データ分析で値を0〜1にそろえる正規化と、計算後に元の単位へ戻す復元も同じ組です。暗号化と復号も「変換と、その逆変換」の組であり、元に戻せる変換はすべて逆関数の考え方で整理できます。

飽和する量のモデル

酵素反応の速度を表すミカエリス・メンテン式は分数関数の形をしており、基質を増やすほど反応速度は上がりますが、ある上限に近づいて飽和します。広告費と効果の関係のように「増えるが頭打ちになる」量のモデルとして、分数関数は現場で広く使われます。
