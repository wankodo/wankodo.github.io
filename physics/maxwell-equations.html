物理の解法辞典 ― 電磁気（大学）

大学 電磁気

どんな時に使えるか 電場と磁場に関する法則を4つの式にまとめたのがマクスウェル方程式です。電荷が電場を作ること、磁荷が単独で存在しないこと、磁場の変化が電場を作ること、電流と電場の変化が磁場を作ることを表し、この4式から電磁波の存在と、その速さが光速に一致することが導かれます。

どんな問題に使うか

高校までに学ぶ電磁気の法則（クーロンの法則、電磁誘導、アンペールの法則など）を、1つの体系として統一して理解するための項目です。

  • 4つの式がそれぞれどの法則に対応し、何を主張しているかを説明する問題
  • 真空中で電磁波が伝わる速さを、真空の誘電率 ε0 と真空の透磁率 μ0 から計算する問題
  • 変位電流がなぜ必要だったのか（充電中のコンデンサーなど）を説明する問題
  • 「光は電磁波の一種である」ことの根拠を述べる問題

式の形は積分形で示します。微分形（∇・や ∇× を使う形）も同じ内容を、空間の各点での言葉で書き直したものです。

公式・考え方

使う定数は、真空の誘電率 ε0 ＝ 8.85×10−12 C2/(N・m2)、真空の透磁率 μ0 ＝ 4π×10−7 N/A2 です。電場を E [N/C または V/m]、磁場（磁束密度）を B [T] とします。

第1式：電場のガウスの法則

∮ E・dS ＝ Q / ε0

閉じた面を貫いて出ていく電場の総量は、その面の中にある電荷 Q の合計で決まる、という式です。意味は「電場は電荷から湧き出す」。電場の「出発点」は正の電荷、「到着点」は負の電荷で、クーロンの法則を空間の言葉で言い直したものにあたります。

第2式：磁場のガウスの法則

∮ B・dS ＝ 0

閉じた面を貫く磁場の総量は、正味でいつも 0、という式です。意味は「磁場には出発点（磁荷）が単独では存在しない」。磁石を割ってもN極だけを取り出せないことに対応し、磁力線は必ず閉じた輪になります。

第3式：ファラデーの電磁誘導の法則

∮ E・dl ＝ − dΦB / dt

回路を1周したときの電場のはたらき（起電力）は、その回路を貫く磁束 ΦB の変化率に等しい（向きは変化を打ち消す向き）、という式です。意味は「磁場の変化が電場を作る」。発電機の原理そのものです。

第4式：アンペール・マクスウェルの法則

∮ B・dl ＝ μ0 I ＋ μ0ε0 (dΦE / dt)

回路を1周したときの磁場は、その回路を貫く電流 I と、電場の変化（第2項）で決まる、という式です。意味は「電流と、電場の変化が、磁場を作る」。第2項がマクスウェルの追加した部分で、この電場の変化が作る磁場の効果を変位電流といいます。

変位電流と電磁波の予言

充電中のコンデンサーでは、導線には電流が流れても、極板の間には電流が流れません。ところが極板の間では電場が変化しています。マクスウェルは「電場の変化も電流と同じように磁場を作る」と考えて第4式に第2項を加え、つじつまを合わせました。

すると、電荷も電流もない真空中でも、「磁場の変化→電場」「電場の変化→磁場」が互いに相手を作り続ける波、すなわち電磁波が存在できることが4式から導かれます。その速さは次のように ε0 と μ0 だけで決まります。

c ＝ 1 / √(ε0μ0)

この値は当時知られていた光の速さと一致しました。これが「光は電磁波の一種である」という結論の根拠です。

解き方の手順

  1. どの式の話かを見分ける。電荷と電場なら第1式、磁荷の不存在なら第2式、磁場の変化と起電力なら第3式、電流・電場の変化と磁場なら第4式です。
  2. 式を「何が何を作るか」の文に翻訳する。左辺が結果（場の総量や1周分のはたらき）、右辺が原因（電荷・電流・場の変化）です。
  3. 光速の計算では、まず μ0 ＝ 4π×10−7 を数値に直し、ε0μ0 の積、平方根、逆数の順に計算する。指数の計算を一段ずつ進めるのが確実です。
  4. 得られた値が光速 3.00×108 m/s と一致するか確認する。一致が、電磁波＝光という結論の検算になります。

例題

問題：ε0 ＝ 8.85×10−12 C2/(N・m2)、μ0 ＝ 4π×10−7 N/A2 を使って、c ＝ 1/√(ε0μ0) の値を求め、光速 3.00×108 m/s と比べよ。

答えと解説を見る
  1. μ0 ＝ 4π×10−7 ≒ 1.257×10−6 N/A2 です。
  2. 積は ε0μ0 ＝ 8.85×10−12 × 1.257×10−6 ≒ 1.112×10−17 s2/m2。
  3. 平方根は √(1.112×10−17) ≒ 3.335×10−9 s/m。
  4. 逆数をとると c ＝ 1 / (3.335×10−9) ≒ 2.999×108 ≒ 3.00×108 m/s。

答え：c ≒ 3.00×108 m/s で、光速と一致する。電気の定数（ε0）と磁気の定数（μ0）だけから光の速さが出てくることが、光が電磁波であることの強い証拠になりました。

現場での使われ方

電波と無線通信の設計

ラジオ・テレビ・携帯電話・Wi-Fi などの電波はすべて電磁波で、その伝わり方はマクスウェル方程式そのものが支配しています。アンテナの形や長さの設計、電波が建物で反射・回折する様子の予測計算は、この4式をコンピュータで解く電磁界シミュレーションによって行われています。

モーター・発電機・変圧器の設計

第3式の電磁誘導と第4式の「電流が磁場を作る」は、モーター、発電機、変圧器の動作原理です。これらの機器の磁気回路の設計でも、材料中の電磁場の計算の土台はマクスウェル方程式です。

光ファイバーとレーザー

光も電磁波なので、光ファイバーの中を光がどう伝わるか、レンズや反射でどう進むかの精密な計算は、幾何光学で足りない場面ではマクスウェル方程式に基づく波動光学で扱われます。

考え出した人

ジェームズ・クラーク・マクスウェル（1831〜1879、スコットランドの物理学者）

まとめたのはスコットランドの物理学者ジェームズ・クラーク・マクスウェル（1831〜1879）です。ファラデーの「力線」の直観やアンペールの法則など、先人の法則を数学の式に整え、1865年の論文で変位電流の項を加えた完全な形を発表しました。電磁波の存在は式からの予言でしたが、1888年にハインリヒ・ヘルツが火花放電の実験で電磁波を実際に発生・検出し、予言が証明されました。単位 Hz はヘルツの名に由来します。
