数学ツール集トップ ＞ 数と式 ＞ 一次不定方程式

高校 数と式 計算機あり

どんな時に使えるか硬貨や切手の組み合わせで合計金額をぴったり作ったり、荷物の積み合わせで重さや容量をぴったり満たす個数の組み合わせを探したりするときに使う。2種類の数量の合計をちょうど目標値にする、実務の「ぴったり合わせ」の一般形である。

どんな問題に使うか

未知数が2つあるのに式が1つしかない方程式 a x ＋ b y ＝ c で、解を整数に限る問題です。「不定」は解が1つに定まらないという意味ですが、整数という条件を付けると、解は規則正しく並んだ組み合わせだけに絞られます。

  • 「○円の品物と△円の品物を合わせてちょうど□円にする買い方は何通りか」という金額合わせの問題
  • 2種類の箱や袋で、総個数や総重量をちょうど目標値にする組み合わせの問題
  • a x ＋ b y ＝ c の整数解をすべて（一般解の形で）求める問題
  • 解があるかどうか自体を判定する問題（最大公約数がカギになる）

実数の範囲では解は無数にありますが、整数解は「あるかないか」がまず問題になり、ある場合は等間隔に並びます。その構造を読み解くのがこの解法です。

公式・考え方

a x ＋ b y ＝ c　（d ＝ gcd(a, b)）

解がある条件：c が d で割り切れること。a x ＋ b y は常に d の倍数になるので、c が d の倍数でなければ整数解は1つもありません。逆に、割り切れれば解は必ずあります。

特殊解と一般解：まず解を1つ（特殊解 x0, y0）見つけます。するとすべての解は

x ＝ x0 ＋ (b/d) k，　y ＝ y0 − (a/d) k　（k は整数）

の形に書けます。x を (b/d) 増やすと a x は a(b/d) 増え、y を (a/d) 減らすと b y はちょうど同じだけ減るので、合計が変わらない、という仕組みです。

特殊解の見つけ方：拡張ユークリッドの互除法を使います。通常の互除法の割り算を逆にたどると、a x ＋ b y ＝ d を満たす x, y が機械的に求まります。あとは両辺を c/d 倍すれば、求める方程式の特殊解になります。

解き方の手順

  1. d ＝ gcd(a, b) を求め、c が d で割り切れるか確認する。割り切れなければ「整数解なし」で終了です。
  2. 拡張ユークリッドの互除法で a x ＋ b y ＝ d の解を1つ求める。互除法の各割り算を記録し、余り＝割る数−商×割られる数の形で逆向きに代入していく。
  3. 両辺を c/d 倍して、もとの方程式の特殊解 (x0, y0) を得る。
  4. 一般解 x ＝ x0 ＋ (b/d)k，y ＝ y0 − (a/d)k を書く。
  5. 個数や金額など x, y ≧ 0 の条件がある場合は、その範囲に入る k を絞り込む。x が 0 以上で最小になる解もここで見つかります。

例題

問題：7個入りの箱と11個入りの箱を使って、ちょうど100個を出荷したい。7個入りの箱を x 箱、11個入りの箱を y 箱とするとき、組み合わせをすべて求めよ。

答えと解説を見る

式は 7x ＋ 11y ＝ 100 です。d ＝ gcd(7, 11) ＝ 1 で、100 は 1 で割り切れるので解があります。

  1. 7x ＋ 11y ＝ 1 の解を1つ探す：7×(−3) ＋ 11×2 ＝ −21 ＋ 22 ＝ 1 なので、(−3, 2) が解。
  2. 両辺を100倍すると特殊解は (−300, 200)。
  3. 一般解は x ＝ −300 ＋ 11k，y ＝ 200 − 7k。
  4. x ≧ 0 となるのは k ≧ 28（x ＝ 8）のとき、y ≧ 0 となるのは k ≦ 28 のとき。よって k ＝ 28 のみ。

答え：7個入りの箱が8箱、11個入りの箱が4箱（検算：7×8 ＋ 11×4 ＝ 56 ＋ 44 ＝ 100）。組み合わせはこの1通りだけです。

現場での使われ方

硬貨・切手の金額合わせ

「50円切手と80円切手でちょうど○○円分買う」といった問題は、まさに一次不定方程式です。自動販売機や両替機の設計、郵便料金の組み合わせ計算でも、合計をぴったり作れる組み合わせがあるかをこの形で判定します。

荷物の積み合わせ

トラックやコンテナに2種類の荷物を積むとき、総重量や容量の上限をぴったり満たす個数の組み合わせを探す問題も同じ形になります。切り捨てや端数を出さずに積み切る計画を立てる場面で使われます。

暗号・計算機科学の土台

特殊解を求める拡張ユークリッドの互除法は、RSA暗号で秘密鍵を求める計算（法のもとでの逆元計算）にもそのまま使われています。高校のこの単元が、現代の暗号技術の入口になっています。

考え出した人

ディオファントス（3世紀頃）アレクサンドリアの数学者で、著書『算術』で整数解を求める問題を数多く扱ったことから、この種の方程式は「ディオファントス方程式」とも呼ばれます。互除法そのものはユークリッド（紀元前3世紀頃）の『原論』に記された方法で、それを逆にたどって解を組み立てるのが拡張ユークリッドの互除法です。またインドのアーリヤバタ（476〜550）も、同じ問題を解く「粉砕法（クッタカ）」を独自に編み出していました。

この解法を計算機で試す →一次不定方程式 計算機：a、b、c を入れると、拡張ユークリッドの互除法の手順つきで特殊解と一般解を計算します。
