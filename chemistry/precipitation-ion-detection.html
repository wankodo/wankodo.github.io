沈殿反応とイオンの検出

化学の考え方辞典 ― 無機化学（高校化学・3年）

化学ツール集トップ ＞ 無機化学 ＞ 沈殿反応とイオンの検出

高校化学・3年 無機化学

どんな時に使えるか 水溶液に特定の試薬を加えたときに生じる沈殿の色や、酸・アルカリ・アンモニア水への溶け方を手がかりに、溶液に含まれるイオンの種類を見分けるときに使う。塩化銀の白色、ヨウ化銀の黄色、水酸化鉄（III）の赤褐色のように沈殿ごとに決まった色があり、白色どうしでも熱水や過剰の試薬で溶けるかどうかを組み合わせると、ハロゲン化物イオンや硫酸イオン、金属イオンを区別できる。

どんな問題に使うか

水に溶けにくい塩や水酸化物が固体として析出する沈殿反応を、イオンの種類を調べる手がかりとして使う考え方です。次のような場面で使います。

  • 未知の水溶液に試薬を加えた結果（沈殿の有無と色）から、含まれているイオンを判定する問題
  • 塩化物イオン・臭化物イオン・ヨウ化イオンのように、似た沈殿を作るイオンどうしを区別する問題
  • 白色沈殿どうしを、熱水・酸・過剰の水酸化ナトリウム水溶液やアンモニア水で溶けるかどうかで見分ける問題
  • 複数のイオンが混ざった溶液を、沈殿反応を組み合わせて分離・確認する問題（陽イオンの系統分析への入口）

ポイントは、「どの試薬で沈殿するか」「沈殿の色は何か」「その沈殿が何に溶けるか」の3点をセットで見ることです。色だけでは白色どうしが区別できず、溶け方だけでも決め手に欠けます。3点を組み合わせることで判定が一通りに絞られます。沈殿が生じるかどうかを溶解度積 Ksp で数値的に予測する考え方は溶解平衡と溶解度積で扱っています。

公式・考え方

沈殿反応は、水溶液中でイオンどうしが結びついて、水に溶けにくい（難溶性の）化合物を作る反応です。たとえば銀イオンと塩化物イオンでは、次のように書けます。

Ag+ ＋ Cl− → AgCl ↓（白色沈殿）

各記号の意味は次の通りです。

  • Ag+、Cl−：水溶液中に電離して存在するイオン。右上の数字と符号はイオンの電荷を表す
  • AgCl：難溶性の塩。生成物の化学式で、溶けずに固体として析出する
  • ↓：沈殿が生じることを示す記号

代表的な沈殿と色（銀・バリウム・カルシウム・鉛の塩）

  • 塩化銀 AgCl：白色。アンモニア水に溶けてジアンミン銀（I）イオン [Ag(NH3)2]+ になる
  • 臭化銀 AgBr：淡黄色。ハロゲン化銀はいずれも光で分解しやすく、写真感光材料に使われてきた
  • ヨウ化銀 AgI：黄色。アンモニア水にも溶けないため、AgCl との区別に使える
  • 硫酸バリウム BaSO4：白色。水にも希塩酸にも溶けないことが、他のバリウム塩との決定的な違い
  • 炭酸バリウム BaCO3：白色。ただし希塩酸に二酸化炭素を発生しながら溶けるので、BaSO4 と区別できる
  • 炭酸カルシウム CaCO3：白色。希塩酸に二酸化炭素を発生しながら溶ける。大理石や石灰石の主成分
  • 塩化鉛（II） PbCl2：白色。冷水には溶けにくいが熱水には溶けるという、白色沈殿の中では目立つ特徴をもつ。冷やすと再び析出する
  • ヨウ化鉛（II） PbI2：黄色

代表的な沈殿と色（金属の水酸化物）

金属イオンを含む水溶液に水酸化ナトリウム水溶液やアンモニア水を加えると、多くの場合その金属の水酸化物が沈殿します。

  • 水酸化銅（II） Cu(OH)2：青白色（淡青色）。Cu2+ を含む溶液に塩基を加えると生じる。過剰のアンモニア水には溶けて、テトラアンミン銅（II）イオン [Cu(NH3)4]2+ の深い青色の溶液になる
  • 水酸化鉄（III） Fe(OH)3：赤褐色。Fe3+ の検出で最も目立つ色
  • 水酸化鉄（II） Fe(OH)2：淡緑色（緑白色）。空気中の酸素で酸化されやすく、しだいに赤褐色の Fe(OH)3 に変わる。Fe2+ と Fe3+ はこの色の違いで区別できる
  • 水酸化亜鉛 Zn(OH)2：白色。両性水酸化物で、過剰の水酸化ナトリウム水溶液にも、過剰のアンモニア水にも溶ける（アンモニア水ではテトラアンミン亜鉛（II）イオン [Zn(NH3)4]2+ になる）
  • 水酸化アルミニウム Al(OH)3：白色。両性水酸化物で過剰の水酸化ナトリウム水溶液には溶けるが、過剰のアンモニア水には溶けない。この点が Zn(OH)2 との区別になる
  • 水酸化マグネシウム Mg(OH)2：白色。過剰の水酸化ナトリウム水溶液には溶けない

なお、Ag+ を含む溶液に水酸化ナトリウム水溶液を加えると、生じるのは水酸化銀ではなく褐色の酸化銀 Ag2O の沈殿です。銀は「水酸化物の色」で覚える対象ではない点に注意します。

ハロゲン化物イオンの検出（硝酸銀水溶液）

Cl−・Br−・I− の検出には硝酸銀 AgNO3 水溶液を使います。手順の考え方は次の通りです。

  • 先に希硝酸で酸性にする：試料に炭酸イオン CO32− が含まれていると、Ag+ と炭酸銀の沈殿を作って判定を邪魔します。希硝酸で酸性にすると CO32− は二酸化炭素として追い出され、邪魔がなくなります
  • 酸性にするのに塩酸は使わない：塩酸は Cl− そのものを含むため、もとの試料に Cl− がなくても AgCl の白色沈殿が出てしまいます（誤判定のもと）。だから酸には硝酸を使います
  • 沈殿の色で判定する：白色なら Cl−（AgCl）、淡黄色なら Br−（AgBr）、黄色なら I−（AgI）
  • アンモニア水で確かめる：AgCl はアンモニア水に溶けますが、AgI は溶けません。白色か黄色かで迷う場合の追加の手がかりになります
Ag+ ＋ Br− → AgBr ↓（淡黄色）／ Ag+ ＋ I− → AgI ↓（黄色）

硫酸イオンの検出（塩化バリウム水溶液）

SO42− の検出には塩化バリウム BaCl2 水溶液を使います。

Ba2+ ＋ SO42− → BaSO4 ↓（白色）

ここでも順序が大切です。試料を先に希塩酸で酸性にしてから BaCl2 水溶液を加えます。CO32− が含まれていると BaCO3 の白色沈殿も出ますが、BaCO3 は酸に溶けるのに対し、BaSO4 は酸性にしても溶けずに残ります。「酸性にしたうえで白色沈殿が残る」ことが SO42− の判定条件です。逆に、炭酸イオンの検出は、試料に希塩酸を加えて発生する気体（二酸化炭素）を石灰水に通し、石灰水が CaCO3 の生成で白く濁ることで確認します。

解き方の手順

  1. 加えた試薬から、候補の沈殿を挙げる。AgNO3 ならハロゲン化銀、BaCl2 なら BaSO4 や BaCO3、NaOH や NH3 水なら金属の水酸化物、というように、試薬ごとに起こりうる沈殿は限られます。
  2. 沈殿の色と照合する。白色・淡黄色・黄色・青白色・赤褐色・淡緑色など、観察された色と代表的な沈殿の対応を確認します。
  3. 溶け方で絞り込む。白色どうしは色では決着しません。熱水に溶けるか（PbCl2）、酸に溶けるか（BaCO3 は溶ける、BaSO4 は溶けない）、過剰の NaOH で溶けるか（両性の Zn(OH)2、Al(OH)3）、過剰の NH3 水で溶けるか（Zn(OH)2 は溶ける、Al(OH)3 は溶けない）を追加で確認します。
  4. 邪魔をするイオンを先に除いたか確認する。ハロゲン化物イオンの検出では希硝酸で CO32− を、硫酸イオンの検出では希塩酸で CO32− を先に処理しているかが、手順の正しさを左右します。
  5. 反応をイオン反応式で書き、判定を結論づける。「試薬→沈殿の化学式と色→溶け方」の根拠をそろえて、含まれているイオンを答えます。

例題

問題1：無色の水溶液 A に希硝酸を加えて酸性にしてから硝酸銀水溶液を加えると、白色沈殿が生じた。この沈殿にアンモニア水を加えると溶けた。水溶液 A に含まれていた陰イオンは何か。問題2：無色の水溶液 B に希塩酸を加えて酸性にしてから塩化バリウム水溶液を加えると、白色沈殿が生じ、酸性にしても溶けなかった。水溶液 B に含まれていた陰イオンは何か。問題3：青色の水溶液 C に水酸化ナトリウム水溶液を少量加えると青白色の沈殿が生じ、代わりにアンモニア水を過剰に加えると沈殿は溶けて深い青色の溶液になった。水溶液 C に含まれていた陽イオンは何か。問題4：無色の水溶液 D に水酸化ナトリウム水溶液を加えると白色沈殿が生じ、過剰に加えると溶けた。別の試料にアンモニア水を加えても白色沈殿が生じたが、過剰に加えても溶けなかった。水溶液 D に含まれていた陽イオンは Zn2+ と Al3+ のどちらか。

答えと解説を見る
  1. 問題1：希硝酸で酸性にしてあるので、炭酸イオンによる沈殿の邪魔は除かれています。Ag+ と白色沈殿を作るのは Cl− で、沈殿は AgCl です。アンモニア水に溶けることも AgCl の性質と一致します。よって陰イオンは塩化物イオン Cl−です（Ag+ ＋ Cl− → AgCl ↓）。
  2. 問題2：Ba2+ と白色沈殿を作る陰イオンには SO42− と CO32− がありますが、BaCO3 は酸に溶け、BaSO4 は酸に溶けません。酸性でも溶けずに残ったので沈殿は BaSO4 で、陰イオンは硫酸イオン SO42−です（Ba2+ ＋ SO42− → BaSO4 ↓）。
  3. 問題3：青白色の沈殿は水酸化銅（II） Cu(OH)2 です。過剰のアンモニア水で溶けて深い青色になるのは、テトラアンミン銅（II）イオン [Cu(NH3)4]2+ の生成によるもので、もとの溶液が青色だったこととも一致します。よって陽イオンは銅（II）イオン Cu2+です。
  4. 問題4：白色沈殿が過剰の NaOH で溶ける点は、両性水酸化物である Zn(OH)2 と Al(OH)3 のどちらとも一致します。決め手はアンモニア水で、Zn(OH)2 は過剰のアンモニア水に溶けますが、Al(OH)3 は溶けません。溶けなかったので沈殿は Al(OH)3 で、陽イオンはアルミニウムイオン Al3+です。

答え：問題1は Cl−、問題2は SO42−、問題3は Cu2+、問題4は Al3+。どの問題も「色」だけで決めず、「何に溶けるか（溶けないか）」まで確認して初めて判定が確定します。

現場での使われ方

水質分析での硫酸イオン・塩化物イオンの測定

水道水や環境水の分析では、硫酸イオンを塩化バリウムで硫酸バリウム BaSO4 として沈殿させ、その質量から量を求める重量分析が古典的な定量法として使われてきました。塩化物イオンについても、硝酸銀で塩化銀 AgCl を沈殿させる反応は、滴定による定量（モール法など）の土台になっています。検出の反応が、そのまま「量を測る」分析法につながっている例です。

工場排水の重金属除去（水酸化物沈殿法）

金属イオンを含む工場排水の処理では、水酸化ナトリウムなどで pH を上げ、重金属イオンを水酸化物の沈殿として析出させて取り除く方法が広く使われています。どの pH でどの金属が沈殿するかは水酸化物ごとの溶けにくさの違いに基づいており、この記事の「塩基を加えると水酸化物が沈殿する」という反応が、そのまま処理技術の原理になっています。亜鉛やアルミニウムのように両性の水酸化物は、アルカリを入れすぎると再び溶けてしまうため、pH の管理が重要になります。

写真感光材料とハロゲン化銀

フィルムや印画紙の感光材料には、臭化銀 AgBr を中心とするハロゲン化銀の微粒子が使われてきました。ハロゲン化銀は光が当たると分解して銀を生じる性質があり、この光への反応が写真の原理です。淡黄色の AgBr や黄色の AgI の色と光分解しやすさは、検出反応で覚える性質と地続きのものです。

医療用造影剤の硫酸バリウム

消化管の X 線検査で使われるバリウム造影剤は硫酸バリウム BaSO4 です。水にも酸にもほとんど溶けないため体内に吸収されず、X 線をよく吸収する性質だけを利用できます。「酸に溶けない白色沈殿」という検出上の特徴が、そのまま医療での安全性を支えています。詳しい数値の背景は溶解平衡と溶解度積を参照してください。

考え出した人

カール・レミギウス・フレゼニウス（1818〜1897、ドイツの分析化学者）

沈殿反応そのものは特定の誰かが発明したものではありませんが、試薬を決まった順序で加え、沈殿の生成と溶解を組み合わせてイオンを分離・確認する定性分析の体系をまとめたのが、ドイツの分析化学者カール・レミギウス・フレゼニウス（1818〜1897）です。フレゼニウスは1841年に定性分析の教科書を著し、陽イオンをグループごとに沈殿で分離していく系統分析の手順を確立しました。のちにヴィースバーデンに分析化学の研究所を開き、分析化学の専門誌も創刊しています。この記事の「試薬→色→溶け方」という判定の進め方や、次の項目の陽イオンの系統分析は、フレゼニウス以来の定性分析の枠組みを受け継いだものです。
