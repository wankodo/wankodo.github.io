酸化還元反応式の作り方

化学の考え方辞典 ― 酸化還元・電池と電気分解（高校化学基礎・1年）

化学ツール集トップ ＞ 酸化還元・電池と電気分解 ＞ 酸化還元反応式の作り方

高校化学基礎・1年 酸化還元・電池と電気分解 計算機あり

どんな時に使えるか 酸化還元反応式は、酸化剤と還元剤の半反応式を書き、受け渡しする電子の数が等しくなるよう最小公倍数でそろえて加えると、目算では合わせにくい係数も機械的に決まる。最後に対イオンを補って化学反応式に直し、原子の数と電荷の合計が両辺で一致するかを確認する。

どんな問題に使うか

酸化剤と還元剤が反応する酸化還元反応の反応式を完成させる解法です。次のような場面で使います。

  • 未完成のイオン反応式（例：MnO4− ＋ Fe2+ ＋ H+ → Mn2+ ＋ Fe3+ ＋ H2O）に係数をつけて完成させる問題
  • 過マンガン酸カリウムや二クロム酸カリウムなど、係数が大きくなる反応の化学反応式を書く問題
  • 酸化還元滴定の量的関係の前提として、反応する物質の mol 比（係数の比）を読み取る問題

通常の反応式なら、原子の数を目で見て合わせる目算法で足りることもあります。しかし酸化還元反応では、原子の数に加えて電荷（イオンの電気）も両辺でそろえなければならないうえ、係数が 5 や 6、16 のように大きくなることも珍しくありません。目算法では「原子は合ったのに電荷が合わない」「どこから手をつければよいか分からない」という行き詰まりが起こります。そこで使うのが、酸化と還元を別々に書いた半反応式を組み合わせる方法（半反応式法）です。電子の受け渡しを先にそろえてしまうので、残りの係数は自動的に決まります。

公式・考え方

酸化還元反応では、還元剤が放出した電子 e− を酸化剤がすべて受け取ります。電子が反応の途中で消えたり、ひとりでに増えたりすることはないので、次の関係が必ず成り立ちます。

酸化剤が受け取る電子の数 ＝ 還元剤が放出する電子の数

この等式がそのまま係数を決める鍵になります。半反応式どうしを何倍かして電子の数をそろえ、辺々を加えると電子が消えて、完成したイオン反応式が得られます。

  • 半反応式：酸化（電子を放出）または還元（電子を受け取る）だけを取り出して、電子 e− を含めて書いた式。作り方そのものは「酸化剤と還元剤・半反応式」の項目が正本
  • 電子 e−：電荷 −1 をもつ粒子として数える。半反応式では、原子の数だけでなく電荷の合計も両辺で一致していなければならない
  • イオン反応式：実際に反応するイオンだけを書いた式。反応しないイオン（対イオン）は含まない
  • 対イオン：反応するイオンと対になって化合物を作っているイオン（例：MnO4− に対する K+、H+ に対する SO42−）。イオン反応式を化学反応式に直すときに補う
  • 係数は最も簡単な整数比にする。電子の数をそろえる倍率は、2つの半反応式の電子数の最小公倍数から決める

通しの例：過マンガン酸カリウムと過酸化水素（硫酸酸性）

硫酸酸性の過マンガン酸カリウム KMnO4 水溶液に過酸化水素 H2O2 を加える反応を、手順に沿って通して作ります。まず半反応式を2つ書きます。過マンガン酸イオンは酸化剤、過酸化水素は還元剤として働きます。

MnO4− ＋ 8H+ ＋ 5e− → Mn2+ ＋ 4H2O　…①（還元）
H2O2 → O2 ＋ 2H+ ＋ 2e−　…②（酸化）

電子の数は①が5個、②が2個なので、最小公倍数10にそろえます。①×2、②×5 として辺々を加えると、両辺の 10e− が消えます。

2MnO4− ＋ 16H+ ＋ 5H2O2 → 2Mn2+ ＋ 8H2O ＋ 5O2 ＋ 10H+

両辺に共通する 10H+ を差し引くと、イオン反応式が完成します。

2MnO4− ＋ 5H2O2 ＋ 6H+ → 2Mn2+ ＋ 8H2O ＋ 5O2

検算します。原子は Mn が2個、O が左辺 8＋10 ＝ 18個・右辺 8＋10 ＝ 18個、H が左辺 10＋6 ＝ 16個・右辺 16個で一致。電荷は左辺 −2＋6 ＝ ＋4、右辺 ＋4 で一致しています。次に化学反応式へ直します。MnO4− の対イオンは K+ が2個、6H+ は硫酸 H2SO4 3個分なので対イオンは SO42− が3個です。この K+ 2個と SO42− 3個を両辺に補うと、右辺では K2SO4 1個と MnSO4 2個に組み合わさります。

2KMnO4 ＋ 5H2O2 ＋ 3H2SO4 → K2SO4 ＋ 2MnSO4 ＋ 8H2O ＋ 5O2

化学反応式でも検算します。K 2個、Mn 2個、S 3個、H は左辺 10＋6 ＝ 16個・右辺 16個、O は左辺 8＋10＋12 ＝ 30個・右辺 4＋8＋8＋10 ＝ 30個で、すべて一致しています。

解き方の手順

  1. 酸化剤と還元剤を見分け、それぞれの半反応式を書く。酸化数の変化から、どの物質が電子を受け取り、どの物質が放出するかを確認します。各半反応式の中で、原子の数と電荷の合計が両辺で一致していることも確かめます。
  2. 電子の数を最小公倍数でそろえる。2つの半反応式の電子数（例：5個と2個）の最小公倍数（10）をとり、各式を整数倍して、受け取る電子と放出する電子の数を等しくします。
  3. 辺々を加えて電子を消し、イオン反応式を作る。両辺に同じイオンや分子（H+ や H2O など）が現れたら、差し引いて簡単な形にします。
  4. 対イオンを補って化学反応式に直す。反応したイオンと対になるイオン（K+、Na+、SO42− など）を両辺に同じ数だけ足し、化合物の形に組み合わせます。酸性条件の H+ は、加えた酸（硫酸など）の形で左辺に書きます。
  5. 最終確認をする。すべての原子の数が両辺で一致すること、電荷の合計が両辺で一致すること（化学反応式では両辺とも電荷の合計は0）、係数が最も簡単な整数比になっていることを確かめます。

例題

問題1：硫酸酸性の条件で、過マンガン酸イオンと鉄(II)イオンの反応 MnO4− ＋ Fe2+ ＋ H+ → Mn2+ ＋ Fe3+ ＋ H2O の係数を合わせ、イオン反応式を完成させよ。

答えと解説を見る
  1. 半反応式は、還元が MnO4− ＋ 8H+ ＋ 5e− → Mn2+ ＋ 4H2O、酸化が Fe2+ → Fe3+ ＋ e− です。
  2. 電子の数を5個にそろえるため、酸化の式を5倍して加えると、5e− が消えます。
  3. 検算：原子は Mn 1個、Fe 5個、O 4個、H 8個で両辺一致。電荷は左辺 −1＋10＋8 ＝ ＋17、右辺 2＋15 ＝ ＋17 で一致します。

答え：MnO4− ＋ 5Fe2+ ＋ 8H+ → Mn2+ ＋ 5Fe3+ ＋ 4H2O

問題2：硫酸酸性の二クロム酸カリウム K2Cr2O7 と硫酸鉄(II) FeSO4 の反応について、半反応式から化学反応式を完成させよ（生成物は硫酸カリウム、硫酸クロム(III)、硫酸鉄(III)、水とする）。

答えと解説を見る
  1. 半反応式は、還元が Cr2O72− ＋ 14H+ ＋ 6e− → 2Cr3+ ＋ 7H2O、酸化が Fe2+ → Fe3+ ＋ e− です。
  2. 電子の数を6個にそろえるため酸化の式を6倍して加えると、イオン反応式 Cr2O72− ＋ 6Fe2+ ＋ 14H+ → 2Cr3+ ＋ 6Fe3+ ＋ 7H2O が得られます。検算すると、電荷は左辺 −2＋12＋14 ＝ ＋24、右辺 6＋18 ＝ ＋24 で一致します。
  3. 対イオンを補います。Cr2O72− には K+ 2個、Fe2+ 6個には SO42− 6個、14H+ は硫酸7個分で SO42− 7個を両辺に足すと、右辺は K2SO4 1個、Cr2(SO4)3 1個、Fe2(SO4)3 3個に組み合わさります。
  4. 化学反応式の検算：S は左辺 6＋7 ＝ 13個、右辺 1＋3＋9 ＝ 13個。O は左辺 7＋24＋28 ＝ 59個、右辺 4＋12＋36＋7 ＝ 59個で一致します。

答え：K2Cr2O7 ＋ 6FeSO4 ＋ 7H2SO4 → K2SO4 ＋ Cr2(SO4)3 ＋ 3Fe2(SO4)3 ＋ 7H2O

問題3：過マンガン酸カリウムと濃塩酸の反応 KMnO4 ＋ HCl → KCl ＋ MnCl2 ＋ H2O ＋ Cl2 の係数を、半反応式を使って完成させよ。目算法では手が止まりやすい、係数の大きな反応です。

答えと解説を見る
  1. 半反応式は、還元が MnO4− ＋ 8H+ ＋ 5e− → Mn2+ ＋ 4H2O、酸化が 2Cl− → Cl2 ＋ 2e− です。
  2. 電子の最小公倍数10にそろえ、還元の式を2倍、酸化の式を5倍して加えると、イオン反応式 2MnO4− ＋ 10Cl− ＋ 16H+ → 2Mn2+ ＋ 5Cl2 ＋ 8H2O が得られます。電荷は左辺 −2−10＋16 ＝ ＋4、右辺 ＋4 で一致します。
  3. 対イオンを補います。K+ 2個を両辺に足し、H+ と Cl− は塩酸の形にまとめます。左辺の Cl− は、酸としての HCl 16個分に含まれるものとして数え、右辺では KCl 2個と MnCl2 2個（Cl 4個）に組み合わさり、残りの Cl 10個が 5Cl2 になります。
  4. 検算：Cl は左辺 16個、右辺 2＋4＋10 ＝ 16個。H 16個、O 8個、K 2個、Mn 2個もすべて一致します。

答え：2KMnO4 ＋ 16HCl → 2KCl ＋ 2MnCl2 ＋ 8H2O ＋ 5Cl2。HCl の係数16は、酸として働いた分（イオン反応式の16H+）と、酸化されて Cl2 になった分・塩として残った分の合計です。目算法では、このように1つの物質が複数の役割を担う反応ほど係数が決めにくくなります。

現場での使われ方

酸化還元滴定の mol 比

過マンガン酸カリウム滴定では、試料中の鉄(II)イオンや過酸化水素の量を、滴下した KMnO4 の体積と濃度から求めます。この換算に使うのが、まさにこの項目で作った反応式の係数の比（MnO4− ： Fe2+ ＝ 1：5 など）です。係数が1つ違うだけで分析値が何倍もずれるため、反応式を正確に完成させることが分析の土台になります。

水質検査の COD（化学的酸素要求量）

河川や排水の汚れの指標である COD の測定法の1つに、過マンガン酸カリウム法があります。水中の還元性物質が消費した KMnO4 の量を酸素の量に換算して表す方法で、ここでも酸化還元反応式の係数の比が換算の根拠になっています。

電池・電気分解の電極反応の組み立て

電池や電気分解では、正極・負極（陽極・陰極）で起こる反応はそれぞれ半反応式で書かれます。装置全体の反応式は2つの半反応式を電子が消えるように加えたもので、起電力や生成物の量を見積もる計算は、この組み立ての上に成り立っています。

考え出した人

特定の個人が考え出した方法ではなく、酸化と還元を半反応式に分けて書いてから組み合わせるという、電子の授受を数えるための一般的な手順である

半反応式法には、法則のように一人の発見者の名前は付いていません。酸化還元を「電子の受け渡し」として捉える考え方が整うにつれて、酸化と還元を別々の式に分けて書き、電子の数をそろえてから足し合わせる手順が、係数を間違いなく決める標準的な方法として教科書に受け継がれてきました。半反応式そのものは、電池や電気分解で電極に起こる反応を表す書き方としても使われていて、この項目の手順はその応用にあたります。

この解法を計算機で試す → 酸化還元反応式の作り方 計算機：酸化剤と還元剤の半反応式の電子数から、最小公倍数で電子をそろえる係数比（物質量の比）を解き方の手順つきで表示します。物質量や濃度・体積への応用モードもあります。
