有機化合物の特徴と分類

化学の考え方辞典 ― 有機化学（高校化学・3年）

化学ツール集トップ ＞ 有機化学 ＞ 有機化合物の特徴と分類

高校化学・3年 有機化学

どんな時に使えるか 有機化合物は炭素を骨格とする化合物で、炭素は4本の手（価標）で他の原子と結びつき、鎖式にも環式にも長くつながることができる。同じ分子式でもつながり方の違う異性体が存在し、小さな分子が繰り返しつながる重合も起こるため、種類は膨大になる。性質は炭素骨格に付いた官能基で大きく決まるので、分類はまず骨格（鎖式・環式、飽和・不飽和）を見て、次に官能基を見るのが基本になる。

どんな問題に使うか

有機化学の入口として、初めて見る有機化合物を炭素骨格と官能基で整理するときの考え方です。次のような場面で使います。

  • 分子式・示性式・構造式を見て、化合物の種類（アルコール、カルボン酸、エステルなど）を判断する問題
  • 鎖式か環式か、飽和か不飽和かを、炭素どうしの結合のつながり方から判断する問題
  • 同じ分子式をもつ異性体どうしで、なぜ性質が違うのかを説明する問題
  • この先の炭化水素、官能基、芳香族、高分子などの各項目へ進む前の全体像をつかむ問題

有機化合物は種類が膨大なため、1つずつ暗記するのではなく、骨格の形と官能基の2つの物差しで分類してから性質を予測するのが基本の姿勢です。この項目はその物差しの入口です。

公式・考え方

炭素の4本の手と炭素骨格

有機化合物とは、炭素 C を骨格とする化合物の総称です（一酸化炭素 CO、二酸化炭素 CO2、炭酸塩などの一部の炭素化合物は、慣習として無機化合物に分類します）。炭素の価電子は4個で、共有結合の手（価標）を4本もちます。炭素はこの手を使って水素 H、酸素 O、窒素 N などと結びつくだけでなく、炭素どうしでも単結合・二重結合・三重結合でつながることができます。この炭素どうしのつながりを炭素骨格といいます。

  • 鎖式化合物：炭素が鎖のようにつながったもの（枝分かれを含む）。例：メタン、エタン、エタノール
  • 環式化合物：炭素が輪（環）を作ったもの。例：シクロヘキサン、ベンゼン。ベンゼン環をもつものを特に芳香族化合物として区別します
炭素の価標は4本：単結合×4、二重結合×1＋単結合×2、三重結合×1＋単結合×1 などの組み合わせで必ず合計4本になる

例えばメタン CH4 の炭素は単結合4本、エテン（エチレン）C2H4 の炭素は二重結合1本＋単結合2本、エチン（アセチレン）C2H2 の炭素は三重結合1本＋単結合1本で、いずれも手の合計は4本です。構造式を書くときは、この「炭素の手は4本」という検算が最も基本的な間違い探しになります。

メタンとエタンの構造式。炭素は4本の手のすべてを結合に使い、炭素どうしの結合によって骨格が長く伸びていきます。

種類が膨大な理由 ― 異性体と重合

知られている有機化合物の種類は、無機化合物に比べて桁違いに多く、その理由は主に2つあります。1つ目は異性体の存在です。分子式が同じでも、原子のつながり方が違えば別の化合物になります（詳しくは「構造式と異性体」で扱います）。炭素数が増えるほどつながり方の組み合わせが急増します。2つ目は重合です。小さな分子（単量体）が繰り返しつながって大きな分子（高分子）を作ることができ、つながる数によっても無数の種類が生まれます。さらに、炭素骨格が鎖式にも環式にもなり、二重結合・三重結合や枝分かれも作れることが、組み合わせを大きく広げています。

飽和と不飽和の入口

炭素どうしの結合がすべて単結合の炭化水素を飽和炭化水素、二重結合や三重結合を含む炭化水素を不飽和炭化水素といいます。二重結合・三重結合は反応しやすい場所で、不飽和化合物は他の分子がその結合に付け加わる付加反応を起こしやすいという性質につながります。詳しくは「炭化水素（アルカン・アルケン・アルキン）」で扱います。

エテン（二重結合）とエチン（三重結合）は不飽和炭化水素、シクロヘキサンは環式の飽和炭化水素、ベンゼンはベンゼン環をもつ芳香族化合物です。ベンゼン環は六角形の内側に円を書く表記が一般的です。

官能基による分類の入口

炭素骨格に付いた、化合物の性質を決める原子の集まりを官能基といいます。同じ官能基をもつ化合物は似た性質・似た反応を示すため、有機化合物は官能基で分類するのが基本です。ここでは名前の紹介だけにとどめ、それぞれの詳しい性質は後続の項目への橋渡しとします。

  • ヒドロキシ基 −OHをもつもの：アルコール（例：エタノール）。詳しくは「アルコールとエーテル」へ
  • カルボキシ基 −COOHをもつもの：カルボン酸（例：酢酸）。詳しくは「カルボン酸とエステル」へ
  • エステル結合 −COO−をもつもの：エステル（例：酢酸エチル）。詳しくは「カルボン酸とエステル」へ
  • そのほか、アルデヒド、ケトン、アミンなども官能基で分類します。全体像は「官能基と化合物の分類」へ

エタノール、ジメチルエーテル、酢酸、酢酸エチル、尿素の構造式。各構造式では水素を省略して書く場合もありますが、ここでは官能基の位置が分かるように主なつながりを示しています。エタノールとジメチルエーテルは、どちらも分子式 C2H6O でありながら、つながり方が違う異性体です。

分子式・示性式・構造式の書き分け

有機化合物の表し方には、情報量の違う3つの式があります。

  • 分子式：原子の種類と数だけを示す式。例：エタノールは C2H6O。つながり方は分からないため、異性体どうしは同じ分子式になります
  • 示性式：官能基が分かるようにまとめて書く式。例：エタノールは C2H5OH、酢酸は CH3COOH、酢酸エチルは CH3COOCH2CH3。官能基の部分をひとかたまりで示すので、分類の判断に使えます
  • 構造式：原子のつながり方を価標（線）で示す式。異性体の区別や反応する場所の判断には構造式が必要です

問題を解くときは、分子式で原子の数を数え、示性式で官能基を読み取り、構造式でつながり方を確認する、という順に情報を使い分けるのが基本です。

解き方の手順

  1. 分子式から原子の種類と数を数える。炭素数と水素数の関係から、多重結合や環の有無の目安も付けます。炭素の手は4本という原則も確認します。
  2. 炭素骨格を見る。炭素が鎖状につながっていれば鎖式、輪を作っていれば環式です。ベンゼン環があれば芳香族として区別します。
  3. 飽和・不飽和を判断する。炭素どうしの結合がすべて単結合なら飽和、二重結合・三重結合を含めば不飽和です。
  4. 示性式・構造式から官能基を読み取る。−OH が炭素に付いていればアルコール、−COOH があればカルボン酸、−COO− があればエステル、のように官能基で分類します。
  5. 同じ分子式の別化合物がないか考える。つながり方を変えた異性体が書けないかを確認し、異性体どうしは性質が違うことを意識して答えをまとめます。

例題

問題1：エタノール C2H5OH とジメチルエーテル CH3OCH3 は、どちらも分子式 C2H6O である。この2つが互いにどのような関係にあるか、また官能基による分類をそれぞれ答えよ。

答えと解説を見る

分子式は同じ C2H6O ですが、構造式（上の図）を見るとつながり方が違います。エタノールは C−C−O−H とつながり −OH をもつためアルコール、ジメチルエーテルは C−O−C とつながるエーテルです。分子式が同じで構造が違う化合物どうしを異性体といい、官能基が違うため性質も異なります。分子式だけでは区別できず、示性式・構造式で初めて区別できる典型例です。

答え：互いに異性体。エタノールはアルコール、ジメチルエーテルはエーテル。

問題2：エタン C2H6、エテン C2H4、エチン C2H2 について、炭素どうしの結合の種類と、飽和・不飽和の別をそれぞれ答えよ。また、シクロヘキサン C6H12 とベンゼン C6H6 は骨格の観点でどう分類されるか答えよ。

答えと解説を見る

構造式（上の図）で炭素どうしの結合を見ます。エタンは C−C の単結合だけなので飽和炭化水素、エテンは C＝C の二重結合、エチンは C≡C の三重結合を含むので、どちらも不飽和炭化水素です。各炭素の手の合計は、エタン 4本（単結合のみ）、エテン 4本（二重1本＋単結合2本）、エチン 4本（三重1本＋単結合1本）で、すべて4本にそろいます。シクロヘキサンとベンゼンはどちらも炭素が輪を作る環式化合物で、このうちベンゼンはベンゼン環をもつため芳香族化合物に分類します。シクロヘキサンは炭素どうしがすべて単結合の飽和の環式化合物です。

答え：エタンは単結合・飽和、エテンは二重結合・不飽和、エチンは三重結合・不飽和。シクロヘキサンとベンゼンは環式で、ベンゼンは芳香族。

問題3：酢酸 CH3COOH と酢酸エチル CH3COOCH2CH3 について、示性式から読み取れる官能基（または結合）と分類をそれぞれ答えよ。また、酢酸の分子式を答えよ。

答えと解説を見る

酢酸の示性式 CH3COOH の末尾 −COOH がカルボキシ基なので、分類はカルボン酸です。原子を数えると C が2個、H が 3＋1＝4個、O が2個で、分子式は C2H4O2 です。酢酸エチルの示性式には −COO− のエステル結合が含まれるので、分類はエステルです。示性式は官能基をひとかたまりで示すため、構造式を全部描かなくても分類を読み取れるのが利点です。

答え：酢酸はカルボキシ基をもつカルボン酸で分子式 C2H4O2、酢酸エチルはエステル結合をもつエステル。

現場での使われ方

医薬品と日用品の分類・設計

医薬品の有効成分の多くは有機化合物で、開発ではまず炭素骨格と官能基の組み合わせとして分子を設計し、官能基を変えることで効き方や溶けやすさを調整します。消毒用エタノール（アルコール）や食酢の主成分である酢酸（カルボン酸）のように、官能基による分類は、薬品・食品・日用品のラベルに書かれた成分を読み解くときの物差しにもなっています。

プラスチック・合成繊維などの高分子材料

ポリエチレンなどのプラスチックは、エテンのような小さな有機化合物（単量体）が重合してできた高分子です。単量体の構造と官能基の有無が、できあがる材料の硬さや耐熱性などの性質を左右します。有機化合物の分類の考え方は、石油化学工場で原料と製品を系統立てて扱う基礎にもなっています。

燃料と香料・食品成分

ガソリンや都市ガスの主成分は炭化水素で、炭素数や飽和・不飽和の違いが燃え方や状態（気体・液体）の違いにつながります。また、果物の香りの成分の多くはエステルであり、酢酸エチルのようなエステルは香料や溶剤として利用されています。官能基を見ることで、香りや溶けやすさといった性質の見通しが立ちます。

考え出した人

フリードリヒ・ヴェーラー（1800〜1882、ドイツの化学者）、フリードリヒ・アウグスト・ケクレ（1829〜1896、ドイツの化学者）

かつて有機化合物は、生命の力によってしか作れないと考えられていました。ドイツの化学者フリードリヒ・ヴェーラーは1828年、無機化合物から、有機化合物である尿素 CO(NH2)2 が得られることを示し（尿素の合成）、有機化合物も実験室で合成できることを明らかにしました。これが有機化学が大きく発展する転機の1つになりました。また、ドイツの化学者フリードリヒ・アウグスト・ケクレは、炭素が4本の手をもつ（炭素の四価）ことと炭素どうしが鎖状につながる考え方を1858年頃に示し、1865年にはベンゼンの構造として六角形の環構造（ベンゼン環）を提案しました。本項目の「炭素の4本の手」「炭素骨格」「ベンゼン環」という考え方は、ケクレらの提案が土台になっています。
