陽イオンの定性分析

化学の考え方辞典 ― 無機化学（高校化学・3年）

化学ツール集トップ ＞ 無機化学 ＞ 陽イオンの定性分析

高校化学・3年 無機化学

どんな時に使えるか 陽イオンの定性分析は、試料溶液に含まれる金属イオンを、分離試薬を決まった順に加えて属（グループ）ごとに沈殿として分け取り、沈殿の色や溶け方、炎色反応などから種類を確かめる方法である。希塩酸、酸性・塩基性での硫化水素、アンモニア水、炭酸アンモニウムという順序は、沈殿のできやすさの違いを利用したもので、この流れ図をたどれば、混合溶液でもイオンを1つずつ切り分けて同定できる。

どんな問題に使うか

複数の陽イオンを含む溶液を、属ごとに沈殿で分離しながら同定する（系統分析）ときの考え方です。次のような場面で使います。

  • 系統分析の流れ図を読み、「どの段階で、どのイオンが、何色の沈殿になるか」を答える問題
  • Ag+、Cu2+、Fe3+、Zn2+、Ca2+ などが混ざった溶液について、分離の順序を組み立てる問題
  • Pb2+ のように、第1属と第2属の両方で沈殿が現れるイオンの扱いを問う問題
  • 沈殿が過剰の試薬に溶ける性質（AgCl がアンモニア水に溶ける、Al(OH)3 が水酸化ナトリウム水溶液に溶けるなど）を、同定の手がかりとして使う問題

ポイントは、個々の沈殿反応をばらばらに覚えるのではなく、「分離試薬を加える順序」と「その段階で沈殿する属」を流れとしてつかむことです。各段階で沈殿したものはろ過して取り除き、ろ液を次の段階へ進めます。

公式・考え方

定性分析とは、試料に何が含まれているかを確かめる分析で、どれだけ含まれているかを測る定量分析と区別します。陽イオンの系統分析では、陽イオンを沈殿のでき方の似た仲間ごとに第1属から第6属に分け、分離試薬を順に加えて属ごとに沈殿として分離し、最後に各イオンを個別の反応で確認します。

属分けの土台は沈殿のできやすさ（溶解度）の違いです。とくに硫化物は、酸性では硫化物イオン S2− の濃度が低く抑えられるため、非常に溶けにくい硫化物だけが沈殿し、塩基性では S2− の濃度が上がるため、より溶けやすい硫化物も沈殿します。この pH による切り分けが、第2属と第4属を分ける仕組みです。

第1属 ― 希塩酸で沈殿（塩化物）

分離試薬は希塩酸です。塩化物が水に溶けにくい Ag+ と Pb2+ が沈殿します。

Ag+ ＋ Cl− → AgCl ↓（白色）
Pb2+ ＋ 2Cl− → PbCl2 ↓（白色）

見分け方：PbCl2 は熱水に溶けるのに対し、AgCl は熱水にも溶けません。AgCl は過剰のアンモニア水に溶けてジアンミン銀（I）イオン [Ag(NH3)2]+ になり、これに希硝酸を加えると再び AgCl の白色沈殿が生じます。なお PbCl2 は完全には沈殿しきらず、一部の Pb2+ がろ液に残るため、Pb2+ は第2属でも PbS として再び現れます。

第2属 ― 酸性で硫化水素を通じると沈殿（硫化物・酸性）

第1属のろ液を酸性にして硫化水素 H2S を通じると、酸性でも溶けにくい硫化物が沈殿します。代表は Cu2+、Pb2+（残り）、Cd2+、Hg2+、Bi3+ などです。

Cu2+ ＋ H2S → CuS ↓（黒色）＋ 2H+
Cd2+ ＋ H2S → CdS ↓（黄色）＋ 2H+
Pb2+ ＋ H2S → PbS ↓（黒色）＋ 2H+

確認反応：Cu2+ を含む水溶液に過剰のアンモニア水を加えると、テトラアンミン銅（II）イオン [Cu(NH3)4]2+ の深い青色を示します。CdS の黄色は第2属の中で目立つ色です。

※ ここで紹介する実験・製法を実際に行うときは、学校の授業や専門家の指導のもとで、安全に十分注意し、自己責任で行ってください。

硫化水素は腐卵臭をもつ有毒な気体です。そのため実際の実験室では、加熱すると溶液の中で硫化水素を発生するチオアセトアミド CH3CSNH2 を代わりに使うことが多くなっています（CH3CSNH2 ＋ H2O → CH3CONH2 ＋ H2S）。溶液の中で少しずつ H2S が生じるため、沈殿が均一にできやすい利点もありますが、発生する硫化水素そのものの毒性は変わらないので、扱いは同様に慎重でなければなりません。

※ ここで紹介する実験・製法を実際に行うときは、学校の授業や専門家の指導のもとで、安全に十分注意し、自己責任で行ってください。

第3属 ― アンモニア水で沈殿（水酸化物）

ろ液に塩化アンモニウムを加えたうえでアンモニア水を加えて塩基性にすると、水酸化物が溶けにくい Fe3+、Al3+、Cr3+ が沈殿します。塩化アンモニウムを共存させるのは、OH− の濃度を低く抑え、Mg2+ などが水酸化物として一緒に沈殿するのを防ぐためです。

Fe3+ ＋ 3OH− → Fe(OH)3 ↓（赤褐色）
Al3+ ＋ 3OH− → Al(OH)3 ↓（白色）
Cr3+ ＋ 3OH− → Cr(OH)3 ↓（灰緑色）

見分け方：Al(OH)3 は両性水酸化物で、過剰の水酸化ナトリウム水溶液に溶けてテトラヒドロキシドアルミン酸イオン [Al(OH)4]− になりますが、Fe(OH)3 は溶けません。この性質で Fe3+ と Al3+ を分けられます。

第4属 ― 塩基性で硫化水素を通じると沈殿（硫化物・塩基性）

ろ液を塩基性（アンモニア性）にして硫化水素を通じると、酸性では沈殿しなかった硫化物が沈殿します。代表は Zn2+、Mn2+、Ni2+、Co2+、Fe2+ などです。

Zn2+ ＋ S2− → ZnS ↓（白色）
Mn2+ ＋ S2− → MnS ↓（淡赤色）
Ni2+ ＋ S2− → NiS ↓（黒色）

ZnS の白色は、黒色の NiS・CoS・FeS の中で目立つ手がかりです。第2属と第4属は、どちらも硫化物の沈殿ですが、酸性で沈殿すれば第2属、塩基性で初めて沈殿すれば第4属という液性が区別の決め手になります。

第5属 ― 炭酸アンモニウムで沈殿（炭酸塩）

ろ液に炭酸アンモニウム (NH4)2CO3 を加えると、炭酸塩が溶けにくい Ca2+、Sr2+、Ba2+ が白色沈殿になります。

Ca2+ ＋ CO32− → CaCO3 ↓（白色）
Ba2+ ＋ CO32− → BaCO3 ↓（白色）

3つのイオンは炎色反応で見分けます。Ca2+ は橙赤色、Sr2+ は紅色、Ba2+ は黄緑色です。

第6属 ― 沈殿しない残りのイオン

第5属までの操作で沈殿しなかった Mg2+、Na+、K+、NH4+ が第6属で、共通の分離試薬はありません。個別の反応で確認します。Na+ は炎色反応で黄色、K+ は紫色（赤紫色）を示します。NH4+ は水酸化ナトリウム水溶液と加熱するとアンモニア NH3 を発生することで確認でき、Mg2+ はリン酸塩を加えるとリン酸マグネシウムアンモニウムの白色結晶性沈殿を生じます。

流れ全体をまとめると、希塩酸（第1属）→ 酸性で H2S（第2属）→ NH3 水（第3属）→ 塩基性で H2S（第4属）→ (NH4)2CO3（第5属）→ 残り（第6属）の順です。順序を入れ替えると、後の属のイオンが先に沈殿して混ざってしまうため、この順番自体が分離の設計になっています。

解き方の手順

  1. 流れ図の現在の段階を確認する。いま加えようとしている分離試薬が何か（希塩酸／酸性で H2S／アンモニア水／塩基性で H2S／炭酸アンモニウム）で、対象になる属が決まります。
  2. その属に属するイオンだけを沈殿させる。試料に含まれるイオンのうち、その属のものが沈殿し、それ以外はろ液に残ると読みます。沈殿の化学式と色もあわせて押さえます。
  3. 沈殿とろ液を分けて次へ進む。沈殿はその属の確認反応（熱水や過剰の試薬への溶け方、炎色反応など）へ、ろ液は次の属の操作へ進めます。
  4. 例外を点検する。Pb2+ は第1属で沈殿しきらず第2属でも現れること、硫化物は液性（酸性／塩基性）で属が変わることを確認します。
  5. 最後に第6属を個別反応で確認する。沈殿しない Na+、K+ は炎色反応、NH4+ は加熱によるアンモニア発生で確かめます。

例題

問題1：Ag+、Cu2+、Ca2+ を含む混合溶液に系統分析を行う。希塩酸を加えたとき、次にろ液を酸性にして硫化水素を通じたとき、さらに操作を進めて炭酸アンモニウムを加えたときに、それぞれ何が何色の沈殿として得られるか。問題2：Fe3+、Al3+、Zn2+ を含む混合溶液では、希塩酸と酸性の硫化水素では沈殿が生じなかった。アンモニア水を加えたときと、その後のろ液を塩基性にして硫化水素を通じたときに生じる沈殿を答えよ。また、アンモニア水で得られた沈殿どうしを分ける方法も答えよ。問題3：Pb2+ を含む溶液に希塩酸を加えると白色沈殿が生じたが、ろ液を酸性にして硫化水素を通じても黒色沈殿が新たに生じた。両方の沈殿の化学式を答え、なぜ2回現れるのか説明せよ。問題4：第5属までの操作で何も沈殿しなかった溶液を白金線につけて炎に入れると、黄色の炎色が見られた。含まれているイオンは何か。

答えと解説を見る
  1. 問題1：希塩酸で第1属の Ag+ が AgCl（白色）として沈殿します。ろ液を酸性にして H2S を通じると第2属の Cu2+ が CuS（黒色）として沈殿します。第3属・第4属にあたるイオンはないので沈殿はなく、炭酸アンモニウムを加えると第5属の Ca2+ が CaCO3（白色）として沈殿します。
  2. 問題2：アンモニア水を加えると第3属が沈殿し、Fe3+ から Fe(OH)3（赤褐色）、Al3+ から Al(OH)3（白色）が得られます。ろ液を塩基性にして H2S を通じると第4属の Zn2+ が ZnS（白色）として沈殿します。第3属の沈殿どうしの分離は、過剰の水酸化ナトリウム水溶液を加えると両性水酸化物の Al(OH)3 だけが [Al(OH)4]− となって溶け、Fe(OH)3 が残ることで行えます。
  3. 問題3：希塩酸で生じた白色沈殿は PbCl2、硫化水素で生じた黒色沈殿は PbS です。PbCl2 は水にわずかに溶けるため、第1属の操作では Pb2+ の一部がろ液に残ります。残った Pb2+ が、溶解度の小さい PbS として第2属で沈殿するので、Pb2+ は2つの属にまたがって現れます。
  4. 問題4：第5属まで沈殿しないのは第6属で、黄色の炎色反応は Na+ の特徴です（K+ なら紫色になります）。

答え：問題1は AgCl（白色）→ CuS（黒色）→ CaCO3（白色）。問題2は Fe(OH)3（赤褐色）と Al(OH)3（白色）、次に ZnS（白色）で、Al(OH)3 は過剰の NaOH 水溶液に溶けることで分けられる。問題3は PbCl2 と PbS で、PbCl2 がわずかに溶けて残るため。問題4は Na+。流れ図の問題は「いま何属の操作か」を先に決め、その属のイオンだけを拾うのが読み方のコツです。

現場での使われ方

分析化学の基礎訓練と教育実験

陽イオンの系統分析は、沈殿・ろ過・錯イオン生成・炎色反応といった無機化学の基本操作を一続きの流れで体験できるため、高校・大学の化学実験で長く使われてきました。未知試料を前に「どの試薬を、どの順で加えるか」を設計する考え方は、現代の分析手順を組み立てる訓練そのものです。

機器分析が主流になる前の金属イオン分析

原子吸光分析や ICP 発光分光分析などの機器分析が普及するまでは、沈殿分離による定性分析が、鉱石・合金・水試料などに含まれる金属イオンを調べる実務的な手段でした。現在、定量の主役は感度と精度の高い機器分析に移っていますが、系統分析で培われた「溶解度の差で分けてから確かめる」という発想は、前処理としての沈殿分離や共沈といった、機器分析の前段階の操作にも生きています。

炎色反応の応用（花火と発色）

第5属・第6属の確認に使う炎色反応は、金属元素を炎の中で発色させる現象で、Ca の橙赤色、Sr の紅色、Ba の黄緑色、Na の黄色、K の紫色といった発色は、花火の色付けにも利用されています。分析の確認反応と、身近な発色技術が同じ原理でつながっています。

考え出した人

カール・レミギウス・フレゼニウス（1818〜1897、ドイツの化学者）

陽イオンを属ごとに分離する系統的な定性分析の方法を体系化した中心人物が、ドイツの化学者カール・レミギウス・フレゼニウス（1818〜1897）です。フレゼニウスは1841年に定性化学分析の教科書を著し、硫化水素などによる属分離を軸に、未知試料を順序立てて分析する手順を整理しました。彼は分析化学を専門に教える研究室を率い、1862年には分析化学の専門誌を創刊するなど、分析化学を独立した学問分野として確立するうえで大きな役割を果たしました。今日の教科書に載る第1属から第6属への流れ図は、19世紀に整えられたこの系統分析の枠組みを受け継いだものです。
