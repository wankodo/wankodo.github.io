官能基と化合物の分類

化学の考え方辞典 ― 有機化学（高校化学・3年）

化学ツール集トップ ＞ 有機化学 ＞ 官能基と化合物の分類

高校化学・3年 有機化学

どんな時に使えるか 有機化合物の性質は、炭素骨格よりも、骨格に付いた官能基によって大きく決まる。ヒドロキシ基をもてば水素結合で沸点が上がって水に溶けやすくなり、カルボキシ基をもてば酸性を示す、というように、官能基を見れば化合物の分類と性質の見通しが立つ。同じ炭素数でも官能基が違えば沸点や溶解性は大きく変わるため、構造式ではまず官能基を探すのが基本になる。

どんな問題に使うか

示性式や構造式を見て、どの官能基をもつかから化合物を分類し、性質を予測するときの考え方です。次のような場面で使います。

  • −OH、−COOH、−CHO、−COO−、−NH2 などの官能基を構造式・示性式から読み取り、アルコール、カルボン酸、アルデヒド、エステル、アミンなどに分類する問題
  • 同じ分子式・同じ炭素数の化合物どうしで、沸点の高低や水への溶けやすさの違いを官能基で説明する問題
  • 酸性・塩基性、酸化されやすさ、水素結合の有無など、性質の違いを官能基に結びつけて答える問題
  • ベンゼン環をもつ芳香族化合物と、鎖式の化合物とを区別する問題

炭素骨格は分子の「大きさと形」を決めますが、反応する場所や水とのなじみ方のような化学的な性格は官能基が決めます。この項目では、主要な官能基を一通り並べ、それぞれがどの性質を決めるかを整理します。各官能基の詳しい反応は後続の項目で扱います。

公式・考え方

官能基とは

官能基とは、有機化合物の性質を決める、特定の構造をもつ原子の集まりのことです。同じ官能基をもつ化合物は、炭素骨格が多少違っても似た性質・似た反応を示すため、官能基ごとにまとめたものが化合物の分類（アルコール、カルボン酸など）になります。

化合物の分類と性質 ＝ 炭素骨格（大きさ・形）＋ 官能基（化学的な性格）

主要な官能基の一覧

官能基（示性式）化合物の分類代表化合物どの性質を決めるか
ヒドロキシ基 −OHアルコールエタノール C2H5OHO−H が水素結合を作るため沸点が高く、水に溶けやすい。酸化されるとアルデヒド、さらにカルボン酸になる
カルボキシ基 −COOHカルボン酸酢酸 CH3COOH水溶液中で一部が電離して酸性を示す。分子どうしが水素結合で強く結びつく（二量体）ため沸点が高い。塩基と中和し、アルコールとエステルを作る
ホルミル基 −CHO（アルデヒド基）アルデヒドアセトアルデヒド CH3CHO酸化されやすく、カルボン酸になりやすい。還元性をもつのが特徴で、ケトンとの区別に使われる
カルボニル基 C＝O（ケトンのもの）ケトンアセトン（プロパノン）CH3COCH3C＝O の極性で水と水素結合できるため水に溶けるものがあるが、自分どうしでは水素結合しないのでアルコールより沸点は低い。アルデヒドと違い、穏やかな条件では酸化されにくい
エステル結合 −COO−エステル酢酸エチル CH3COOCH2CH3水素結合の供与体（O−H）をもたないため、同じくらいの分子量のカルボン酸より沸点が低い。果物のような香りの成分が多く、加水分解でカルボン酸とアルコールに戻る
エーテル結合 −O−エーテルジメチルエーテル CH3OCH3O−H をもたないため分子どうしの水素結合がなく、沸点が低い。反応性が低く、溶媒として使われるものがある
アミノ基 −NH2アミンエチルアミン C2H5NH2窒素の非共有電子対が H+ を受け取るため塩基性を示す。N−H で水素結合も作る
アミド結合 −CONH−（−CONH2 を含む）アミドアセトアミド CH3CONH2N−H と C＝O で強い水素結合を作るため、融点・沸点が高い。タンパク質のペプチド結合もアミド結合であり、生体分子の形を保つ要になっている
ニトロ基 −NO2ニトロ化合物ニトロメタン CH3NO2酸素を多く含む強い極性の基で、ニトロ化合物には爆発性をもつものがある。還元するとアミノ基に変わる
ベンゼン環 C6H5−芳香族化合物ベンゼン C6H6、フェノール C6H5OH環の電子が全体に広がって安定なため、二重結合をもつ見かけに反して付加反応より置換反応を起こしやすい。水になじみにくい（疎水性）

なお、フェノールのようにベンゼン環に直接 −OH が付いた化合物は、アルコールとは性質が違い（弱い酸性を示すなど）、芳香族化合物として別に扱います。同じ −OH でも、付いている相手によって性格が変わる点に注意してください。

エタノール、酢酸、アセトアルデヒド、アセトン（プロパノン）の構造式。アルデヒドとケトンはどちらも C＝O をもちますが、−CHO のように鎖の末端で水素と結びついたものがアルデヒド、鎖の内側で両側を炭素に挟まれたものがケトンです。水素は官能基に関わるものだけを示し、炭素に付いた水素は省略しています（以下の図も同じ）。

酢酸エチル、ジメチルエーテル、エチルアミン、アセトアミドの構造式。エステル結合 −COO− とエーテル結合 −O− は見た目が似ていますが、C＝O を含むかどうかが区別の決め手です。アミドは C＝O と窒素が直接結びついた −CONH− の構造が目印です。

ニトロメタン、ベンゼン、フェノールの構造式。ニトロ基は窒素に酸素が2つ結びついた −NO2 が目印です。フェノールはベンゼン環に −OH が直接付いた化合物で、アルコールとは区別します。

同じ炭素数でも官能基で変わる沸点と溶解性

性質の違いが最もはっきり出るのが、沸点と水への溶け方です。鍵は水素結合です。O−H や N−H のように、電気陰性度の大きい原子に付いた水素は、隣の分子の酸素や窒素と水素結合を作ります。水素結合があると、分子どうしを引き離す（＝沸騰させる）のに余分なエネルギーが要るため沸点が上がり、水とも水素結合で結びつくため溶けやすくなります。

  • 炭素数2の化合物で比べる：エタン C2H6 の沸点は約 −89 ℃、ジメチルエーテル CH3OCH3 は約 −24 ℃、エタノール C2H5OH は約 78 ℃。ジメチルエーテルとエタノールは分子式が同じ C2H6O の異性体ですが、−OH をもち分子どうしが水素結合するエタノールの沸点が約100 ℃も高くなります
  • 水への溶け方：エタンは水にほとんど溶けません。エタノールは −OH が水と水素結合するため水と任意の割合で混ざります。酢酸やアセトンも水によく溶けますが、エステルやベンゼン環だけをもつ化合物は水に溶けにくく、炭素骨格（疎水性の部分）が大きくなるほど溶けにくくなります
  • カルボン酸の沸点が高い理由：酢酸の沸点は約 118 ℃ で、分子量の近い化合物の中でも高めです。カルボキシ基どうしが2か所で水素結合してペア（二量体）を作り、見かけの分子量が2倍になるためです

つまり、沸点や溶解性を問われたら、まず「O−H や N−H があるか（水素結合の供与体）」「C＝O や −O− のように水素結合を受け取る原子があるか」「疎水性の炭素骨格がどれだけ大きいか」の順に官能基を見ていくのが基本です。

解き方の手順

  1. 酸素・窒素などのヘテロ原子を探す。官能基は炭素と水素以外の原子（O、N など）を含むことが多いので、まず構造式・示性式の中で C と H 以外の原子に注目します。ベンゼン環の有無もここで確認します。
  2. 官能基の形を読み取る。−OH ならアルコール、−COOH ならカルボン酸、末端の −CHO ならアルデヒド、内側の C＝O ならケトン、−COO− ならエステル、C−O−C ならエーテル、−NH2 ならアミン、−CONH− ならアミド、−NO2 ならニトロ化合物、と対応づけます。−COOH や −COO− の中にも C＝O が含まれますが、より大きなまとまり（カルボキシ基・エステル結合）として読み取るのが原則です。
  3. 付いている相手を確認する。−OH がベンゼン環に直接付いていればフェノール類であり、アルコールとは性質が違うことに注意します。
  4. 官能基から性質を予測する。酸性ならカルボキシ基（とフェノール）、塩基性ならアミノ基、酸化されやすいのはアルデヒド（と第一級アルコール）、水素結合で沸点が高いのは −OH や −NH をもつもの、というように結びつけます。
  5. 比べる問題では分子量・炭素数をそろえる。沸点や溶解性の比較は、大きさが近い化合物どうしで官能基だけの違いを見るのが筋道です。異性体どうしの比較が典型です。

例題

例題1で使う 1-プロパノール、プロパナール、プロピオン酸の構造式。プロパノン（アセトン）の構造式は本文の図にあります。プロピオン酸の C＝O の酸素は炭素の下に示しています。

問題1：炭素数3の次の化合物について、もつ官能基と分類をそれぞれ答えよ。（ア）1-プロパノール CH3CH2CH2OH　（イ）プロパナール CH3CH2CHO　（ウ）プロパノン CH3COCH3　（エ）プロピオン酸 CH3CH2COOH

答えと解説を見る

示性式の末尾や中央のまとまりに注目します。（ア）は −OH をもつのでヒドロキシ基・アルコール。（イ）は鎖の末端に −CHO をもつのでホルミル基・アルデヒド。（ウ）は鎖の内側に C＝O があり両側が炭素なのでカルボニル基・ケトン。（エ）は −COOH をもつのでカルボキシ基・カルボン酸です。（イ）と（ウ）はどちらも C＝O を含み分子式も同じ C3H6O ですが、C＝O の位置（末端か内側か）でアルデヒドとケトンに分かれ、酸化されやすさが違います。

答え：（ア）ヒドロキシ基・アルコール、（イ）ホルミル基・アルデヒド、（ウ）カルボニル基・ケトン、（エ）カルボキシ基・カルボン酸。

例題2で使うエタンの構造式。ジメチルエーテルとエタノールの構造式は本文の図にあります。

問題2：エタン（沸点約 −89 ℃）、ジメチルエーテル（沸点約 −24 ℃）、エタノール（沸点約 78 ℃）について、沸点がこの順に高くなる理由を官能基の言葉で説明せよ。また、水に最も溶けやすいのはどれか答えよ。

答えと解説を見る

3つは大きさが近い分子です。エタンは C と H だけの炭化水素で、分子間には弱いファンデルワールス力しか働かないため沸点が最も低くなります。ジメチルエーテルは酸素を含むため分子の極性が大きくなり、エタンより沸点が上がりますが、O−H をもたないので分子どうしの水素結合はできません。エタノールは −OH をもち、分子どうしが水素結合で結びつくため、引き離すのに大きなエネルギーが要り、沸点が際立って高くなります。水への溶け方も同じ理由で、−OH が水と水素結合するエタノールが最も溶けやすく（水と任意の割合で混ざる）、エタンはほとんど溶けません。

答え：沸点の差は主に水素結合の有無による。エタン＜ジメチルエーテル＜エタノールの順に分子間の引力が強くなる。水に最も溶けやすいのはエタノール。

例題3で使うアニリンとニトロベンゼンの構造式。どちらもベンゼン環に官能基が1つ付いた芳香族化合物です。

問題3：アニリン C6H5NH2 とニトロベンゼン C6H5NO2 について、（1）共通する骨格と、それぞれがもつ官能基を答えよ。（2）塩基性を示すのはどちらか、理由とともに答えよ。（3）ニトロベンゼンを還元すると何になるか答えよ。

答えと解説を見る

（1）どちらもベンゼン環をもつ芳香族化合物で、アニリンはアミノ基 −NH2、ニトロベンゼンはニトロ基 −NO2をもちます。（2）塩基性を示すのはアニリンです。アミノ基の窒素がもつ非共有電子対が H+ を受け取るためで、酸と塩を作ります（ただしベンゼン環の影響で、脂肪族のアミンより塩基性は弱い）。ニトロ基にはその働きはありません。（3）ニトロ基は還元されるとアミノ基に変わるので、ニトロベンゼンを還元するとアニリンが得られます。この「ニトロベンゼン→アニリン」の変換は、染料の原料を作る出発点として知られています。

答え：（1）共通の骨格はベンゼン環。アニリンはアミノ基、ニトロベンゼンはニトロ基。（2）アニリン（アミノ基の窒素が H+ を受け取るため）。（3）アニリン。

現場での使われ方

香料・食品の香りの設計

果物や花の香りの成分の多くはエステルで、酢酸エチルのようなエステルは香料や溶剤として使われています。どのエステル結合をもつかで香りが変わるため、香料の設計は「官能基はそのままに、炭素骨格を少し変える」という発想で行われます。官能基で分類する考え方が、そのまま製品の設計図になっています。

医薬品の効き方と官能基

医薬品の有効成分では、カルボキシ基をもつものは酸性、アミノ基をもつものは塩基性というように、官能基が体内での溶け方や標的への結びつき方を左右します。開発の現場では、骨格は保ったまま官能基を付け替え、効き目と副作用のバランスを調整する作業が日常的に行われています。

染料とアニリン

アニリンはアミノ基をもつ芳香族化合物で、アゾ染料など多くの染料の出発原料です。ニトロベンゼンを還元してアニリンを得て、そこから色のもとになる構造を作るという流れは、官能基を変換しながら目的の化合物へ近づける有機合成の典型例です。

洗剤・消毒など日用品の読み解き

消毒用エタノールはアルコール、食酢はカルボン酸、漂白や消毒に使う製品の成分表示にも官能基をもつ化合物が並びます。成分名から官能基を思い浮かべられると、「酸性だから塩基性の汚れに効く」「アルコールだから脂に混ざりやすい」といった働きの見通しが立ち、製品ラベルの理解に直結します。

考え出した人

ユストゥス・フォン・リービッヒ（1803〜1873、ドイツの化学者）、シャルル・ジェラール（1816〜1856、フランスの化学者）

官能基という考え方は、特定の1人が一度に作ったものではなく、19世紀の有機化学の中で段階的に育ちました。ドイツの化学者ユストゥス・フォン・リービッヒは、フリードリヒ・ヴェーラーとともに1832年、反応の前後でまとまって行動する原子の集まり（ベンゾイル基）の存在を示しました。これは「原子の集まりが化合物の性格を担う」という根基説（ラジカル説）として知られ、官能基の考え方の源流の1つです。その後、フランスの化学者シャルル・ジェラールは1850年代に、有機化合物をいくつかの「型」に分類して整理する型説を唱え、化合物を構造のまとまりで分類する見方を進めました。こうした積み重ねの上に、今日の「官能基で分類し、性質を読む」という方法が成り立っています。
