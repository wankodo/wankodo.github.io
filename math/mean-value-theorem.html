平均値の定理

数学解法辞典 ― 微分・積分（高校）

数学ツール集トップ ＞ 微分・積分 ＞ 平均値の定理

高校 微分・積分 計算機あり

どんな時に使えるかある区間を移動した平均速度と、その区間の中のある瞬間の瞬間速度が一致する点が必ず存在する、というのが平均値の定理である。高速道路の区間速度取り締まり（平均速度監視）はまさにこの原理で、誤差の評価や数値計算の精度保証など、微分を使った理論の証明でも土台になっている。

どんな問題に使うか

関数がある区間全体でどう変化したか（平均変化率）と、その区間の中のある1点での変化の速さ（微分係数）が一致する点の存在を示したり、その点を求めたりする問題です。

  • 与えられた関数と区間について、平均値の定理を満たす c を求める問題
  • 平均値の定理を使って、不等式や等式を証明する問題
  • 前段階のロルの定理を使って、方程式の解の個数や存在を示す問題
  • 区間の平均速度と瞬間速度の関係を考える問題

平均変化率や微分係数をただ計算する項目と違い、こちらは「その2つが一致する点が区間の内側に必ずある」という存在の保証が中心です。

公式・考え方

関数 f が閉区間 [p, q] で連続で、開区間 (p, q) で微分可能ならば、次の式を満たす c が区間 (p, q) の内側に少なくとも1つ存在します。これが平均値の定理です。

f′(c) ＝ (f(q) − f(p)) ÷ (q − p)　（p ＜ c ＜ q）

右辺は区間 [p, q] における平均変化率、左辺は点 c における微分係数です。つまり「区間全体の平均の変化の速さと、ある1点での瞬間の変化の速さが一致する点が、区間の内側に必ずある」という主張です。

前段階として、f(p) ＝ f(q) の場合をロルの定理といいます。このとき平均変化率は 0 になるので、f′(c) ＝ 0 を満たす c が区間の内側に少なくとも1つ存在します。平均値の定理は、ロルの定理を f(p) ≠ f(q) の場合に広げたものと見ることができます。

幾何学的には、平均変化率 (f(q) − f(p)) ÷ (q − p) は、グラフ上の2点 (p, f(p)) と (q, f(q)) を結ぶ直線の傾きです。したがって平均値の定理は、区間の両端を結ぶ直線と平行な接線が、区間の内側のどこかに少なくとも1本引けるという意味になります。

解き方の手順

  1. 条件を確認する。関数が区間 [p, q] で連続で、(p, q) で微分可能かを確かめる。多項式の関数はすべての区間でこの条件を満たす。
  2. 両端の値を求める。f(p) と f(q) を計算する。
  3. 平均変化率を求める。(f(q) − f(p)) ÷ (q − p) を計算する。
  4. 導関数を求める。f′(x) を計算する。
  5. f′(c) ＝ 平均変化率 とおいて解く。方程式を解いて c の候補を求める。
  6. 区間の内側にあるか確認する。求めた c が p ＜ c ＜ q を満たすことを確かめる。

例題

問題：関数 f(x) ＝ x² − 2x について、区間 [0, 3] で平均値の定理を満たす c を求めよ。

答えと解説を見る

f は多項式の関数なので、区間 [0, 3] で連続で、(0, 3) で微分可能です。f(0) ＝ 0、f(3) ＝ 9 − 6 ＝ 3 なので、平均変化率 ＝ (3 − 0) ÷ (3 − 0) ＝ 1 です。

f′(x) ＝ 2x − 2 なので、f′(c) ＝ 1 とおくと 2c − 2 ＝ 1 を解いて c ＝ 1.5 となります。これは区間 (0, 3) の内側にあります。

答え：c ＝ 1.5

現場での使われ方

高速道路の平均速度監視（区間速度取り締まり）

高速道路の区間速度取り締まり（平均速度監視）は、区間の入口と出口の通過時刻から平均速度を計算し、制限速度を超えていないかを判定する仕組みです。平均値の定理が示すのは、この平均速度とまったく同じ瞬間速度で走った瞬間が、区間の中に必ず存在したということです。つまり平均速度が制限を超えていれば、その瞬間速度で制限を超えた瞬間が確かにあったことが、定理によって保証されます。

誤差の評価

測定値や近似値にどれだけの誤差がありうるかを評価するとき、平均値の定理が使われます。区間の両端での関数の値の差は、区間の中のどこかの点での微分係数と区間の幅の積に等しいので、微分係数の大きさの上限が分かれば、値の差（誤差）の上限を見積もることができます。

数値計算の精度保証

コンピュータによる数値計算では、近似計算の結果が真の値からどれだけずれているかを保証する必要があります。平均値の定理はその誤差評価の土台で、テイラー展開の剰余項の評価など、微分を使った理論の証明でも繰り返し使われる基本定理です。

考え出した人

ジョゼフ＝ルイ・ラグランジュ（1736〜1813、フランスの数学者）／ミシェル・ロル（1652〜1719、フランスの数学者）

平均値の定理は、フランスの数学者ジョゼフ＝ルイ・ラグランジュ（1736〜1813）が1797年に提示したとされます。ラグランジュは微分積分を代数的に基礎づけようとした大著の中でこの定理を述べ、微分の理論の土台に据えました。前段階となるロルの定理は、フランスの数学者ミシェル・ロル（1652〜1719）が1691年に発表したもので、もとは方程式の解の存在を扱う結果でした。現在の形の証明や条件の整備は、その後のコーシーらによって進められました。
