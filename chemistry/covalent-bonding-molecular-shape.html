共有結合と分子の形

化学の考え方辞典 ― 化学結合（高校化学基礎・1年）

化学ツール集トップ ＞ 化学結合 ＞ 共有結合と分子の形

高校化学基礎・1年 化学結合

どんな時に使えるか 原子どうしが価電子を出し合って電子のペア（共有電子対）を共有し、希ガスと同じ安定な電子配置になる結合が共有結合で、共有する電子対が1組なら単結合、2組なら二重結合、3組なら三重結合になる。分子の形は、中心原子のまわりの電子対（非共有電子対を含む）が互いに反発して最も離れる配置で決まり、メタンは正四面体形、二酸化炭素は直線形、水は折れ線形になる。

どんな問題に使うか

非金属元素の原子どうしが結びついてできる分子のつくりを扱うときの考え方です。次のような場面で使います。

  • 水素 H2、酸素 O2、窒素 N2 などの分子について、電子式と構造式を書く問題
  • 単結合・二重結合・三重結合のどれになるかを、共有電子対の組数から判断する問題
  • メタン CH4、アンモニア NH3、水 H2O、二酸化炭素 CO2 などの分子の立体構造（形）と結合角を答える問題
  • 非共有電子対（孤立電子対）の数が、分子の形にどう影響するかを考える問題

ポイントは、結合そのものは「電子対を何組共有するか」で決まり、分子の形は「中心原子のまわりの電子対どうしの反発」で決まる、という2段構えで考えることです。

公式・考え方

金属元素と非金属元素の間では電子の受け渡し（イオン結合）が起こりますが、非金属元素どうしでは、どちらの原子も電子を放したがらないため、価電子を出し合って電子のペアを共有します。この結合が共有結合です。共有されている電子のペアを共有電子対、結合に使われず1つの原子のまわりに残っているペアを非共有電子対（孤立電子対）といいます。各原子は、共有によって最外殻の電子が希ガスと同じ配置（水素は2個、それ以外は8個：オクテット）になると安定になります。

原子と価電子を点で表した式を電子式、共有電子対を線（価標）で表した式を構造式といいます。共有する電子対の組数で結合の名前が変わります。

  • 単結合：電子対を1組共有する結合。構造式では線1本で書く（例：H−H、CH4 の C−H 結合）
  • 二重結合：電子対を2組共有する結合。線2本で書く（例：O＝O、CO2 の C＝O 結合）
  • 三重結合：電子対を3組共有する結合。線3本で書く（例：N≡N）
単結合 ＝ 共有電子対1組（電子2個）／ 二重結合 ＝ 2組（電子4個）／ 三重結合 ＝ 3組（電子6個）

H2 は単結合、O2 は二重結合、N2 は三重結合。どの分子でも、各原子のまわりの電子（共有分＋非共有分）が水素なら2個、それ以外なら8個（オクテット）になっています。

分子の立体構造は、中心原子のまわりにある電子対（共有電子対も非共有電子対も）が、互いに反発してできるだけ離れようとすることで決まります（電子対反発の考え方。大学では VSEPR 理論として学びます）。電子対の「置き場所」の数が基本の形を決め、非共有電子対は目に見える原子ではないため、原子だけを見た形は基本の形から少し崩れます。

  • 電子対が2組：正反対の向きに離れる → 直線形（CO2、結合角180°）
  • 電子対が3組：平面上で互いに120°に離れる → 正三角（三角平面）形（三フッ化ホウ素 BF3、結合角120°）
  • 電子対が4組：立体的に最も離れる → 正四面体形（CH4、結合角約109.5°）。ただし非共有電子対が1組あると原子の形は三角錐形（NH3、結合角約107°）、2組あると折れ線形（H2O、結合角約104.5°）になります

非共有電子対どうし・非共有電子対と共有電子対の反発は、共有電子対どうしの反発より強いため、非共有電子対が多いほど結合角は基本の109.5°から押し縮められます（CH4 約109.5° ＞ NH3 約107° ＞ H2O 約104.5°）。

代表的な分子の形。CO2 と BF3 には非共有電子対が中心原子になく、電子対の配置そのままが原子の形になります。NH3 と H2O は電子対の配置は正四面体に近いものの、非共有電子対の分だけ原子の形が崩れ、結合角も小さくなります。

解き方の手順

  1. 各原子の価電子の数を確認する。H は1個、C は4個、N は5個、O は6個、F は7個です（最外殻の電子数＝周期表の族の情報と対応します）。
  2. 電子式を書く。まず原子を価電子の点とともに並べ、原子どうしが電子対を共有して、各原子のまわりが水素なら2個、それ以外なら8個（オクテット）になるように点を配置します。余ったペアが非共有電子対です。
  3. 構造式に直す。共有電子対1組を線1本に置き換えます。線が1本なら単結合、2本なら二重結合、3本なら三重結合です。非共有電子対は構造式では通常省略します。
  4. 中心原子のまわりの電子対の総数を数える。共有電子対（二重・三重結合はまとめて1か所として数える）と非共有電子対の合計が、2組なら直線形、3組なら三角平面、4組なら正四面体が基本形です。
  5. 原子だけの形と結合角を答える。非共有電子対がある場合は、その分を除いた原子の配置で形の名前を言い、結合角は非共有電子対が多いほど基本形より小さくなることを確認します。

例題

問題1：メタン CH4 の電子式・構造式の特徴と、分子の形・H−C−H の結合角を答えよ。問題2：二酸化炭素 CO2 の構造式と分子の形・結合角を答えよ。問題3：アンモニア NH3 と水 H2O について、中心原子の非共有電子対の数、分子の形、結合角をそれぞれ答え、CH4 と比べて結合角が小さくなる理由を述べよ。

答えと解説を見る
  1. 問題1：C の価電子は4個、H は1個ずつで、価電子の合計は 4 ＋ 1×4 ＝ 8個です。C が4個の H と電子対を1組ずつ共有すると、C のまわりは8個（オクテット）、各 H のまわりは2個になり、非共有電子対は残りません。構造式は C から4本の単結合が出た形で、中心の C のまわりの電子対は4組なので、分子の形は正四面体形、結合角は約109.5°です。
  2. 問題2：価電子の合計は C の4個 ＋ O の6個×2 ＝ 16個です。C が各 O と電子対を1組だけ共有したのでは C のまわりが4個にしかならないため、各 O と2組ずつ共有する二重結合にします（O＝C＝O）。すると C のまわりは8個、各 O のまわりも共有分4個＋非共有電子対2組（4個）で8個になります。中心の C のまわりの電子対の場所は左右2か所なので、分子の形は直線形、結合角は180°です。
  3. 問題3：NH3 では価電子の合計は 5 ＋ 1×3 ＝ 8個で、N が3個の H と単結合を作ると共有に6個を使い、残り2個が非共有電子対1組として N のまわりに残ります。H2O では価電子の合計は 6 ＋ 1×2 ＝ 8個で、O が2個の H と単結合を作ると共有に4個を使い、残り4個が非共有電子対2組として残ります。どちらも中心原子のまわりの電子対は4組で配置は正四面体に近いものの、原子だけを見ると NH3 は三角錐形（結合角約107°）、H2O は折れ線形（結合角約104.5°）です。非共有電子対は共有電子対より強く反発して結合を押し縮めるため、非共有電子対が多い H2O の方が NH3 より結合角が小さくなります。

答え：問題1は単結合4本の正四面体形で結合角約109.5°、問題2は O＝C＝O の二重結合2本で直線形・結合角180°、問題3は NH3 が非共有電子対1組・三角錐形・約107°、H2O が非共有電子対2組・折れ線形・約104.5°。どの分子でも「価電子の合計」と「各原子のまわりが8個（Hは2個）」を数え直すことが検算になります。

現場での使われ方

分子の形から分かる極性と、溶媒の選び方

CO2 は C＝O 結合自体には極性がありますが、分子が直線形で両側の極性が打ち消し合うため、分子全体としては極性が小さい気体です。一方、H2O は折れ線形で極性が打ち消されず、強い極性をもつため、食塩のようなイオン結晶をよく溶かす溶媒になります。「形が極性を決め、極性が溶けやすさを決める」という見方は、実験室や工場で溶媒を選ぶときの基本的な判断材料です。CO2 の直線形で無極性に近い性質は、超臨界二酸化炭素を抽出溶媒として使う技術（コーヒーの脱カフェインなど）にもつながっています。

医薬品の設計（分子の形と受容体）

薬の分子は、体内の標的タンパク質（受容体や酵素）の決まった形のくぼみに、形が合うものだけがはまって作用します。そのため新薬の設計では、共有結合で組み立てた分子の立体構造を予測・調整することが欠かせません。結合角や非共有電子対の向きまで含めた分子の形の理解が、医薬品化学の出発点になっています。

共有結合でできた材料（高分子・ネットワーク固体）

プラスチックや合成ゴムなどの高分子は、炭素原子どうしの共有結合が長くつながった分子です。また、ダイヤモンドは炭素原子が正四面体の向きに共有結合で結ばれたネットワーク固体で、その立体的な結合の網目が極端な硬さの理由になっています。分子の形と結合の組み立て方が、そのまま材料の性質を決めています。

考え出した人

ギルバート・N・ルイス（1875〜1946、アメリカの化学者）、ロナルド・ギレスピー（1924〜2021、カナダの化学者）、ロナルド・ニーホルム（1917〜1971、オーストラリアの化学者）

共有結合の考え方は、アメリカの化学者ギルバート・N・ルイスが1916年に発表した電子対の共有による結合モデルが土台で、原子が電子を出し合って希ガスと同じ8個の電子配置（オクテット）になるという見方を示しました。「共有（covalent）」という言葉自体は、アメリカの化学者アーヴィング・ラングミュアが1919年に広めたものです。分子の形を電子対の反発から予測する方法は、イギリスで活動したロナルド・ニーホルムとカナダのロナルド・ギレスピーが1957年に体系化し、後に VSEPR（原子価殻電子対反発）理論と呼ばれるようになりました。高校化学基礎で学ぶ「電子対が最も離れる形が分子の形」という説明は、この理論の考え方そのものです。
