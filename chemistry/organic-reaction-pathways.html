反応経路図の読み方

化学の考え方辞典 ― 有機化学（高校化学・3年）

化学ツール集トップ ＞ 有機化学 ＞ 反応経路図の読み方

高校化学・3年 有機化学

どんな時に使えるか 反応経路図は、有機化合物どうしを反応の矢印でつないだ合成の地図である。箱が化合物、矢印が反応を表し、矢印の上に試薬や条件が書かれる。エチレンやベンゼンのような基本原料から目的の化合物まで、矢印を順にたどれば合成の順序が読み取れ、目的物から逆向きにたどれば原料と手順を組み立てられる。

どんな問題に使うか

たくさんの有機反応を、1枚の地図として整理して読み取るための考え方です。個々の反応をばらばらに暗記するのではなく、「どの化合物が、どの反応で、何に変わるか」のつながりで覚えるのが目的で、次のような場面で使います。

  • 経路図の空欄（化合物名や試薬・条件）を埋める問題
  • ある原料から目的の化合物を作るのに、どの矢印をどの順にたどればよいかを答える問題（合成経路を選ぶ問題）
  • 矢印の上に書かれた試薬・条件から、反応の種類（付加・酸化・還元・置換・脱水など）を読み取る問題
  • 目的物しか示されていないときに、経路を逆向きにたどって原料までさかのぼる問題

ポイントは、経路図を「左から右へ読む本」ではなく、駅と路線でできた路線図として見ることです。化合物が駅、矢印が路線にあたり、出発駅（原料）と到着駅（目的物）が決まれば、乗り換えの順序は図の上でたどれます。

公式・考え方

経路図の3つの約束事

  • 箱（枠）＝化合物：箱の中には化合物の名前や構造式が書かれます。同じ化合物が図の離れた場所に2回出てくることもあります。
  • 矢印＝反応：矢印の向きが反応の進む向きです。原料から生成物へ向かいます。可逆な反応（エステル化など）では両向きの矢印 ⇌ で書かれることもあります。
  • 矢印の上（下）の文字＝試薬と条件：加える試薬（H2O、O2、濃硫酸など）、触媒、温度・圧力、「酸化」「還元」のような反応の種類が書かれます。この文字がないと反応は進まない、という意味で、矢印そのものと同じくらい重要です。
読み方：原料 ―（試薬・条件）→ 生成物　／　逆読み：目的物 ←（必要な試薬・条件）― 原料

矢印の上の言葉と反応の種類の対応は、次のように読み替えます。

  • 付加：二重結合が開いて、相手の分子が両側の炭素に分かれて付く（エチレン ＋ H2O → エタノール など）
  • 酸化：酸素が付く、または水素が取れる方向の変化（エタノール → アセトアルデヒド → 酢酸 の階段）
  • 還元：水素が付く、または酸素が取れる方向の変化（ニトロベンゼン → アニリン など）
  • 置換：原子や原子団が別のものと入れ替わる（ベンゼン → ニトロベンゼン、ベンゼン → クロロベンゼン など）
  • 脱水：分子内や分子間で水が取れる（エタノール → エチレン、エタノール2分子 → ジエチルエーテル など）。温度で生成物が変わることがある
  • エステル化：カルボン酸とアルコールから水が取れてエステルができる（酢酸 ＋ エタノール ⇌ 酢酸エチル ＋ 水）

地図1：エチレンを起点とする経路

エチレン CH2＝CH2 は二重結合をもつため付加反応の入口が広く、脂肪族化合物の多くはここからたどれます。中心の道は「エチレン → エタノール → アセトアルデヒド → 酢酸」という酸化の階段で、酢酸とエタノールが出会うと酢酸エチルができます。

エチレンを起点とする経路図の例。酢酸エチルの箱には、酢酸からの矢印とエタノールからの矢印の2本が入っています。これは「原料が2つある反応（エステル化）」の書き方で、両方の原料がそろって初めて生成物ができることを表します。

この地図に現れる反応式は次の通りです。いずれも両辺の原子数が一致することを検算してあります。

  • 水の付加：C2H4 ＋ H2O → C2H5OH（リン酸触媒・高温・高圧）
  • 水素の付加：C2H4 ＋ H2 → C2H6（ニッケル触媒）
  • 臭素の付加：C2H4 ＋ Br2 → C2H4Br2
  • 付加重合：n CH2＝CH2 → −(CH2−CH2)n−
  • エタノールの酸化：C2H5OH ＋ [O] → CH3CHO ＋ H2O（[O] は酸化剤から受け取る酸素を表す略記）
  • アセトアルデヒドの酸化：CH3CHO ＋ [O] → CH3COOH
  • エタノールの分子間脱水：2C2H5OH → C2H5OC2H5 ＋ H2O（濃硫酸・140 ℃）
  • エタノールの分子内脱水：C2H5OH → C2H4 ＋ H2O（濃硫酸・170 ℃）
  • エステル化：CH3COOH ＋ C2H5OH ⇌ CH3COOC2H5 ＋ H2O（濃硫酸・加熱）

地図1に登場する化合物の構造式。エタノール → アセトアルデヒド → 酢酸の階段は、−CH2OH → −CHO → −COOH と、炭素に付いた酸素の数が増えていく「酸化の階段」として構造式でも読み取れます。

地図2：ベンゼンを起点とする経路

ベンゼン C6H6 の環は安定で、付加反応より置換反応（環の水素が別の原子団と入れ替わる反応）が中心です。代表的な分岐は、ニトロ化からアニリンへ向かう道と、クロロ化からフェノールへ向かう道、そしてフェノールからサリチル酸・アセチルサリチル酸（アスピリン）へ向かう道です。

ベンゼンを起点とする経路図の例。アニリンへの道は「置換（ニトロ化）→ 還元」、フェノールへの道は「置換（クロロ化）→ 置換（−Cl を −OH に）」というように、矢印の上の言葉を並べるだけで合成の手順書になります。

この地図に現れる反応式は次の通りです（いずれも検算済み）。

  • ニトロ化：C6H6 ＋ HNO3 → C6H5NO2 ＋ H2O（濃硫酸・約60 ℃）
  • ニトロベンゼンの還元：C6H5NO2 ＋ 6[H] → C6H5NH2 ＋ 2H2O（スズと塩酸。[H] は還元剤から受け取る水素を表す略記）
  • クロロ化：C6H6 ＋ Cl2 → C6H5Cl ＋ HCl（鉄触媒）
  • クロロベンゼンからフェノール：C6H5Cl ＋ NaOH → C6H5OH ＋ NaCl（高温・高圧）
  • フェノールの塩の生成：C6H5OH ＋ NaOH → C6H5ONa ＋ H2O
  • サリチル酸の生成（コルベ・シュミット反応の全体）：C6H5ONa ＋ CO2 ＋ HCl → C6H4(OH)COOH ＋ NaCl（二酸化炭素を反応させた後、塩酸で酸性にして取り出す）
  • アセチルサリチル酸の生成：C6H4(OH)COOH ＋ (CH3CO)2O → C6H4(OCOCH3)COOH ＋ CH3COOH（サリチル酸 ＋ 無水酢酸 → アセチルサリチル酸 ＋ 酢酸）

※ ここで紹介する実験・製法を実際に行うときは、学校の授業や専門家の指導のもとで、安全に十分注意し、自己責任で行ってください。

地図2に登場する化合物の構造式。六角形がベンゼン環（環内の円は二重結合の広がりを表す）で、環から出た線の先が置換した原子団です。サリチル酸では −OH と −COOH が隣り合う位置（オルト位）に付き、アセチルサリチル酸ではその −OH が −OCOCH3 に変わります。

逆向きにたどる考え方（目的物から原料へ）

合成の問題では、原料ではなく目的物だけが先に決まっていることが普通です。その場合は地図を逆向きに読みます。手順は「目的物の1つ手前を探す」ことの繰り返しです。たとえばアセチルサリチル酸を作りたいなら、まず「何に無水酢酸を反応させればよいか」を考えてサリチル酸にさかのぼり、次に「サリチル酸は何から作るか」でフェノール（の塩）に、さらにクロロベンゼン、ベンゼンへとたどります。矢印を逆にたどるときは、矢印の上の試薬・条件も一緒に逆向きに読むのがコツです。「還元で得られるなら、出発側は酸化された形（ニトロ基）だったはずだ」というように、官能基の変化から1つ手前を推測できます。この「ゴールから逆向きに組み立てる」考え方は、実際の有機合成の設計でも基本の手順になっています。

解き方の手順

  1. 出発点とゴールを丸で囲む。原料（エチレンやベンゼンなどの基本化合物）と目的物を先に特定します。
  2. 矢印の上の言葉から反応の種類を読む。試薬名だけでなく、「酸化」「還元」「付加」「置換」「脱水」といった種類に読み替えると、官能基がどう変わるかが見えます。
  3. 順向きにたどれるか試す。原料から矢印を1本ずつ進み、各段階の生成物を構造式で確認しながらゴールへ向かいます。
  4. 行き詰まったら逆向きにたどる。目的物の1つ手前（何をどう変えれば目的物になるか）から考え、原料までさかのぼって道をつなぎます。
  5. 条件の違いに注意する。同じ原料・同じ試薬でも、温度などの条件で生成物が変わる矢印（エタノールの脱水：140 ℃ではジエチルエーテル、170 ℃ではエチレン）があります。条件まで含めて1つの矢印として覚えます。
  6. 各矢印の反応式を書き、原子数を検算する。C・H・O・N・Cl などの数が両辺で一致しているかを確認すれば、生成物の書き間違いに気づけます。

例題

問題1（エチレンの経路図の空欄埋め）：エチレンを出発点とする次の経路で、A〜E に当てはまる化合物名を答えよ。エチレン ―（H2O 付加）→ A ―（酸化）→ B ―（酸化）→ C。A と C を濃硫酸と加熱すると D ができる。また、エチレンどうしが多数つながると E ができる。

問題2（ベンゼンの経路図の空欄埋めと条件）：ベンゼンからアニリンを作る経路「ベンゼン → F → アニリン」について、F の化合物名と、各矢印の上に書くべき試薬・条件（反応の種類も含む）を答えよ。

問題3（逆向きにたどる）：酢酸エチルをエチレンだけを炭素源として作りたい。経路図を逆向きにたどり、必要な手順を順番に述べよ。

問題4（合成経路を選ぶ）：フェノールからサリチル酸を作るには、フェノールに直接 CO2 を反応させるのではなく、ある手順を挟む。経路図をもとに、その手順と理由を答えよ。また、サリチル酸からアセチルサリチル酸を作るときの試薬も答えよ。

答えと解説を見る
  1. 問題1：A は水の付加でできるエタノール、B はその酸化でできるアセトアルデヒド、C はさらに酸化された酢酸です。D は酢酸とエタノールのエステル化でできる酢酸エチル（CH3COOH ＋ C2H5OH ⇌ CH3COOC2H5 ＋ H2O、両辺とも C4H10O3 で一致）。E は付加重合でできるポリエチレンです。「酸化の階段」をたどる問題は、−OH → −CHO → −COOH という官能基の変化で見分けます。
  2. 問題2：F はニトロベンゼンです。1本目の矢印は「濃硝酸（混酸：濃硝酸と濃硫酸）・約60 ℃」で、反応の種類は置換（ニトロ化）：C6H6 ＋ HNO3 → C6H5NO2 ＋ H2O。2本目の矢印は「スズ（または鉄）と塩酸」で、反応の種類は還元：C6H5NO2 ＋ 6[H] → C6H5NH2 ＋ 2H2O（両辺とも C6H11NO2 で一致）。アニリンの −NH2 は、ニトロ基 −NO2 を還元して作るのが基本の道です。
  3. 問題3：目的物の酢酸エチルから逆向きにたどります。酢酸エチルは酢酸とエタノールのエステル化でできるので、原料は酢酸とエタノールの2つに分かれます。エタノールはエチレンへの水の付加で得られ、酢酸はエタノールを2段階酸化（エタノール → アセトアルデヒド → 酢酸）して得られます。よって手順は「(1) エチレンに水を付加してエタノールを作る。(2) その一部を酸化して酢酸を作る。(3) 酢酸と残りのエタノールを濃硫酸と加熱してエステル化する」となります。逆向きにたどると、必要な原料が途中で枝分かれすることに気づけるのがポイントです。
  4. 問題4：フェノールはまず水酸化ナトリウムでナトリウムフェノキシド（塩）に変えてから CO2 を反応させ、その後塩酸で酸性にしてサリチル酸を取り出します（コルベ・シュミット反応）。塩の形（−ONa）にすると環が反応しやすくなり、−COOH が −ONa の隣の位置に入るためです。全体の式は C6H5ONa ＋ CO2 ＋ HCl → C6H4(OH)COOH ＋ NaCl（両辺とも C7H6O3NaCl で一致）。サリチル酸からアセチルサリチル酸を作る試薬は無水酢酸で、−OH が −OCOCH3 に変わります（C7H6O3 ＋ C4H6O3 → C9H8O4 ＋ C2H4O2、両辺とも C11H12O6 で一致）。

答え：問題1は A エタノール、B アセトアルデヒド、C 酢酸、D 酢酸エチル、E ポリエチレン。問題2は F ニトロベンゼン、矢印は混酸による置換（ニトロ化）と Sn・HCl による還元。問題3は エチレン → エタノール →（一部を酸化して）酢酸、酢酸＋エタノール → 酢酸エチル。問題4は NaOH で塩（ナトリウムフェノキシド）にしてから CO2、次いで HCl。アセチル化の試薬は無水酢酸。

例題に登場する化合物の構造式。A〜C は酸化の階段（−CH2OH → −CHO → −COOH）、D はその合流点、F はベンゼン環に −NO2 が付いた形です。

現場での使われ方

石油化学コンビナートの「地図」そのもの

エチレンは石油化学の最も基本的な原料で、工場ではエチレンからエタノール、酢酸、酢酸エチル、ポリエチレンなどが実際にこの経路図の矢印どおりに生産されています。コンビナートでは、ある工場の生成物が隣の工場の原料になるようにプラントが配置されており、経路図はそのまま産業の配置図になっています。どの矢印（反応）をどの規模で動かすかが、製品の供給量を決めます。

医薬品の合成ルート設計

アセチルサリチル酸（アスピリン）は、ベンゼンからクロロベンゼン、フェノール、サリチル酸を経て作る道が教科書の経路図そのままにたどれます。医薬品の開発では、目的の化合物から逆向きに原料へさかのぼる「逆向きにたどる考え方」が合成ルート設計の基本手順として使われており、安く手に入る原料まで何段階でたどり着けるかが、製造コストを大きく左右します。

染料・香料などのファインケミカル

アニリンは染料や医薬品の中間体（原料と製品の間にある化合物）として大量に使われ、「ベンゼン → ニトロベンゼン → アニリン」の2段階はその代表的な供給ルートです。酢酸エチルは塗料や接着剤の溶剤、マニキュアの除光液などに使われる身近な製品で、こちらも経路図の合流点にあたる化合物です。身の回りの製品名を経路図の上で探すと、どの駅（化合物）から来たものかが見えてきます。

考え出した人

特定の考案者はいない（反応経路図は、19世紀以降に蓄積された個々の有機反応を、合成の手順として整理し直した図の書き方）

反応経路図そのものは、特定の個人が発明した法則ではありません。ニトロ化・還元・酸化・エステル化といった個々の反応は19世紀以降、多くの化学者の研究によって1つずつ確立され、それらが教科書や工場の設計の中で「原料から製品までの地図」として整理されるようになりました。本文で扱った反応のうち、フェノールの塩に二酸化炭素を反応させてサリチル酸を得る方法は、ドイツの化学者ヘルマン・コルベが1860年頃に示し、後に改良されたことからコルベ・シュミット反応と呼ばれます。経路図は、こうした個別の反応の集積を、順向きにも逆向きにも読める形に並べ直したものだと言えます。

関連項目
