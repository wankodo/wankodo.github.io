石油と石油化学

化学の考え方辞典 ― 有機化学（高校化学・3年）

化学ツール集トップ ＞ 有機化学 ＞ 石油と石油化学

高校化学・3年 有機化学

どんな時に使えるか 石油は、原油を沸点の違いで分ける分留によって、石油ガス・ナフサ・灯油・軽油・重油・アスファルトなどの留分に分けられる。中でもナフサを熱分解するとエチレン・プロペン・1,3-ブタジエンなどが得られ、接触改質ではベンゼンなどの芳香族化合物が得られる。これらの基礎原料から、プラスチック・合成繊維・合成ゴムなど多様な石油化学製品が生まれる。

どんな問題に使うか

原油から燃料や化学製品がどう作られるかを扱うときの考え方です。有機化学と高分子化学をつなぐ位置にあり、次のような場面で使います。

  • 分留で得られる留分（石油ガス・ナフサ・灯油・軽油・重油・アスファルト）を、沸点の低い順に並べ、それぞれの用途と結びつける問題
  • ナフサの熱分解で得られるエチレン・プロペン・1,3-ブタジエンと、接触改質で得られるベンゼンなどの芳香族化合物を区別する問題
  • エチレン→ポリエチレン、1,3-ブタジエン→合成ゴムのように、基礎原料と石油化学製品のつながりを答える問題

ポイントは、「分留は沸点の違いで分ける物理的な分離」であり、「熱分解・接触改質は分子そのものを作り替える化学変化」だという区別です。この2段階を分けて考えると、石油化学全体の流れが見通せます。

公式・考え方

原油と分留：沸点の違いで分ける

原油は、地下から産出する炭化水素の混合物です。炭素数が多い分子ほど分子間力が強く、沸点が高くなります。製油所では原油を加熱して蒸気にし、温度が上ほど低くなる分留塔に通します。蒸気は塔を上るにつれて冷え、自分の沸点以下になった段で液体に戻るため、沸点の低い（炭素数の少ない）成分ほど塔の上の方から、沸点の高い成分ほど下の方から取り出せます。この操作を分留（分別蒸留）といい、得られる各部分を留分と呼びます。分留は混合物を分ける操作であり、分子そのものは変化しません。

沸点の低い順（＝炭素数の少ない順）：石油ガス ＜ ナフサ ＜ 灯油 ＜ 軽油 ＜ 重油 ＜ アスファルト（残油）
  • 石油ガス（炭素数およそ1〜4）：プロパン・ブタンが主成分。液化したものが LPガス（液化石油ガス）で、家庭用・業務用燃料やカセットコンロに使われます
  • ナフサ（炭素数およそ5〜12）：粗製ガソリンとも呼ばれます。ガソリンの原料になるとともに、石油化学の最も重要な原料です
  • 灯油（炭素数およそ10〜16）：ストーブなどの暖房用燃料、ジェット燃料に使われます
  • 軽油（炭素数およそ14〜20）：ディーゼルエンジン（トラック・バス・船舶など）の燃料に使われます
  • 重油（炭素数およそ20以上）：火力発電所や大型船舶の燃料、工場のボイラー燃料に使われます
  • アスファルト（残油）：分留の最後に残る高沸点の残り。道路の舗装や防水材に使われます

留分の境目は製油所や教科書によって多少異なり、炭素数や沸点の範囲は重なり合います。ここに挙げた炭素数は目安として捉えてください。大切なのは絶対値ではなく、「炭素数が増えるほど沸点が上がり、塔の下から取り出される」という順序の関係です。

ナフサの熱分解：基礎原料を作る

ナフサをそのまま燃料にするだけでは、プラスチックなどの原料は得られません。そこでナフサを高温（およそ800 ℃）の水蒸気とともに加熱し、大きな分子の結合を切って小さな分子に変える熱分解（クラッキング）を行います。熱分解では、炭素どうしの二重結合をもつエチレン C2H4 とプロペン C3H6、二重結合を2つもつ 1,3-ブタジエン C4H6 などが得られます。これらは反応性の高い二重結合をもち、重合や付加反応の出発点になるため、石油化学の基礎原料と呼ばれます。

※ ここで紹介する実験・製法を実際に行うときは、学校の授業や専門家の指導のもとで、安全に十分注意し、自己責任で行ってください。

接触改質：芳香族化合物を得る

ナフサを白金などの触媒の存在下で反応させる接触改質（リフォーミング）では、鎖状の炭化水素が環状の芳香族化合物に作り替えられ、ベンゼン C6H6・トルエン・キシレン（頭文字をとって BTX とも呼ばれます）が得られます。接触改質はもともとガソリンの性能（オクタン価）を高めるために発達した技術で、ここで得られる芳香族化合物も重要な基礎原料です。つまり基礎原料の供給は、熱分解がアルケン類、接触改質が芳香族類という分担になっています。

熱分解で得られる基礎原料の構造式。いずれも二重結合をもつことが共通点で、この二重結合が開いてつながる付加重合が、プラスチックや合成ゴムへの入口になります。

接触改質で得られる芳香族の基礎原料（ベンゼン・トルエン・キシレン）と、ベンゼンから作られるスチレンの構造式。ベンゼン環の詳しい性質は芳香族化合物の項目で扱います。

基礎原料から石油化学製品へ

基礎原料は、重合や付加反応を経て多様な製品になります。代表的なつながりは次の通りです。

  • エチレン → 付加重合でポリエチレン（袋・フィルム・容器）。水の付加でエタノールにもなります
  • プロペン → 付加重合でポリプロピレン（食品容器・自動車部品・繊維）
  • 1,3-ブタジエン → スチレンと共重合させた SBR など合成ゴム（タイヤ）の原料
  • ベンゼン → スチレンを経てポリスチレン（発泡スチロール・食品トレイ）。また、ナイロン66の原料であるアジピン酸やヘキサメチレンジアミンの出発物質にもなります
  • p-キシレン → テレフタル酸を経て、PET（ペットボトル）やポリエステル繊維の原料になります

プラスチック・合成繊維・合成ゴムそのものの性質や作り方は高分子の項目で詳しく扱います。ここでは、それらの出発点がすべて原油の分留とナフサの変換にあるという全体像をつかむことが目標です。

解き方の手順

  1. 留分は「炭素数→沸点→取り出す位置→用途」の順に結びつける。炭素数が少ないほど沸点が低く、分留塔の上から取り出されます。
  2. 分留と化学変化を区別する。分留は沸点の違いによる分離（分子は不変）、熱分解と接触改質は分子を作り替える化学変化です。
  3. 基礎原料の出所で整理する。熱分解からはエチレン・プロペン・1,3-ブタジエン（アルケン類）、接触改質からはベンゼン・トルエン・キシレン（芳香族類）が得られます。
  4. 製品へのつながりは「二重結合が開いてつながる」付加重合でたどる。エチレン→ポリエチレン、プロペン→ポリプロピレン、ブタジエン→合成ゴム、ベンゼン→スチレン→ポリスチレン、という代表例を押さえます。

例題

問題1（留分と用途）：次の用途に最も適する留分を、石油ガス・ナフサ・灯油・軽油・重油・アスファルトから選べ。（a）カセットコンロの燃料（液化されたもの）（b）石油化学製品の原料として熱分解される留分（c）ジェット燃料やストーブの燃料（d）ディーゼルエンジンの燃料（e）道路舗装の材料

問題2（沸点の順序）：次の留分を沸点の低い順に並べよ。軽油、石油ガス、重油、灯油、ナフサ

問題3（基礎原料と製品）：次の製品の原料となる基礎原料を答えよ。（a）ポリエチレン（b）ポリプロピレン（c）タイヤなどに使われる合成ゴム（主原料の1つ）（d）ポリスチレン（ベンゼンから作られる中間の物質を経由する）

問題4（熱分解と接触改質）：ベンゼン・トルエン・キシレンが主に得られるのは、ナフサの熱分解と接触改質のどちらか。また、エチレンが主に得られるのはどちらか。

答えと解説を見る
  1. 問題1：（a）石油ガス。プロパン・ブタンを液化した LPガスが燃料です。（b）ナフサ。熱分解されてエチレンなどの基礎原料になります。（c）灯油。（d）軽油。（e）アスファルト。分留で最後に残る残油です。
  2. 問題2：炭素数が少ないほど沸点が低いので、石油ガス → ナフサ → 灯油 → 軽油 → 重油 の順です。分留塔ではこの順に上から下へ取り出されます。
  3. 問題3：（a）エチレン C2H4 の付加重合でポリエチレンができます。（b）プロペン C3H6 の付加重合でポリプロピレンができます。（c）1,3-ブタジエン C4H6。スチレンと共重合させた SBR が代表的な合成ゴムです。（d）ベンゼンからスチレンが作られ、その付加重合でポリスチレンができます。
  4. 問題4：ベンゼン・トルエン・キシレン（芳香族化合物）は主に接触改質で得られ、エチレン（アルケン類）は主に熱分解で得られます。「熱分解＝アルケン、接触改質＝芳香族」と対で覚えるのが要点です。

答え：問題1は（a）石油ガス、（b）ナフサ、（c）灯油、（d）軽油、（e）アスファルト。問題2は石油ガス→ナフサ→灯油→軽油→重油。問題3は（a）エチレン、（b）プロペン、（c）1,3-ブタジエン、（d）スチレン（ベンゼンから作られる）。問題4は芳香族が接触改質、エチレンが熱分解。例題に登場する基礎原料の構造式は、本文の図（エチレン・プロペン・1,3-ブタジエン／ベンゼン・トルエン・p-キシレン・スチレン）にすべて示してあります。

現場での使われ方

製油所の分留塔と石油化学コンビナート

原油はタンカーで製油所に運ばれ、巨大な分留塔で留分ごとに分けられます。製油所の近くには石油化学工場が集まったコンビナートが作られることが多く、パイプラインで送られたナフサが熱分解装置（エチレンプラント）で基礎原料に変えられ、さらに下流の工場でプラスチックや合成繊維の原料に加工されます。エチレンの生産量は、その国の石油化学工業の規模を示す目安として使われます。

燃料の使い分け

留分は性質に合わせて燃料として使い分けられます。ガソリンは自動車の火花点火エンジン、軽油はディーゼルエンジン、灯油は暖房とジェット燃料、重油は発電所や大型船舶、LPガスは家庭・業務用と、沸点と燃え方の違いがそのまま用途の違いになっています。身近な燃料の名前は、分留の留分の名前とほぼ対応しています。

身の回りの石油化学製品

ペットボトル（PET）、発泡スチロール、衣料のポリエステルやナイロン、自動車のタイヤ（合成ゴム）、プラスチック容器や袋など、身の回りの製品の多くは石油化学製品です。これらはすべて「原油→分留→ナフサ→基礎原料→重合」というこの項目の流れの先にあります。一方で、プラスチックごみや二酸化炭素排出の問題から、リサイクルや植物由来原料への置き換えも進められています。

考え出した人

特定の発明者はいない ― 原油の分留と石油化学は、19世紀後半から20世紀にかけて多くの技術者・企業によって発展した工業技術である

石油の利用は、1859年にアメリカ・ペンシルベニア州でエドウィン・ドレークが油井の掘削に成功し、ランプ用燃料としての灯油の需要が広がったことから本格化しました。当初は灯油以外の留分はあまり活用されませんでしたが、自動車の普及でガソリンの需要が増え、1913年にはウィリアム・バートンらが重質油を熱で分解してガソリンを増やす熱分解（クラッキング）の工業化に成功しました。その後、接触改質やナフサの熱分解による基礎原料の生産が発達し、20世紀半ば以降、燃料のためだった石油精製が、プラスチック・合成繊維・合成ゴムを生む石油化学工業へと広がっていきました。特定の一人の発明ではなく、精製技術と触媒技術の積み重ねの上に成り立つ技術です。
