配位結合と錯イオン

高校化学・3年 化学結合

どんな時に使えるか 一方の原子がもつ非共有電子対を、もう一方の原子が受け取って共有する結合が配位結合で、金属イオンに分子やイオンが配位結合で結びついたイオンが錯イオンである。中心の金属イオンに直接結びついた原子の数が配位数で、配位子の種類と数、中心金属の酸化数によって錯イオンの名前と電荷が決まり、遷移元素の錯イオンは特有の色を示すものが多い。

どんな問題に使うか

アンモニアや水のような分子が金属イオンに結びついてできる錯イオンの、つくり・名前・電荷・色を扱うときの考え方です。次のような場面で使います。

  • 配位結合が通常の共有結合とどう違うかを、非共有電子対の出どころで説明する問題
  • テトラアンミン銅（II）イオン [Cu(NH3)4]2+ のような錯イオンについて、配位数・名前・電荷を求める問題
  • 中心金属イオンの酸化数を、錯イオン全体の電荷と配位子の電荷から逆算する問題
  • 硫酸銅（II）水溶液にアンモニア水を加えたときの色の変化のように、錯イオンの生成と色を結びつける問題（遷移元素の性質とセットで出題される）

ポイントは、錯イオンを「中心の金属イオン＋まわりの配位子」という組み立てで読み、電荷は部品の電荷の合計として数えることです。

公式・考え方

通常の共有結合では、2つの原子が電子を1個ずつ出し合って電子対を作ります。これに対して配位結合は、一方の原子がもつ非共有電子対（孤立電子対）を、もう一方の原子がそっくり受け取って共有する結合です。たとえばアンモニウムイオン NH4+ では、アンモニア NH3 の窒素原子の非共有電子対が水素イオン H+ に提供され、N−H 結合が1本できます。いったんできてしまえば、その結合は他の3本の N−H 結合と区別がつきません。

金属イオンに、非共有電子対をもつ分子やイオンが配位結合でいくつか結びついたイオンを錯イオンといいます。中心にある金属イオンを中心金属イオン、結びつく分子・イオンを配位子といい、中心金属イオンに直接結びついた原子の数を配位数といいます。配位子が結びつくのは、配位子側に非共有電子対があるからです。

錯イオンの電荷 ＝ 中心金属イオンの電荷 ＋（配位子の電荷 × 個数）の合計

代表的な配位子と、その電荷は次の通りです。分子である配位子は電荷が0、陰イオンである配位子はそのイオンの電荷をもちます。

  • アンモニア NH3：配位子名は「アンミン」、電荷0。窒素の非共有電子対で結びつく
  • 水 H2O：配位子名は「アクア」、電荷0。酸素の非共有電子対で結びつく
  • シアン化物イオン CN−：配位子名は「シアニド」、電荷 −1
  • 塩化物イオン Cl−：配位子名は「クロリド」、電荷 −1
  • 水酸化物イオン OH−：配位子名は「ヒドロキシド」、電荷 −1

テトラアンミン銅（II）イオン [Cu(NH3)4]2+ のつくり。4つの NH3 が、それぞれ窒素の非共有電子対を Cu2+ に提供して配位結合しています。配位数は、中心金属に直接結びついた窒素原子の数で4です。

錯イオンの名前は、配位子の数（ギリシャ数詞）＋配位子名＋中心金属名＋（酸化数をローマ数字で）＋イオンの順に組み立てます。数の数え方は、1＝（通常省略）、2＝ジ、3＝トリ、4＝テトラ、5＝ペンタ、6＝ヘキサです。錯イオン全体が陰イオンのときは、金属名の後ろに「酸」を付けて「〜酸イオン」とします。

  • [Cu(NH3)4]2+：テトラアンミン銅（II）イオン。配位数は4。電荷は Cu2+ の +2 と NH3 の 0×4 の合計で +2。深い青色を示す
  • [Ag(NH3)2]+：ジアンミン銀（I）イオン。配位数は2。電荷は Ag+ の +1 と 0×2 の合計で +1。無色
  • [Zn(NH3)4]2+：テトラアンミン亜鉛（II）イオン。配位数は4。無色
  • [Fe(CN)6]4−：ヘキサシアニド鉄（II）酸イオン。配位数は6。電荷 −4 から逆算すると鉄の酸化数は +2（+2 ＋ (−1)×6 ＝ −4）
  • [Al(OH)4]−：テトラヒドロキシドアルミン酸イオン。配位数は4。電荷は Al3+ の +3 と OH− の (−1)×4 の合計で −1

配位数と立体的な形には対応があり、配位数2では直線形（[Ag(NH3)2]+）、配位数4では正四面体形（[Zn(NH3)4]2+）や平面正方形、配位数6では正八面体形（[Fe(CN)6]4−）が代表的です。

色については、遷移元素のイオンは水溶液中で水分子が配位した錯イオンとして存在し、特有の色を示します。Cu2+ の水溶液が青色なのはアクア錯イオンの色で、ここにアンモニアが配位すると、より深い青色のテトラアンミン銅（II）イオンに変わります。配位子が替わると吸収する光の色が変わるため、錯イオンの色は配位子の種類でも変化します。

解き方の手順

  1. 中心金属イオンと配位子を切り分ける。角括弧 [ ] の中身が錯イオンで、金属が中心、まわりの分子・イオンが配位子です。括弧の外のイオンは相手イオンで、錯イオンの一部ではありません。
  2. 配位数を数える。中心金属に直接結びついた原子の数です。ここで挙げた配位子はどれも原子1個で結びつくので、配位子の個数＝配位数になります。
  3. 電荷を部品ごとに合計する。中心金属イオンの電荷に、配位子の電荷×個数を足します。分子の配位子（NH3、H2O）は0、陰イオンの配位子（CN−、Cl−、OH−）はその電荷で計算します。合計が角括弧の右上の電荷と一致するか確認します。
  4. 酸化数を逆算する。中心金属の酸化数が分からないときは、（錯イオンの電荷）−（配位子の電荷の合計）を計算します。これが名前の（II）や（III）に入る数です。
  5. 名前を組み立てる。「数の数詞＋配位子名＋金属名＋（酸化数）＋イオン」の順に並べ、錯イオン全体が陰イオンなら金属名の後に「酸」を付けます。

例題

問題1：硫酸銅（II）の青色水溶液にアンモニア水を少量加えると水酸化銅（II）の青白色（淡青色）の沈殿が生じ、さらに過剰に加えると沈殿が溶けて深い青色の溶液になる。この深い青色のイオンの化学式・名前・配位数を答えよ。問題2：[Ag(NH3)2]+ の名前と配位数を答え、電荷が +1 になることを部品の電荷から確かめよ。問題3：[Fe(CN)6]4− について、鉄の酸化数と配位数を求め、名前を答えよ。

答えと解説を見る
  1. 問題1：過剰のアンモニアの中で Cu2+ に NH3 が4つ配位結合し、[Cu(NH3)4]2+ が生じます。配位子はアンミン、数は4で「テトラ」、銅の酸化数は +2 のままなので、名前はテトラアンミン銅（II）イオン、配位数は4です。電荷は +2 ＋ 0×4 ＝ +2 で、式の右上の 2+ と一致します。
  2. 問題2：配位子アンミンが2つなので「ジ」アンミン、銀の酸化数は +1 だから、名前はジアンミン銀（I）イオン、配位数は2です。電荷は Ag+ の +1 ＋ NH3 の 0×2 ＝ +1 で、式の + と一致します。
  3. 問題3：鉄の酸化数を x とすると、配位子 CN− が6つで電荷の合計は −6 です。x ＋ (−6) ＝ −4 より x ＝ +2、つまり酸化数は+2（II）です。配位数は6で、錯イオン全体が陰イオンなので金属名の後に「酸」を付け、名前はヘキサシアニド鉄（II）酸イオンです。

答え：問題1は [Cu(NH3)4]2+、テトラアンミン銅（II）イオン、配位数4。問題2はジアンミン銀（I）イオン、配位数2（電荷は +1＋0×2＝+1）。問題3は酸化数 +2、配位数6、ヘキサシアニド鉄（II）酸イオン。どの問題も「電荷の合計が式の右上と合うか」を最後に確かめることが検算になります。

現場での使われ方

金属イオンの検出・分析（沈殿を錯イオンで溶かす）

塩化銀 AgCl の白色沈殿は水に溶けませんが、アンモニア水を加えるとジアンミン銀（I）イオン [Ag(NH3)2]+ を生じて溶けます。この「沈殿が錯イオンになって溶ける」性質は、陽イオンの系統分析で銀イオンを確認する手がかりとして実際に使われます。また、ジアンミン銀（I）イオンを含む溶液（トレンス試薬／アンモニア性硝酸銀溶液）は、アルデヒドと反応して銀を析出させる銀鏡反応の試薬として、分析や教材実験で使われます。

血液と光合成を担う錯体（ヘモグロビンとクロロフィル）

血液中で酸素を運ぶヘモグロビンは、中心に鉄イオンをもつ錯体（ヘム）を含み、鉄に酸素分子が配位結合することで酸素を運びます。植物の光合成色素クロロフィル（葉緑素）は、中心にマグネシウムイオンをもつ錯体です。生体の中で金属イオンに分子が配位する仕組みそのものが、生命活動の土台になっています。

医薬とめっき・触媒（シスプラチンと錯塩）

抗がん剤のシスプラチンは、白金に塩化物イオンとアンモニアが配位した錯体で、配位子が平面正方形に並んだ構造が薬効と結びついています。また、金や銀のめっきでは、シアン化物イオンと金属の錯イオンを含むめっき液が使われてきました。錯イオンにすることで金属イオンの濃度や析出のしかたを細かく制御できる点が、工業的に利用されています。

考え出した人

アルフレート・ウェルナー（1866〜1919、スイスの化学者）

錯イオンの構造を体系的に説明したのは、スイスの化学者アルフレート・ウェルナー（1866〜1919）です。それまでの化学では、金属塩にアンモニアなどが結びついた化合物（錯塩）のつくりをうまく説明できませんでした。ウェルナーは1893年に、中心の金属原子のまわりに配位子が決まった数だけ立体的に並ぶという配位説を提唱し、配位数や立体構造の考え方を打ち立てました。この業績により、ウェルナーは1913年にノーベル化学賞を受賞しています。今日の「配位数」「配位子」という言葉と、錯イオンを立体的に捉える見方は、ウェルナーの理論が土台になっています。
