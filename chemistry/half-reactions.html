酸化剤と還元剤・半反応式

化学の考え方辞典 ― 酸化還元・電池と電気分解（高校化学基礎・1年）

化学ツール集トップ ＞ 酸化還元・電池と電気分解 ＞ 酸化剤と還元剤・半反応式

高校化学基礎・1年 酸化還元・電池と電気分解

どんな時に使えるか 酸化剤が電子を受け取る反応と、還元剤が電子を放出する反応を、それぞれ電子を含む式で表したものが半反応式である。酸化数の変化をもとに、H2O と H+ で原子の数を合わせ、電子で電荷を合わせれば、代表的な酸化剤・還元剤の半反応式を自分で作ることができ、電子の係数から酸化剤・還元剤の価数も読み取れる。

どんな問題に使うか

酸化還元反応を、電子を受け取る側（還元）と電子を放出する側（酸化）に分けて表すときの考え方です。次のような場面で使います。

  • 過マンガン酸イオンや二クロム酸イオンなど、代表的な酸化剤の半反応式を書く問題
  • 硫化水素や二酸化硫黄など、代表的な還元剤の半反応式を書く問題
  • 半反応式の電子 e− の係数から、酸化剤・還元剤の価数（1 mol あたり授受する電子の物質量）を読み取る問題
  • 2つの半反応式を組み合わせて、酸化還元反応全体の反応式（イオン反応式）を作る問題の下準備

ポイントは、酸化剤は電子を受け取って自身は還元され、還元剤は電子を放出して自身は酸化されることです。酸化剤の半反応式では電子が左辺に、還元剤の半反応式では電子が右辺に来ます。

公式・考え方

酸化還元反応では、電子を放出する反応と受け取る反応が必ず対になって起こります。この片方だけを取り出して、電子 e− を含む式で表したものを半反応式といいます。半反応式では、通常の化学反応式と同じく原子の数が両辺で一致することに加えて、電子の電荷も含めた電荷の総和も両辺で一致しなければなりません。

代表的な酸化剤の半反応式（酸性条件）

酸化剤は電子を受け取るので、電子は左辺にあります。括弧内は酸化剤の価数（受け取る電子の数）です。

過マンガン酸イオン： MnO4− ＋ 8H+ ＋ 5e− → Mn2+ ＋ 4H2O（価数5）
二クロム酸イオン： Cr2O72− ＋ 14H+ ＋ 6e− → 2Cr3+ ＋ 7H2O（価数6）
過酸化水素： H2O2 ＋ 2H+ ＋ 2e− → 2H2O（価数2）
希硝酸： NO3− ＋ 4H+ ＋ 3e− → NO ＋ 2H2O（価数3）
濃硝酸： NO3− ＋ 2H+ ＋ e− → NO2 ＋ H2O（価数1）
熱濃硫酸： H2SO4 ＋ 2H+ ＋ 2e− → SO2 ＋ 2H2O（価数2）
酸素： O2 ＋ 4H+ ＋ 4e− → 2H2O（価数4）

硝酸は濃さによって生成物が変わります。希硝酸では一酸化窒素 NO が、濃硝酸では二酸化窒素 NO2 が生じ、受け取る電子の数（価数）も変わります。硫酸が酸化剤として働くのは、熱した濃硫酸の場合に限られます。

代表的な還元剤の半反応式

還元剤は電子を放出するので、電子は右辺にあります。括弧内は還元剤の価数（放出する電子の数）です。

硫化水素： H2S → S ＋ 2H+ ＋ 2e−（価数2）
二酸化硫黄： SO2 ＋ 2H2O → SO42− ＋ 4H+ ＋ 2e−（価数2）
鉄（II）イオン： Fe2+ → Fe3+ ＋ e−（価数1）
シュウ酸： H2C2O4 → 2CO2 ＋ 2H+ ＋ 2e−（価数2）
過酸化水素： H2O2 → O2 ＋ 2H+ ＋ 2e−（価数2）

過酸化水素 H2O2 は、相手が強い還元剤のときは酸化剤として、相手が強い酸化剤のときは還元剤として働く、両方の顔を持つ物質です。どちらの半反応式を使うかは、反応相手によって決まります。

価数の読み取り

半反応式に現れる電子の係数が、その物質の価数です。たとえば MnO4− の半反応式では電子の係数が5なので、MnO4− 1 mol は電子 5 mol を受け取り、酸化剤としての価数は5です。価数は、酸化還元滴定などで「酸化剤と還元剤が何 mol 対何 mol でちょうど反応するか」を決める手がかりになります。

  • e−：電子。電荷は −1。酸化剤の半反応式では左辺、還元剤の半反応式では右辺に書く
  • 価数：物質 1 mol が授受する電子の物質量 [mol]。半反応式の電子の係数と一致する（単位は付けずに「価数5」のように表す）
  • H+・H2O：酸性条件で原子の数を合わせるために使う。水素イオンが豊富にある酸性水溶液での反応が前提

解き方の手順

酸性条件での半反応式の作り方です。例として、過マンガン酸イオン MnO4− が Mn2+ に変化する反応で流れを追います。

  1. 酸化数の変化を確認し、反応物と生成物を書く。Mn の酸化数は MnO4− 中では ＋7、Mn2+ では ＋2。酸化数が減るので還元、つまり電子を受け取る反応です。まず MnO4− → Mn2+ と書きます。
  2. 酸素原子の数を、H2O を加えて合わせる。左辺に O が4個あるので、右辺に 4H2O を加えます。MnO4− → Mn2+ ＋ 4H2O。
  3. 水素原子の数を、H+ を加えて合わせる。右辺に H が8個あるので、左辺に 8H+ を加えます。MnO4− ＋ 8H+ → Mn2+ ＋ 4H2O。
  4. 電荷を電子 e− で合わせる。左辺の電荷は −1＋8 ＝ ＋7、右辺は ＋2。その差の5だけ、左辺に 5e− を加えると両辺とも ＋2 になります。MnO4− ＋ 8H+ ＋ 5e− → Mn2+ ＋ 4H2O。
  5. 検算する。原子の数（Mn・O・H）と電荷の総和が、両辺で一致しているかを最後に必ず確認します。還元剤の半反応式でも手順は同じで、電子は右辺に現れます。

なお、中性・塩基性条件では H+ の代わりに H2O と OH− を使って合わせますが、高校化学基礎で扱う代表的な半反応式は、ほとんどが酸性条件のものです。

例題

問題1：酸性条件で、硫化水素 H2S が硫黄 S に変化する半反応式を書け。問題2：酸性条件で、二クロム酸イオン Cr2O72− がクロム（III）イオン Cr3+ に変化する半反応式を書き、二クロム酸イオンの酸化剤としての価数を答えよ。問題3：二酸化硫黄 SO2 が硫酸イオン SO42− に変化する半反応式を書き、二酸化硫黄の還元剤としての価数を答えよ。問題4：鉄（II）イオン Fe2+ が鉄（III）イオン Fe3+ に変化する半反応式を書け。

答えと解説を見る
  1. 問題1：S の酸化数は H2S 中では −2、単体の S では 0。酸化数が増えるので酸化、つまり電子を放出する反応です。H2S → S と書き、H を合わせるために右辺へ 2H+ を加え、電荷を合わせるために右辺へ 2e− を加えます。H2S → S ＋ 2H+ ＋ 2e−。検算すると、電荷は左辺 0、右辺 ＋2−2 ＝ 0 で一致します。
  2. 問題2：Cr の酸化数は Cr2O72− 中では ＋6、Cr3+ では ＋3 で、還元の反応です。Cr2O72− → 2Cr3+ と書き、O を合わせるため右辺へ 7H2O、H を合わせるため左辺へ 14H+ を加えます。電荷は左辺が −2＋14 ＝ ＋12、右辺が ＋6 なので、左辺へ 6e− を加えて両辺とも ＋6 にします。Cr2O72− ＋ 14H+ ＋ 6e− → 2Cr3+ ＋ 7H2O。電子の係数が6なので、価数は6です。
  3. 問題3：S の酸化数は SO2 中では ＋4、SO42− 中では ＋6 で、酸化の反応です。SO2 → SO42− と書き、O を合わせるため左辺へ 2H2O、H を合わせるため右辺へ 4H+ を加えます。電荷は左辺 0、右辺 −2＋4 ＝ ＋2 なので、右辺へ 2e− を加えて両辺とも 0 にします。SO2 ＋ 2H2O → SO42− ＋ 4H+ ＋ 2e−。電子の係数が2なので、価数は2です。
  4. 問題4：原子の数はすでに合っているので、電荷だけを合わせます。右辺へ e− を1つ加えて、Fe2+ → Fe3+ ＋ e−。電荷は左辺 ＋2、右辺 ＋3−1 ＝ ＋2 で一致します。

答え：問題1は H2S → S ＋ 2H+ ＋ 2e−。問題2は Cr2O72− ＋ 14H+ ＋ 6e− → 2Cr3+ ＋ 7H2O で価数6。問題3は SO2 ＋ 2H2O → SO42− ＋ 4H+ ＋ 2e− で価数2。問題4は Fe2+ → Fe3+ ＋ e−。どの式も、原子の数と電荷の総和の両方が両辺で一致していることが完成の条件です。

現場での使われ方

酸化還元滴定

過マンガン酸カリウム水溶液で鉄（II）イオンやシュウ酸、過酸化水素の量を測る酸化還元滴定は、半反応式の価数にもとづいて計算します。MnO4− の価数5と Fe2+ の価数1から、両者は物質量比 1：5 でちょうど反応すると分かり、滴定に使った体積から未知の濃度が求まります。製鉄所の品質管理や医薬品の分析などで実際に使われている方法です。

水質検査（COD測定）

河川や排水の汚れの指標である COD（化学的酸素要求量）の測定では、試料水に過マンガン酸カリウムを加え、有機物などの還元性物質が消費する酸化剤の量を半反応式の電子の授受で換算します。半反応式は、水質管理の実務でも量の物差しとして働いています。

電池・電気分解の電極反応の記述

電池の負極・正極や電気分解の陰極・陽極で起こる反応は、どれも半反応式で書かれます。たとえばダニエル電池の負極は Zn → Zn2+ ＋ 2e−、正極は Cu2+ ＋ 2e− → Cu という2つの半反応式の組み合わせです。新しい電池材料の研究でも、電極反応を半反応式で整理することが出発点になります。

考え出した人

特定の考案者はいない（電子の授受で酸化還元を表す書き方は、電気化学の発展の中で確立した）

半反応式は、特定の誰かが発明したものではありません。その土台を作ったのは、イギリスの科学者マイケル・ファラデー（1791〜1867）です。ファラデーは1830年代に電気分解の法則を確立し、流れた電気量と化学変化の量が比例することを示しました。つまり、電子の授受を「数えて」扱えることが、この時点で実験から裏づけられていたのです。その後、19世紀末に電子そのものが粒子として確認されると、酸化還元反応を「電子を受け取る半分」と「電子を放出する半分」に分けて書く半反応式の表し方が、電気化学の共通の書き方として定着しました。
