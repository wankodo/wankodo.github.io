ジョルダン標準形

数学解法辞典 ― 線形代数（大学）

数学ツール集トップ ＞ 線形代数 ＞ ジョルダン標準形

大学 線形代数 計算機あり

どんな時に使えるかジョルダン標準形は、対角化できない行列でも必ず行き着ける「最終形」で、連立線形微分方程式の解の形の決定（t·e^(λt) の項が現れるかどうか）や制御工学の状態方程式の解析、行列の累乗の計算に使われる。固有値が重なっても行列の振る舞いを完全に見通せる、線形代数の到達点である。

どんな問題に使うか

行列を、似た形（相似な行列）の中でいちばん単純な形に変形する問題です。対角化はその特別な場合で、固有ベクトルが足りずに対角化できない行列でも、ジョルダン標準形には必ず変形できます。

  • 固有値が重解の行列が、対角化できるかジョルダン細胞になるかを判定する問題
  • 行列のジョルダン標準形を求める問題
  • ジョルダン標準形を使って行列の累乗（n乗）を計算する問題
  • 連立線形微分方程式の解の形を、ジョルダン標準形から読み取る問題

固有値・固有ベクトルの項目で学ぶ対角化の続きにあたる項目です。対角化は「固有ベクトルが十分に取れる場合」の話で、取れない場合の受け皿がジョルダン標準形になります。

公式・考え方

どんな正方行列も、複素数の範囲では、適当な正則行列 P による相似変換 P−1AP でジョルダン標準形に変形できます。対角化できるかどうかは運次第でも、ジョルダン標準形には必ずできる、というのがこの理論の核心です。

ジョルダン標準形は、対角線上にジョルダン細胞と呼ばれるブロックを並べた形です。ジョルダン細胞は、対角成分がすべて同じ固有値 λ で、その1つ上の成分（上対角成分）がすべて 1 のブロックです。

ジョルダン細胞（2×2）＝ [λ 1; 0 λ]（1行目：λ 1／2行目：0 λ）

固有ベクトルが十分に取れる固有値については、細胞は1×1（ただの対角成分）になります。つまり対角形は「すべての細胞が1×1のジョルダン標準形」であり、対角化はジョルダン標準形の特別な場合です。固有値が重解でも固有ベクトルが足りないと、2×2以上の細胞が現れます。

2×2行列では、固有方程式 λ² − tλ ＋ Δ ＝ 0（t はトレース、Δ は行列式）の判別式 D ＝ t² − 4Δ で場合が分かれます。D ＞ 0 なら異なる固有値が2つで対角形、D ＝ 0 なら重解で、行列が λI そのものでなければジョルダン細胞になります。

解き方の手順

  1. 固有方程式を作る。トレース t ＝ a ＋ d と行列式 Δ ＝ ad − bc から、λ² − tλ ＋ Δ ＝ 0 と立てる。
  2. 判別式 D ＝ t² − 4Δ を計算する。固有値が異なる2つか、重解か、複素数かがここで決まる。
  3. D ＞ 0 の場合：異なる2つの実固有値 λ ＝ (t ± √D) / 2 が取れ、固有ベクトルも2本取れるので、標準形は対角形 diag(λ1, λ2)。
  4. D ＜ 0 の場合：複素固有値 t/2 ± i·√(−D)/2 になる。実数の範囲では対角化できないが、複素数の範囲では対角形になる。
  5. D ＝ 0 の場合：固有値は重解 λ ＝ t/2。行列が λI そのもの（b ＝ c ＝ 0 かつ a ＝ d ＝ λ）なら固有ベクトルが2本取れて対角形、そうでなければ固有ベクトルは1本だけで、ジョルダン細胞 [λ 1; 0 λ] になる。
  6. 最終形を書く。対角形かジョルダン細胞かを明示して答える。

例題

問題：行列 [[2, 1], [0, 2]]（1行目：2 1／2行目：0 2）のジョルダン標準形を求めよ。

答えと解説を見る

トレース t ＝ 2 ＋ 2 ＝ 4、行列式 Δ ＝ 2×2 − 1×0 ＝ 4 なので、固有方程式は λ² − 4λ ＋ 4 ＝ (λ − 2)² ＝ 0、固有値は 2（重解）です。

固有ベクトルは (A − 2I)v ＝ 0、つまり [[0, 1], [0, 0]] v ＝ 0 を解いて得られ、v は (1, 0) 方向の1本しか取れません。行列が 2I そのものではないため、対角化はできません。

したがって標準形はジョルダン細胞になります。もとの行列自体が、すでに対角成分 2・上対角成分 1 のジョルダン細胞の形をしています。

答え：ジョルダン標準形は [[2, 1], [0, 2]]（固有値 2 のジョルダン細胞）

現場での使われ方

連立線形微分方程式の解の形の決定

連立線形微分方程式 x' ＝ Ax の解は、A のジョルダン標準形で形が決まります。対角化できる場合は e^(λt) の組み合わせだけですが、ジョルダン細胞があると、解に t·e^(λt) のような「t が掛かった項」が現れます。振動や共振、減衰の仕方が変わる分岐点が、細胞があるかどうかで決まるのです。

制御工学の状態方程式の解析

制御工学では、システムを状態方程式 x' ＝ Ax ＋ Bu の形で表し、A の固有値（極）の位置で安定性を判定します。重解の極がある場合にシステムがどう振る舞うかは、対角化できるかジョルダン細胞になるかで変わるため、標準形による解析が設計の基礎になっています。

行列の累乗の計算

行列の n 乗 A^n は、もとの形のままでは計算が大変ですが、ジョルダン標準形 J に変形すれば J^n が規則的に計算でき、A^n ＝ P J^n P−1 と戻せます。ジョルダン細胞の累乗には二項係数が現れる形の公式があり、マルコフ連鎖の n ステップ遷移や漸化式の一般項など、繰り返し適用する計算の土台になります。

考え出した人

カミーユ・ジョルダン（1838〜1922、フランスの数学者）

フランスの数学者カミーユ・ジョルダン（1838〜1922）が、1870年に標準形の理論を提示しました。行列（当時は線形変換の置換の理論として）を、相似なものの中で最も単純な形に帰着させるこの結果は、群論の創始者の一人でもあるジョルダンの代表的な業績で、「ジョルダン標準形」の名前は彼に由来します。

関連項目

ジョルダン標準形は、固有値・固有ベクトルの項目で扱う対角化の続きです。対角化は固有ベクトルが十分に取れる場合の標準形であり、取れない場合まで含めて必ず行き着ける形がジョルダン標準形だと捉えると、線形代数の全体像がつながります。行列のランクと線形独立の項目も、固有ベクトルの本数を考える土台としてあわせて読むと理解が深まります。数学ツール集トップへ戻る
