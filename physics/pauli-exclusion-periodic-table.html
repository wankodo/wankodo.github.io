パウリの排他原理と周期表

大学 原子・量子・素粒子

どんな時に使えるか 原子の中で電子がどの軌道に何個まで入れるかを決めるパウリの排他原理を知りたいときに使う。量子数の組み合わせは1つの電子ごとに重複が許されず、この制限が殻の収容数と周期表の並びをそのまま決めている。

どんな問題に使うか

原子の電子配置と、周期表の並びの理由を説明するときの解法です。次のような場面で使います。

  • 量子数（n, l, m, s）の組み合わせの数を数え、殻や軌道の収容数を求める問題
  • 原子番号から電子配置（1s2 2s2 2p6 …）を書く問題
  • 元素が周期表のその位置に来る理由や、似た化学的性質を持つ元素が縦に並ぶ理由を説明する問題
  • なぜ電子が全て一番低い軌道に落ち込まず、原子に大きさと構造が生まれるかを説明する問題

土台はシュレーディンガー方程式の考え方です。水素原子の方程式を解くと、電子の状態は量子数の組で指定されます。そこに排他原理が加わることで、多電子原子の構造と周期表が一気に説明できるようになります。

公式・考え方

1つの原子の中で、(n, l, m, s) の組が完全に同じ電子は2個以上存在できない

これがパウリの排他原理です。4つの量子数の意味は次の通りです。

  • n（主量子数）：1, 2, 3, …。殻（K殻、L殻、M殻、…）とエネルギーの大まかな大きさを決める
  • l（方位量子数）：0 から n−1 まで。軌道の形を決め、l ＝ 0, 1, 2, 3 を s, p, d, f 軌道と呼ぶ
  • m（磁気量子数）：−l から ＋l までの整数。軌道の向きの数（2l＋1 通り）を決める
  • s（スピン量子数）：＋1/2 と −1/2 の2通り。電子のスピンの向きを表す

収容数はこの数え方から機械的に出ます。1つの軌道（n, l, m が決まった状態）には s の2通り分、つまり電子2個までしか入れません。副殻（l が決まった集まり）には軌道が 2l＋1 個あるので収容数は 2(2l＋1) 個、すなわち s 軌道は2個、p 軌道は6個、d 軌道は10個、f 軌道は14個です。殻全体では n に対して 2n2 個となり、K殻（n＝1）は2個、L殻（n＝2）は8個、M殻（n＝3）は18個です。周期表の各周期の長さ 2, 8, 8, 18, 18, 32… は、この収容数と軌道が埋まる順序（エネルギーの低い順：1s → 2s → 2p → 3s → 3p → 4s → 3d → …）から決まります。なお、同じ副殻の中では電子はまず別々の軌道に1個ずつ入る傾向があり、これをフントの規則といいます。

化学との接続もここにあります。化学反応で主役になるのは一番外側の電子（価電子）で、最外殻の電子配置が似た元素同士は似た性質を持ちます。周期表で同じ族（縦の列）に性質の似た元素が並ぶのは、排他原理と軌道の埋まる順序の結果なのです。もし排他原理がなければ、全ての電子が 1s 軌道に落ち込み、原子ごとの個性も化学結合の多様性も生まれません。

解き方の手順

  1. 原子番号 Z ＝ 電子の総数を確認する。中性原子では電子の数は原子番号と等しくなります。
  2. エネルギーの低い軌道から順に埋める。順序は 1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p → … です。
  3. 各副殻の上限を守る。s は2個、p は6個、d は10個、f は14個までです（排他原理からの帰結）。
  4. 合計が Z と一致するか検算する。上付きの数字の合計が電子の総数に等しいことを必ず確認します。
  5. 最外殻の電子数から周期表の位置を読む。何番目の周期かは最大の n、族の手がかりは最外殻の電子配置です。

例題

問題：ナトリウム（原子番号 Z ＝ 11）の基底状態の電子配置を書け。また、M殻（n ＝ 3）の収容数が18個であることを量子数から示せ。

答えと解説を見る
  1. 電子は11個です。エネルギーの低い順に埋めると、1s に2個、2s に2個、2p に6個で、ここまでで 2＋2＋6 ＝ 10 個です。
  2. 残り1個は次の 3s に入ります。よって電子配置は 1s2 2s2 2p6 3s1 で、合計は 2＋2＋6＋1 ＝ 11 個と一致します。
  3. M殻（n ＝ 3）では l ＝ 0, 1, 2 が取れます。軌道の数は l ＝ 0 で1個、l ＝ 1 で3個、l ＝ 2 で5個、合計9個です。各軌道にスピンの2通りで電子2個まで入るので、収容数は 9 × 2 ＝ 18 個となり、2n2 ＝ 2 × 32 ＝ 18 と一致します。

答え：ナトリウムの電子配置は 1s2 2s2 2p6 3s1。M殻の収容数は18個。ナトリウムは最外殻（3s）に電子を1個だけ持つため、その1個を失って陽イオンになりやすいという化学的性質が、電子配置からそのまま読み取れます。周期表でナトリウムが第3周期・1族に位置する理由もこれです。

現場での使われ方

分光分析と元素の同定

物質を熱したり放電したりすると、電子が軌道の間を遷移して元素固有の波長の光を出します（炎色反応もその一種です）。どの遷移が許されるかは量子数と排他原理で決まる電子配置に支配されており、この輝線スペクトルを読み取る分光分析は、金属材料の成分検査、環境分析、天体の組成の調査など、現場の分析技術の土台になっています。

半導体と材料設計

シリコン（Z ＝ 14、電子配置は最外殻に4個）をはじめ、半導体の性質は最外殻の電子配置で決まります。ドーピングで使うリンやホウ素の選定も、周期表での位置＝電子配置の近さが基準です。新しい電池材料や触媒の候補探しでも、まず周期表と電子配置から当たりを付けるのが材料設計の出発点になっています。

考え出した人

排他原理を提唱したのはオーストリアのヴォルフガング・パウリ（1900〜1958）で、1925年に原子スペクトルの分析からこの規則を打ち立てました。電子のスピンの導入と結び付いて原子構造の理解が完成し、パウリは1945年にノーベル物理学賞を受賞しています。周期表そのものは、1869年にロシアのドミトリ・メンデレーエフ（1834〜1907）が元素の性質の周期性から提案したものですが、その並びの「なぜ」に量子力学が答えを与えたのが排他原理でした。
