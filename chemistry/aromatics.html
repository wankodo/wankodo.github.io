芳香族化合物

化学の考え方辞典 ― 有機化学（高校化学・3年）

化学ツール集トップ ＞ 有機化学 ＞ 芳香族化合物

高校化学・3年 有機化学

どんな時に使えるか 芳香族化合物は、正六角形のベンゼン環をもつ化合物の仲間で、環の中の炭素どうしの結合は単結合と二重結合の中間の長さでそろっている。この特別な安定さのため、ベンゼンは二重結合をもつアルケンとは違い、付加反応より、環の形を保ったまま環の水素が他の原子や原子団に置き換わる置換反応をしやすい。ニトロ化・スルホン化・ハロゲン化・アルキル化の生成物を、反応条件と置換基から予測するのがこの項目の中心である。

どんな問題に使うか

ベンゼン環をもつ化合物＝芳香族化合物の構造と反応を扱うときの考え方です。炭化水素の項目で入口だけ触れたベンゼンを、ここで本格的に扱います。次のような場面で使います。

  • ベンゼン C6H6 の構造（正六角形・結合の長さが等しいこと）と、アルケンと違って付加反応をしにくい理由を説明する問題
  • ベンゼンのニトロ化・スルホン化・ハロゲン化・アルキル化について、反応条件と生成物を書く問題
  • トルエン・キシレン・スチレンなど、ベンゼン環に置換基が付いた化合物の名前と構造式を対応させる問題
  • クメン法によるフェノールとアセトンの工業的製法の概要と、全体の反応式を書く問題

ポイントは、「ベンゼン環は壊れにくいので、環を保つ置換反応が主役」という一点です。反応の種類ごとに「何が環の水素と置き換わるか」と「必要な条件（触媒・試薬）」をセットで押さえます。

公式・考え方

ベンゼンの構造：正六角形と等しい結合

ベンゼン C6H6 は、6個の炭素原子が正六角形の環を作り、各炭素に水素が1つずつ付いた化合物です。1865年にケクレが提案した構造では単結合と二重結合が交互に並びますが、実際に測ると6本の炭素どうしの結合の長さはすべて等しく、単結合と二重結合のちょうど中間であることが分かっています。二重結合の電子が環全体に広がって分布しているためで、現在は環の中に円を描いてこの広がりを表します。

ベンゼンの2つの表し方。ケクレ構造は提案当時の形で、今でも反応を考えるときに使われますが、実際の結合は左図のように長短が交互になっているのではなく、すべて等しくそろっています。

この広がりのおかげでベンゼン環は特に安定です。二重結合への付加反応が進むとこの安定な広がりが壊れてしまうため、ベンゼンは臭素水を加えてもアルケンのようには脱色せず、付加反応より、環の形を保ったまま水素が置き換わる置換反応をしやすいのが特徴です。

ベンゼンには特有の臭いがあり、引火性のある液体です。また、体内に取り込むと健康に害がある有害な物質として知られており、取り扱いには厳重な注意が必要です。

ベンゼンの置換反応（入口）

ベンゼン環の水素が他の原子や原子団（置換基）に置き換わる反応を置換反応といいます。高校で扱う代表的な4つは次の通りで、生成物はいずれもベンゼン環を保っています。

  • ニトロ化：濃硝酸と濃硫酸の混合物（混酸）と加熱すると、水素がニトロ基 −NO2 に置き換わり、ニトロベンゼンができます。C6H6 ＋ HNO3 → C6H5NO2 ＋ H2O（濃硫酸は触媒・脱水剤として働きます）
  • スルホン化：濃硫酸（発煙硫酸）と加熱すると、水素がスルホ基 −SO3H に置き換わり、ベンゼンスルホン酸ができます。C6H6 ＋ H2SO4 → C6H5SO3H ＋ H2O
  • ハロゲン化：鉄（またはハロゲン化鉄）を触媒として臭素や塩素と反応させると、水素がハロゲンに置き換わり、ブロモベンゼンやクロロベンゼンができます。C6H6 ＋ Br2 → C6H5Br ＋ HBr（触媒 FeBr3）。触媒なしでは臭素水を脱色しない点が、アルケンとの決定的な違いです
  • アルキル化（フリーデル・クラフツ反応）：塩化アルミニウム AlCl3 を触媒としてハロゲン化アルキルと反応させると、水素がアルキル基に置き換わります。たとえばクロロメタン CH3Cl とでは トルエン ができます。C6H6 ＋ CH3Cl → C6H5CH3 ＋ HCl（触媒 AlCl3）
ベンゼンの置換反応：環の H が −NO2／−SO3H／−Br・−Cl／−CH3 などの置換基に1つ置き換わり、ベンゼン環はそのまま残る

置換反応の生成物。ニトロベンゼン（ニトロ化）、ベンゼンスルホン酸（スルホン化）、ブロモベンゼンとクロロベンゼン（ハロゲン化）です。アルキル化の生成物トルエンは次の図にあります。

代表的な芳香族化合物への橋渡し

トルエンはベンゼンの水素1つがメチル基 −CH3 に置き換わった化合物 C6H5CH3 です。メチル基を2つもつものはキシレンと呼ばれ、2つの置換基の位置関係によって、隣り合う o-（オルト、1,2-）、1つ置いた m-（メタ、1,3-）、向かい合う p-（パラ、1,4-） の3種の異性体があります。置換基の付いた炭素を1番として番号を振り、位置を読み取るのが約束です。

トルエンとキシレンの3異性体。分子式はキシレン3種とも C6H4(CH3)2 で同じですが、置換基の位置が違うため性質（融点・沸点など）が異なります。

スチレンはベンゼン環にビニル基 −CH＝CH2 が付いた化合物で、環の外の二重結合の部分で付加重合をしてポリスチレンになります。ベンゼン環自体は置換反応をする一方、側鎖の二重結合は付加反応をする、という二面性がポイントです。また、ベンゼンにプロペン C3H6 を付加させるとクメン（イソプロピルベンゼン）が得られ、これが次のクメン法の原料になります（C6H6 ＋ C3H6 → C9H12）。

クメン法：フェノールとアセトンの工業的製法（概要）

クメン法は、フェノールとアセトンを同時に作る工業的製法で、現在、世界のフェノールの大部分がこの方法で作られています。流れは、(1) ベンゼンとプロペンからクメンを作る、(2) クメンを空気で酸化してクメンヒドロペルオキシドにする、(3) 希硫酸で分解するとフェノールとアセトンが得られる、という3段階です。途中の式をまとめると全体は次のようになります。

クメン法（全体）：C9H12（クメン）＋ O2 → C6H5OH（フェノール）＋ C3H6O（アセトン）

両辺を比べると C は 9＝6＋3、H は 12＝6＋6、O は 2＝1＋1 で一致します（検算済み）。フェノールの性質やサリチル酸への道は「フェノールと芳香族カルボン酸」の項目で扱いますが、原料の流れはここで押さえてください。

スチレン、クメンの原料プロペン、クメン、クメン法の生成物であるフェノールとアセトンの構造式。スチレンのビニル基は環の外にある二重結合で、この部分が付加重合します。アセトンは C＝O（カルボニル基）をもつ最も簡単なケトンです。

解き方の手順

  1. まずベンゼン環があるかを確認する。環がある化合物は、臭素水の脱色のようなアルケン型の付加反応ではなく、置換反応を基本に考えます。
  2. 試薬と条件から反応の種類を決める。混酸 → ニトロ化、濃硫酸と加熱 → スルホン化、ハロゲン＋鉄触媒 → ハロゲン化、ハロゲン化アルキル＋AlCl3 → アルキル化、という対応で見分けます。
  3. 置き換わる置換基を書き、環の水素を1つ取り除いて付ける。生成物の分子式は、ベンゼン C6H6 から H を1つ引いて置換基を足したもの（例：C6H5NO2）になります。
  4. 置換基が2つある場合は位置を確認する。隣（1,2-）が o-、1つ置き（1,3-）が m-、向かい側（1,4-）が p- です。
  5. 反応式の両辺で原子の数を数え直す。C・H・N・O・S・ハロゲンの数が左右で一致しているかを必ず検算します。副生成物（H2O や HBr、HCl）の書き忘れが最も多いミスです。

例題

問題1（ニトロ化）：ベンゼンを混酸（濃硝酸と濃硫酸の混合物）と加熱したときの生成物の名前を答え、反応式を書け。

問題2（スルホン化）：ベンゼンを濃硫酸と加熱したときの生成物の名前と、導入される置換基の示性式を答えよ。

問題3（ハロゲン化）：ベンゼンに触媒の臭化鉄（III）のもとで臭素を作用させたときの生成物を答えよ。また、触媒なしで臭素水を加えただけでは色が消えない理由を、ベンゼンの構造から説明せよ。

問題4（アルキル化）：ベンゼンに塩化アルミニウムを触媒としてクロロメタンを作用させたときの生成物の名前を答え、反応式を書け。この反応の名前も答えよ。

問題5（キシレンの異性体）：キシレンの3種の異性体について、2つのメチル基の位置関係（炭素番号の組み合わせ）と o-・m-・p- の対応を答えよ。

問題6（クメン法）：クメン法全体の反応式 C9H12 ＋ O2 → （生成物2つ）を完成させ、2つの生成物の名前を答えよ。両辺の原子数が一致することも確認せよ。

問題7（スチレン）：スチレンがポリスチレンになるとき、反応するのはベンゼン環か、側鎖のビニル基か。反応の種類（付加・置換・付加重合）とともに答えよ。

答えと解説を見る
  1. 問題1：生成物はニトロベンゼン。反応式は C6H6 ＋ HNO3 → C6H5NO2 ＋ H2O。両辺とも C6・H7・N・O3 で一致します（検算済み）。環の H が −NO2 に置き換わる置換反応です。
  2. 問題2：生成物はベンゼンスルホン酸で、導入される置換基はスルホ基 −SO3H。反応式は C6H6 ＋ H2SO4 → C6H5SO3H ＋ H2O で、両辺とも C6・H8・S・O4 で一致します（検算済み）。
  3. 問題3：生成物はブロモベンゼン C6H5Br で、反応式は C6H6 ＋ Br2 → C6H5Br ＋ HBr（両辺とも C6・H6・Br2 で一致）。色が消えない理由は、ベンゼンの二重結合の電子が環全体に広がって安定しており、付加反応でその広がりを壊すより、環を保つ置換反応の方が起こりやすいからです。置換には触媒が必要です。
  4. 問題4：生成物はトルエン C6H5CH3。反応式は C6H6 ＋ CH3Cl → C6H5CH3 ＋ HCl で、両辺とも C7・H9・Cl で一致します（検算済み）。このアルキル化はフリーデル・クラフツ反応と呼ばれます。
  5. 問題5：隣り合う位置（1,2-）が o-キシレン、1つ置いた位置（1,3-）が m-キシレン、向かい合う位置（1,4-）が p-キシレン です。3種とも分子式は C6H4(CH3)2（＝C8H10）で同じ構造異性体どうしです。
  6. 問題6：C9H12 ＋ O2 → C6H5OH ＋ C3H6O。生成物はフェノールとアセトン。原子数は C：9＝6＋3、H：12＝6＋6、O：2＝1＋1 で両辺一致します（検算済み）。
  7. 問題7：反応するのは側鎖のビニル基 −CH＝CH2 の二重結合で、反応の種類は付加重合です。ベンゼン環は安定なため壊れず、そのまま残ります。n CH2＝CH(C6H5) → −(CH2−CH(C6H5))n− のように、ビニル基どうしがつながって長い鎖になります。

答え：問題1はニトロベンゼン、問題2はベンゼンスルホン酸（−SO3H）、問題3はブロモベンゼン、問題4はトルエン（フリーデル・クラフツ反応）、問題5は 1,2-＝o-、1,3-＝m-、1,4-＝p-、問題6はフェノールとアセトン、問題7はビニル基の付加重合。

例題に登場する生成物の構造式。ニトロベンゼン（問題1）、ベンゼンスルホン酸（問題2）、ブロモベンゼン（問題3）、トルエン（問題4）、フェノールとアセトン（問題6）です。キシレンの3異性体（問題5）とスチレン・クメン（問題6・7）は本文の図にあります。

現場での使われ方

石油化学の出発原料としてのベンゼン・トルエン・キシレン

ベンゼン・トルエン・キシレン（まとめて BTX と呼ばれます）は石油化学の基礎原料で、ナフサの改質（リフォーミング）などで得られ、プラスチック・合成繊維・医薬品など膨大な製品の出発点になっています。p-キシレンはペットボトルやポリエステル繊維の原料の出発物質です。ベンゼンは有害性が高いため、工場では密閉された設備の中で扱われ、ガソリン中の含有量も法令で規制されています。

クメン法によるフェノールとアセトンの生産

クメン法は、安価なベンゼンとプロペンから、フェノールとアセトンという2つの有用な物質を同時に得られる点が工業的に優れており、世界のフェノール生産の主流です。フェノールはフェノール樹脂（ベークライト）や消毒薬などの原料、アセトンは溶剤やアクリル樹脂の原料になります。本文の「全体の反応式1本」は、実際のプラントの物質収支の土台です。

ポリスチレンと置換反応で作る中間体

スチレンの付加重合で得られるポリスチレンは、発泡スチロールや食品容器、家電の筐体などに広く使われます。また、ニトロ化・スルホン化などの置換反応は、染料・医薬品・洗剤の原料となる中間体を作る基本工程として化学工場で日常的に使われており、「環を保ったまま置換基だけを付け替える」というこの項目の考え方が、そのまま工業合成の設計図になっています。

考え出した人

マイケル・ファラデー（1791〜1867、イギリスの化学者・物理学者）、アウグスト・ケクレ（1829〜1896、ドイツの化学者）、シャルル・フリーデル（1832〜1899、フランスの化学者）、ジェームズ・クラフツ（1839〜1917、アメリカの化学者）

ベンゼンは、イギリスの化学者・物理学者マイケル・ファラデーが1825年に鯨油を熱分解して得た液体の中から発見しました。その後、分子式 C6H6 に対してどのような構造が成り立つかが長年の謎でしたが、ドイツの化学者アウグスト・ケクレが1865年に、6個の炭素が環を作り単結合と二重結合が交互に並ぶ六角形の構造を提案し、芳香族化合物の理解の出発点になりました。実際の結合がすべて等しいことは、後の測定で確かめられています。また、アルキル化のフリーデル・クラフツ反応は、フランスのシャルル・フリーデルとアメリカのジェームズ・クラフツが1877年に見いだした反応で、2人の名を取って呼ばれています。
