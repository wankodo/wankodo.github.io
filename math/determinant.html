行列式

数学解法辞典 ― 線形代数（大学）

数学ツール集トップ ＞ 線形代数 ＞ 行列式

大学 線形代数 計算機あり

どんな時に使えるか 行列式の値は、その行列で平面や空間を変形したとき、面積や体積が何倍になるかを表している。値が0かどうかで、逆行列が存在するか、連立方程式の答えが1つに決まるかも判定できる。

どんな問題に使うか

行列式は、正方行列（行と列の数が同じ行列）に対して定まる1つの数で、det A や |A| と書きます。次のような場面で使います。

  • 逆行列が存在するかどうかを、先に判定したい問題
  • 連立一次方程式の解が1つに決まるかどうかを判定したい問題
  • 行列で表される変換で、図形の面積や立体物の体積が何倍になるかを求める問題
  • 2つのベクトルが作る平行四辺形の面積や、3つのベクトルが作る平行六面体の体積を求める問題

「行列そのもの」ではなく「行列の性質を1つの数に要約したもの」が行列式です。特に 0 かどうか が重要な判定材料になります。

公式・考え方

2×2 の行列式

の行列式は、対角線同士の積の差です。

det A ＝ ad − bc

3×3 の行列式（サラスの公式）

3×3 では、左上から右下への斜めの積3つを足し、右上から左下への斜めの積3つを引きます（サラスの公式）。行列の右側に第1列・第2列をもう一度書いて、斜めの線で結ぶと覚えやすい方法です。

det A ＝ aei ＋ bfg ＋ cdh − ceg − bdi − afh

行列式の意味

行列式の絶対値は、その行列による変換で面積・体積が何倍になるかを表します。符号は、変換で図形の向き（裏表）が反転するかどうかを表します。そして行列式が 0 のときは、変換で平面や空間が潰れてしまい、元に戻す逆行列は存在しません。

解き方の手順

  1. サイズを確認する。行列式は正方行列にだけ定義されます。2×2 か 3×3 かで公式が変わります。
  2. 2×2 なら対角の積の差。左上×右下 から 右上×左下 を引きます（ad − bc）。
  3. 3×3 ならサラスの公式。右下がりの斜めの積3つ（＋）と、左下がりの斜めの積3つ（−）を順に計算します。
  4. 符号に注意して合計する。引く側の3項の符号ミスが最も多い間違いです。1項ずつ確認しながら進めます。

例題

問題：2つのベクトル (2, 1) と (1, 3) が作る平行四辺形の面積を行列式で求めよ。また、この2ベクトルを列に持つ行列に逆行列が存在するか判定せよ。

答えと解説を見る
  1. 2ベクトルを列に並べた行列 A ＝
    21
    13
    を作る。
  2. 行列式を計算する：det A ＝ 2 × 3 − 1 × 1 ＝ 6 − 1 ＝ 5
  3. 平行四辺形の面積は行列式の絶対値なので、面積は 5。
  4. det A ＝ 5 ≠ 0 なので、逆行列は存在する（この2ベクトルは潰れていない）。

答え：面積は5、逆行列は存在する。2つのベクトルが一直線に並んでしまうと行列式は 0 になり、面積も 0 になって逆行列も存在しません。

現場での使われ方

面積・体積の拡大率

地図の投影や3Dモデルの変形など、図形を変換する計算では「面積や体積がどれだけ伸び縮みするか」が重要になります。行列式の絶対値がその倍率そのものなので、歪みの評価や補正に使われます。微積分の変数変換（置換積分）で現れるヤコビアンも、行列式です。

逆行列の存在判定

連立方程式を解く前に「そもそも答えが1つに決まるか」を確かめることは、構造計算や回路計算の安全確認につながります。行列式が 0 でないことと、逆行列が存在して解が1つに決まることは、数学的に同じ意味を持ちます。

ベクトルの張る面積・体積

測量や3D計測では、基準となるベクトル同士が作る平行四辺形の面積や平行六面体の体積を行列式で求めます。値が 0 に近いときは、ベクトル同士がほぼ重なっていて基準として不安定だという警告にもなります。

考え出した人

関孝和（1642年頃〜1708年）生年には諸説あります。1683年の『解伏題之法』で、方程式から未知数を消去する過程で、係数の表から行列式にあたる値を計算する方法を示しました。

ゴットフリート・ヴィルヘルム・ライプニッツ（1646年〜1716年）1693年にロピタル宛ての書簡の中で、関とは独立に、ほぼ同じ行列式の考え方に到達しました。鎖国下の日本とヨーロッパで、同時期に別々に生まれた考え方です。

この解法を計算機で試す → 行列式 計算機：2×2・3×3 行列を入れると、ad − bc やサラスの公式の展開手順つきで行列式を計算します。

関連項目

  • 逆行列・掃き出し法 ― 行列式が 0 でないときにだけ作れる「行列の割り算」です。
  • 行列の積 ― 行列式は積について det(AB) ＝ det A × det B という性質を持ちます。
  • 固有値・固有ベクトル ― 固有値を求める固有方程式は、行列式 ＝ 0 の方程式です。
