混成軌道と分子軌道の入口

化学の考え方辞典 ― 化学結合（大学）

化学ツール集トップ ＞ 化学結合 ＞ 混成軌道と分子軌道の入口

大学 化学結合

どんな時に使えるか 炭素が4本の等しい結合を作る理由は、s軌道とp軌道が混ざって混成軌道を作ることで説明でき、sp³なら正四面体形、sp²なら三角平面形、spなら直線形になる。二重結合・三重結合はσ結合とπ結合の組み合わせであり、原子軌道の重なりを分子全体に広げた分子軌道で考えると、結合次数や、酸素分子が不対電子をもって常磁性を示す理由まで説明できる。

どんな問題に使うか

ルイス構造（電子式・構造式）と電子対反発（VSEPR）で分子の形は予測できましたが、「なぜ炭素は4本の等しい結合を作れるのか」「二重結合と単結合では何が違うのか」「なぜ酸素分子は磁石に引かれるのか」には答えられません。その一段先を扱うときの考え方が、混成軌道と分子軌道です。次のような場面で使います。

  • 中心原子のまわりの電子対の数から、sp3・sp2・sp のどの混成かを決め、分子の形と結合角を予測する問題
  • 分子の中の σ（シグマ）結合と π（パイ）結合の数を数える問題
  • 分子軌道のエネルギー準位図に電子を詰め、結合次数と不対電子の数を求める問題
  • O2 の常磁性のように、ルイス構造では説明できない性質を分子軌道で説明する問題

ポイントは、混成軌道は「1つの原子の中で軌道を混ぜて、結合の向きをそろえる」考え方（原子価結合法の入口）、分子軌道は「分子全体に広がる軌道に電子を詰める」考え方で、2つは対立するものではなく、見る範囲の違う説明道具だということです。

公式・考え方

混成軌道 ― s軌道とp軌道を混ぜて結合の向きを作る

炭素の基底状態の電子配置は 1s2 2s2 2p2 で、不対電子は2個しかありません。これでは4本の結合は作れません。そこで原子価結合法では、2s 軌道と 2p 軌道を混ぜ合わせて、同じ形・同じエネルギーの新しい軌道を作ると考えます。これが混成軌道です。混ぜた軌道の数と、できる混成軌道の数は必ず一致します。

1個の s軌道 ＋ n個の p軌道 → (n＋1) 個の spn 混成軌道
  • sp3 混成（s 1個＋p 3個＝4個）：4本の軌道が正四面体の頂点の向きに出る。結合角は約109.5°。例：メタン CH4 の C。非共有電子対も混成軌道1本を占めるため、アンモニア NH3 の N や水 H2O の O も sp3 で、原子だけの形はそれぞれ三角錐形・折れ線形になる
  • sp2 混成（s 1個＋p 2個＝3個）：3本の軌道が同じ平面内で120°に広がる（三角平面形）。混ぜなかった p軌道が1本、平面に垂直に残る。例：エテン（エチレン）C2H4 の C、三フッ化ホウ素 BF3 の B
  • sp 混成（s 1個＋p 1個＝2個）：2本の軌道が正反対の向きに出る（直線形、結合角180°）。混ぜなかった p軌道が2本残る。例：エチン（アセチレン）C2H2 の C、二酸化炭素 CO2 の C

混成の種類は、中心原子のまわりの電子対の置き場所の数（σ結合の相手の数＋非共有電子対の数）で決まります。置き場所が4か所なら sp3、3か所なら sp2、2か所なら sp です。二重結合・三重結合も、置き場所としては1か所と数えます。

混成軌道の本数と向きが、そのまま分子の基本の形になります。sp2 と sp では、混成に使われなかった p軌道が残り、それが次の π結合の材料になります。

σ結合とπ結合 ― 軌道の重なり方の2種類

軌道どうしの重なり方には2種類あります。

  • σ結合：2つの原子を結ぶ軸（結合軸）の上で、軌道が正面から重なる結合。軸のまわりに回しても重なりが変わらないため、σ結合は自由に回転できます。すべての結合はまず1本の σ結合から始まります
  • π結合：結合軸の上下（または前後）で、p軌道どうしが横向きに重なる結合。回転させると重なりが切れてしまうため、π結合を含む二重結合は回転できません。これが、エテンの平面構造や、二重結合まわりのシス・トランス異性体が生まれる理由です
単結合 ＝ σ 1本 ／ 二重結合 ＝ σ 1本 ＋ π 1本 ／ 三重結合 ＝ σ 1本 ＋ π 2本

混成との対応で見ると、混成軌道どうし（または混成軌道と相手の軌道）の正面の重なりが σ結合を作り、sp2 で残った p軌道1本が π結合を1本、sp で残った p軌道2本が π結合を2本作ります。つまり、混成の種類が決まれば、作れる π結合の数も決まります。

分子軌道 ― 軌道を分子全体に広げる

混成軌道が「原子の中」で完結する説明なのに対し、分子軌道（MO）は、電子が分子全体に広がった軌道に入ると考える方法です。2つの原子軌道が重なると、必ず2つの分子軌道ができます。

  • 結合性軌道：原子核の間に電子が集まり、2つの核を結びつける。元の原子軌道よりエネルギーが低い（安定）。記号は σ、π など
  • 反結合性軌道：原子核の間に電子の存在確率が0になる面（節）があり、核どうしを引き離す方向に働く。元の原子軌道よりエネルギーが高い（不安定）。記号は σ*、π* のように *（スター）を付ける

電子は原子軌道のときと同じ決まり（エネルギーの低い順に入る・1軌道に2個まで・同じエネルギーの軌道には1個ずつ入る）で分子軌道に詰めます。結合の強さの目安は結合次数で表します。

結合次数 ＝ （結合性軌道の電子数 − 反結合性軌道の電子数）÷ 2

結合次数が大きいほど結合は短く強くなり、0 なら安定な結合はできません。たとえばヘリウム分子 He2 は、結合性軌道に2個・反結合性軌道に2個の電子が入るため結合次数は （2−2）÷2 ＝ 0 で、安定な分子として存在しません。

O2 の常磁性 ― 分子軌道の代表的な成功例

酸素分子 O2 のルイス構造は O＝O で、すべての電子が対になっているように見えます。ところが実際には、液体酸素は磁石に引き寄せられる常磁性を示し、不対電子の存在を意味します。分子軌道で考えると、この事実が自然に説明できます。O2 の価電子は12個で、エネルギーの低い分子軌道から詰めていくと、最後の2個が、エネルギーの等しい2つの反結合性 π* 軌道にフントの規則どおり1個ずつ入ります。

O2 の分子軌道図（価電子12個分のみ）。結合性軌道の電子は σ2s に2個・σ2p に2個・π2p に4個の計8個、反結合性軌道の電子は σ*2s に2個・π*2p に2個の計4個です。π*2p の2個は対にならず、1個ずつ別々の軌道に入ります。

この図から、結合次数は （8−4）÷2 ＝ 2 となり、ルイス構造の二重結合と一致します。そのうえで、π* 軌道に不対電子が2個あるため、O2 は常磁性を示します。「結合次数はルイス構造と一致するのに、磁性はルイス構造では説明できない」――この両方を1つの図で説明できることが、分子軌道法の強みです。なお、電子が詰まった最も高い軌道を HOMO（最高被占軌道）、その1つ上の空の軌道を LUMO（最低空軌道）と呼び、反応の起こりやすさや光の吸収を考えるときの主役になります。

解き方の手順

  1. 混成を決める。中心原子について、σ結合の相手の数と非共有電子対の数を合計します。4か所なら sp3、3か所なら sp2、2か所なら sp です。
  2. 形と π結合の数を読み取る。混成軌道の向きが基本の形（正四面体・三角平面・直線）で、非共有電子対の分だけ原子の形が崩れます。混成に使われなかった p軌道の数が、その原子が作れる π結合の数です。
  3. σとπを数える。すべての結合に σ が1本ずつあり、二重結合には π が1本、三重結合には π が2本加わります。分子全体で合計します。
  4. 分子軌道では価電子の総数を数える。O2 なら 6×2 ＝ 12個、N2 なら 5×2 ＝ 10個です。
  5. エネルギーの低い分子軌道から電子を詰める。1軌道に2個まで（パウリの排他原理）、同じエネルギーの軌道（π軌道など）にはスピンをそろえて1個ずつ先に入れます（フントの規則）。
  6. 結合次数と不対電子を数える。結合次数 ＝ （結合性の電子数 − 反結合性の電子数）÷ 2。不対電子があれば常磁性、すべて対になっていれば反磁性です。

例題

問題1：メタン CH4、エテン C2H4、エチン C2H2 について、炭素の混成の種類と、分子全体の σ結合・π結合の数をそれぞれ答えよ。問題2：酸素分子 O2 と窒素分子 N2 の結合次数を求め、O2 が常磁性を示す理由を述べよ（N2 は価電子10個が結合性軌道に8個・反結合性軌道に2個入る）。問題3：二酸化炭素 CO2、三フッ化ホウ素 BF3、アンモニア NH3、水 H2O について、中心原子の混成の種類と分子の形を答えよ。

答えと解説を見る
  1. 問題1：CH4 の C は結合の相手が4か所で sp3。結合は C−H の単結合4本だけなので、σ は4本、π は0本です。C2H4 の各 C は結合の相手が3か所（H 2個と C 1個）で sp2。σ は C−H が4本と C−C が1本で計5本、残った p軌道どうしの重なりで π が1本（二重結合 ＝ σ1本＋π1本）です。C2H2 の各 C は結合の相手が2か所で sp。σ は C−H が2本と C−C が1本で計3本、残った p軌道2本分で π が2本（三重結合 ＝ σ1本＋π2本）です。
  2. 問題2：O2 は価電子12個が、結合性軌道に8個（σ2s に2個、σ2p に2個、π2p に4個）、反結合性軌道に4個（σ*2s に2個、π*2p に2個）入るので、結合次数は （8−4）÷2 ＝ 2 です。π*2p の2個の電子は、エネルギーの等しい2つの軌道にフントの規則で1個ずつ入るため不対電子が2個残り、これが O2 が磁石に引かれる常磁性の理由です。ルイス構造 O＝O ではすべての電子が対に見えるため、この性質は説明できません。N2 の結合次数は （8−2）÷2 ＝ 3 で、ルイス構造の三重結合と一致し、不対電子はないので反磁性です。
  3. 問題3：CO2 の C は結合の相手が2か所（二重結合は1か所と数える）で sp、形は直線形です。BF3 の B は結合の相手が3か所で sp2、形は三角平面形です。NH3 の N は結合の相手3か所＋非共有電子対1組で計4か所のため sp3、電子対の配置は正四面体形ですが原子だけの形は三角錐形です。H2O の O は結合の相手2か所＋非共有電子対2組で計4か所のため sp3、原子だけの形は折れ線形です。

答え：問題1は CH4 が sp3・σ4本・π0本、C2H4 が sp2・σ5本・π1本、C2H2 が sp・σ3本・π2本。問題2は O2 の結合次数が2で π*軌道の不対電子2個により常磁性、N2 の結合次数は3。問題3は CO2 が sp・直線形、BF3 が sp2・三角平面形、NH3 が sp3・三角錐形、H2O が sp3・折れ線形。σ結合の総数は「結合の本数」と、二重・三重結合の中にも σ が1本ずつ含まれることとを合わせて数え直すと検算になります。

現場での使われ方

有機材料・色素の設計（HOMO と LUMO）

有機EL（OLED）の発光材料や有機半導体、染料・色素の設計では、分子軌道の HOMO と LUMO のエネルギー差（ギャップ）が、吸収・発光する光の色や電気の流れやすさを決める設計値として使われています。共役した π結合の広がり方を変えてギャップを調整する、という分子軌道の考え方そのものが、材料開発の日常的な設計手順です。

常磁性式の酸素濃度計

多くの気体が反磁性なのに対し、酸素だけが強い常磁性を示す性質は、酸素濃度の測定にそのまま利用されています。常磁性式酸素濃度計は、磁場の中での酸素の引かれ方から濃度を測る装置で、燃焼排ガスの管理や工業プロセスの酸素濃度監視に使われています。O2 の π* 軌道の不対電子という分子軌道の帰結が、実在の計測技術の原理になっています。

炭素材料の性質の使い分け（sp2 と sp3）

グラファイト（黒鉛）は sp2 混成の炭素が平面状につながり、残った p軌道の π電子が平面内を動けるため電気を通します。一方、ダイヤモンドは sp3 混成の炭素が立体的に結ばれ、電気を通さず非常に硬くなります。工具のコーティングなどに使われるダイヤモンドライクカーボン（DLC）膜では、sp2 結合と sp3 結合の比率を調整して硬さや摩擦の性質を作り分けています。混成の種類が、そのまま材料の性質の設計図になっています。

考え出した人

ライナス・ポーリング（1901〜1994、アメリカの化学者）、ロバート・マリケン（1896〜1986、アメリカの物理化学者）、フリードリヒ・フント（1896〜1997、ドイツの物理学者）

混成軌道の考え方は、アメリカの化学者ライナス・ポーリングが1931年に原子価結合法の論文で打ち出したものです。s軌道とp軌道の混成によって、メタンに代表される結合の向きと強さを量子力学から説明し、化学結合の理解を大きく進めました。ポーリングは化学結合の研究で1954年にノーベル化学賞を受けています。分子軌道法は、ドイツの物理学者フリードリヒ・フントとアメリカの物理化学者ロバート・マリケンが1920年代後半に分子のスペクトルを説明する中で築いた方法で、「分子軌道」という言葉自体はマリケンが1932年に導入しました。マリケンは分子軌道法への貢献で1966年にノーベル化学賞を受けています。O2 の常磁性のように原子価結合法では説明しにくい事実を分子軌道法が説明できたことが、2つの方法が競い合いながら化学結合論を深めていく転機になりました。
