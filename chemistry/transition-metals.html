遷移元素と錯イオン・炎色反応

化学の考え方辞典 ― 無機化学（高校化学・3年）

化学ツール集トップ ＞ 無機化学 ＞ 遷移元素と錯イオン・炎色反応

高校化学・3年 無機化学

どんな時に使えるか 周期表の3族から12族に並ぶ遷移元素は、酸化数が複数ある、水溶液が色づくイオンが多い、触媒として働くものが多い、錯イオンをつくりやすい、という共通の特徴をもつ。金属イオンにアンモニアなどが配位した錯イオンは特有の色を示し、金属元素を炎で熱すると元素ごとに決まった色の光を出す炎色反応は、花火の色や元素の検出に使われる。

どんな問題に使うか

鉄・銅・コバルトなどの遷移元素に共通する性質と、色で元素を見分ける手がかりを扱うときの考え方です。次のような場面で使います。

  • 「遷移元素の特徴を挙げよ」という問題で、複数の酸化数・色のあるイオン・触媒・錯イオンの4点を押さえる場面
  • テトラアンミン銅（II）イオン [Cu(NH3)4]2+ のような代表的な錯イオンについて、組成式と色を答える問題
  • 水溶液の色から、Cu2+・Fe2+・Fe3+ などのイオンを推定する問題
  • 炎色反応の色（Li は紅、Na は黄、K は紫など）から元素を判定する問題や、花火の色がどの元素によるものかを説明する問題

ポイントは、遷移元素の性質を「酸化数・色・触媒・錯イオン」の4点で整理し、色については「イオンの色の表」と「炎色反応の表」をそれぞれ元素と結びつけて覚えることです。

公式・考え方

遷移元素とは

周期表の3族から12族に位置する元素を遷移元素（遷移金属）といいます。鉄 Fe、銅 Cu、銀 Ag、金 Au、コバルト Co、ニッケル Ni、クロム Cr、マンガン Mn など、金属らしい金属が並ぶグループです。典型元素（1・2族と13〜18族）とは対照的に、次のような共通の特徴があります。

  • 複数の酸化数をとる：典型元素の金属（Na は +1、Ca は +2 など）は酸化数がほぼ1つに決まりますが、遷移元素は Fe が +2 と +3、Cu が +1 と +2、Mn が +2・+4・+7 など、複数の酸化数をとります。化合物の名前で酸化数を（II）（III）と断るのはこのためです
  • 色のあるイオン・化合物が多い：水溶液が色づくイオンが多く、化合物にも色のついたものが多くあります
  • 触媒として働くものが多い：Fe、Pt、Ni、V2O5 など、工業的に重要な触媒の多くが遷移元素とその化合物です
  • 錯イオンをつくりやすい：金属イオンに分子やイオンが配位結合した錯イオンを、多くの遷移元素がつくります

色のあるイオン

代表的なイオンの水溶液の色は次の通りです。色はイオンの種類だけでなく、まわりに配位しているものによっても変わります。

  • Cu2+：青色
  • Fe2+：淡緑色
  • Fe3+：黄褐色
  • Ni2+：緑色
  • Co2+：赤色
  • Mn2+：淡赤色
  • Cr3+：緑色
  • MnO4−（過マンガン酸イオン）：赤紫色
  • Cr2O72−（二クロム酸イオン）：橙色、CrO42−（クロム酸イオン）：黄色

一方で、Ag+ や Zn2+ のように無色のイオンもあります。「遷移元素のイオンは色づくものが多い」であって、すべてが色づくわけではありません。

代表的な錯イオン

錯イオンの電荷は、中心金属イオンと配位子の電荷の合計で決まります（詳しいつくりは関連項目「配位結合と錯イオン」参照）。

錯イオンの電荷 ＝ 中心金属イオンの電荷 ＋（配位子の電荷 × 個数）の合計
  • [Cu(NH3)4]2+：テトラアンミン銅（II）イオン。深青色。硫酸銅（II）水溶液（青色）にアンモニア水を過剰に加えると生じ、色が一段と深くなります
  • [Co(NH3)6]3+：ヘキサアンミンコバルト（III）イオン。配位子 NH3 は電荷0なので、電荷 +3 がそのままコバルトの酸化数 +3 を表します。その塩は橙黄色を示します
  • [Ag(NH3)2]+：ジアンミン銀（I）イオン。無色。塩化銀の白色沈殿がアンモニア水に溶けるのは、この錯イオンが生じるためです
  • [Fe(CN)6]3−：ヘキサシアニド鉄（III）酸イオン。鉄の酸化数を x とすると x ＋ (−1)×6 ＝ −3 より x ＝ +3 です。カリウム塩 K3[Fe(CN)6] は赤色の結晶で、赤血塩とも呼ばれます

炎色反応

金属元素を含む化合物を炎の中で強く熱すると、その元素に特有の色の光を放ちます。これを炎色反応といいます。熱でエネルギーを受けた原子が、元素ごとに決まった色の光を出すため、色を見れば元素の種類が判定できます。代表的な対応は次の通りです。

  • Li：紅色
  • Na：黄色
  • K：紫色
  • Ca：橙赤色
  • Sr：紅色
  • Ba：黄緑色
  • Cu：青緑色

Li と Sr はともに赤系の色で肉眼では区別しにくいことがあります。その場合は、光を分光器で分けて輝線（光の帯）の位置を見ることで区別できます。また、Na の黄色は非常に強く出るため、少量のナトリウムが混ざると他の元素の色が見えにくくなることも知られています。有名な覚え方に「リアカー（Li・赤）無き（Na・黄）K村（K・紫）動力（Cu・緑）借るとう（Ca・橙）するもくれない（Sr・紅）馬力（Ba・緑）」という語呂合わせがあります。

解き方の手順

  1. 遷移元素かどうかを見分ける。周期表の3〜12族の元素なら遷移元素です。特徴を問われたら「複数の酸化数」「色のあるイオンが多い」「触媒になるものが多い」「錯イオンをつくりやすい」の4点で答えます。
  2. 錯イオンは部品に分解する。角括弧 [ ] の中の金属が中心金属イオン、まわりの分子・イオンが配位子です。電荷は中心金属の電荷と配位子の電荷×個数の合計で確かめ、中心金属の酸化数が分からなければ（錯イオンの電荷）−（配位子の電荷の合計）で逆算します。
  3. 色は対応表と結びつける。水溶液の色ならイオンの色の表（Cu2+ は青、Fe3+ は黄褐色など）、錯イオンなら代表例（テトラアンミン銅（II）イオンは深青色など）と照合します。
  4. 炎色反応は色から元素を逆引きする。黄緑なら Ba、紫なら K、青緑なら Cu のように、炎色の表を逆向きに使います。赤系（Li・Sr・Ca）が候補に複数残るときは、色の微妙な違い（紅か橙赤か）や他の性質で絞り込みます。
  5. 触媒の例は反応とセットで思い出す。ハーバー法の Fe、接触法の V2O5、過酸化水素水の分解の MnO2 のように、反応名と触媒を対にして押さえます。

例題

問題1：ある金属元素を含む試料を炎に入れると、試料Aは黄緑色、試料Bは紫色、試料Cは青緑色の炎になった。それぞれどの元素による炎色反応か。問題2：青色の硫酸銅（II）水溶液にアンモニア水を過剰に加えると、深い青色の溶液になった。生じた錯イオンの組成式と名前、その色を答えよ。問題3：[Fe(CN)6]3− と [Co(NH3)6]3+ について、中心金属の酸化数をそれぞれ求めよ。問題4：花火の赤色にはストロンチウムの化合物が使われる。炎色反応の対応をもとに、その理由を説明せよ。また、緑色の花火に使われる元素を1つ挙げよ。問題5：アンモニアの工業的製法（ハーバー法）と、硫酸の工業的製法（接触法）で使われる触媒をそれぞれ答えよ。

答えと解説を見る
  1. 問題1：炎色反応の表を逆引きします。黄緑色は Ba（バリウム）、紫色は K（カリウム）、青緑色は Cu（銅）です。
  2. 問題2：Cu2+ に NH3 が4つ配位結合して [Cu(NH3)4]2+ が生じます。名前はテトラアンミン銅（II）イオンで、色はもとの水溶液の青色より深い深青色です。電荷は +2 ＋ 0×4 ＝ +2 で、式の右上の 2+ と一致します。
  3. 問題3：[Fe(CN)6]3− では、配位子 CN− が6つで電荷の合計は −6 です。鉄の酸化数を x とすると x ＋ (−6) ＝ −3 より x ＝ +3 です。[Co(NH3)6]3+ では配位子 NH3 の電荷が0なので、コバルトの酸化数は錯イオンの電荷そのままで +3 です。
  4. 問題4：Sr（ストロンチウム）は炎色反応で紅色を示すため、その化合物を火薬に混ぜると燃焼時の炎が赤く色づき、赤い花火になります。緑色の花火には、黄緑色の炎色を示す Ba（バリウム）の化合物が使われます（青緑色の Cu の化合物が青色系に使われることもあります）。
  5. 問題5：ハーバー法の触媒は鉄（Fe を主成分とする触媒）、接触法の触媒は酸化バナジウム（V）V2O5 です。どちらも遷移元素（の化合物）が触媒として働く代表例です。

答え：問題1は A＝Ba、B＝K、C＝Cu。問題2は [Cu(NH3)4]2+、テトラアンミン銅（II）イオン、深青色。問題3は Fe が +3、Co が +3。問題4は Sr の炎色が紅色だからで、緑色は Ba。問題5はハーバー法が Fe、接触法が V2O5。

現場での使われ方

花火の色（炎色反応そのもの）

花火の色は炎色反応の応用そのものです。火薬に金属化合物を混ぜておくと、燃焼の高温で金属元素が特有の色の光を放ちます。赤はストロンチウムの化合物、緑はバリウムの化合物、青は銅の化合物、黄はナトリウムの化合物が担います。打ち上げ花火の鮮やかな色の違いは、元素ごとの炎色の違いを職人が配合で使い分けた結果です。

元素分析と分光（炎色反応の発展形）

炎色反応は、試料に含まれる金属元素を見分ける検出法として実験室で使われてきました。これを精密化したのが、光を波長ごとに分けて輝線の位置から元素を特定する分光分析で、現在の発光分光分析など元素分析法の出発点になっています。天文学でも、星の光を分光して輝線・吸収線を調べることで、遠くの星を構成する元素が分かるようになりました。

工業触媒（遷移元素の触媒作用）

アンモニアを作るハーバー法では鉄を主成分とする触媒、硫酸を作る接触法では酸化バナジウム（V）V2O5 が触媒として使われます。自動車の排気ガスを浄化する三元触媒には白金 Pt・パラジウム Pd・ロジウム Rh が、油脂に水素を付加してマーガリンなどを作る水素化にはニッケル Ni が使われます。化学工業の要所で、遷移元素の触媒作用が活躍しています。

顔料とガラスの色（色のある化合物）

遷移元素の化合物の色は、着色材料にも利用されます。コバルトの化合物はガラスや陶磁器の青色の着色に使われ、顔料の紺青（プルシアンブルー）は鉄を含む錯体です。イオンや化合物の「色」は、見分ける手がかりであると同時に、材料の色そのものとしても役立っています。

考え出した人

ロベルト・ブンゼン（1811〜1899、ドイツの化学者）とグスタフ・キルヒホッフ（1824〜1887、ドイツの物理学者）

炎色反応を元素を見分ける精密な方法に高めたのは、ドイツの化学者ロベルト・ブンゼン（1811〜1899）と物理学者グスタフ・キルヒホッフ（1824〜1887）です。ブンゼンは、色のつかない高温の炎を出すガスバーナー（ブンゼンバーナー）を工夫し、試料の炎色を邪魔なく観察できるようにしました。2人は1859年ごろ、炎の光をプリズムで分ける分光器を組み立て、元素ごとに輝線の位置が決まっていることを突き止めます。この方法で、1860年にセシウム、1861年にルビジウムという新元素を、炎の輝線を手がかりに発見しました。炎色反応はここから分光分析へと発展し、元素の検出法の基礎になりました。
