原子軌道と量子数

大学 物質の構成・原子と周期表

どんな時に使えるか 電子は原子核の周りを回る粒ではなく、原子軌道と呼ばれる空間の広がりに確率的に存在する。軌道は主量子数・方位量子数・磁気量子数の3つで決まり、電子のスピン量子数を合わせた4つの量子数が、電子配置の本当の姿を決める。

どんな問題に使うか

電子殻のイメージを一段深くし、電子が原子の中のどこに、どのような広がりで存在するかを扱うときの考え方です。次のような場面で使います。

  • 主量子数 n から、その主殻に含まれる軌道の種類と数、入れる電子の最大数を求める問題
  • 4つの量子数の組み合わせが許されるかどうかを判定する問題
  • 原子番号から、1s・2s・2p…という軌道表記で電子配置を書く問題（遷移元素を含む）
  • 不対電子（対になっていない電子）の数を数え、磁性や反応性を考える問題

高校で学ぶ電子殻（K殻・L殻・M殻…）は、電子が殻という「入れ物」に順に入る模式的なイメージでした。実際には、電子は決まった軌道を回っているのではなく、原子軌道（オービタル）と呼ばれる空間の広がりの中に、確率的に存在しています。この項目では、その軌道を指定する4つの量子数を軸に、電子配置の本当の姿を整理します。

公式・考え方

原子の中の電子の状態は、量子力学の基本方程式であるシュレーディンガー方程式を解くことで得られます。その解（波動関数）が表す電子の存在確率の広がりが原子軌道で、解に付随して現れる整数が量子数です。軌道1つは次の3つの量子数で決まります。

  • 主量子数 n：軌道の大きさとエネルギーの目安。n ＝ 1, 2, 3, … の正の整数。n が小さい軌道ほど原子核に近く、エネルギーも低い。高校の電子殻はこの n に対応し、n ＝ 1 が K殻、n ＝ 2 が L殻、n ＝ 3 が M殻、n ＝ 4 が N殻である
  • 方位量子数 l：軌道の形を決める。l ＝ 0, 1, 2, …, n−1 の整数。l の値には名前が対応し、l ＝ 0 が s軌道（球形）、l ＝ 1 が p軌道（亜鈴形）、l ＝ 2 が d軌道、l ＝ 3 が f軌道である。同じ n で l が同じ軌道の集まりを副殻と呼び、3p、4d のように「n の数字＋l の文字」で書く
  • 磁気量子数 ml：軌道の空間での向きを決める。ml ＝ −l, −l＋1, …, 0, …, l−1, l の整数で、全部で 2l＋1 通りある。つまり副殻に含まれる軌道の数は、s軌道（l ＝ 0）が1個、p軌道（l ＝ 1）が3個、d軌道（l ＝ 2）が5個、f軌道（l ＝ 3）が7個である

これに、電子自身の性質を表す第4の量子数が加わります。

  • スピン量子数 ms：電子のスピンの向きを表し、ms ＝ ＋1/2 または −1/2 の2通りのみ

軌道の数と電子の収容数は、次の関係で数えられます。

副殻（n, l）の軌道数 ＝ 2l ＋ 1、電子の最大数 ＝ 2(2l ＋ 1)
主殻（n）の軌道数 ＝ n2、電子の最大数 ＝ 2n2

副殻ごとの電子の最大数は、s が 2個、p が 6個、d が 10個、f が 14個です。また主殻の最大数 2n2 は、n ＝ 1 で 2個、n ＝ 2 で 8個、n ＝ 3 で 18個、n ＝ 4 で 32個となり、高校で学んだ K殻2個・L殻8個・M殻18個・N殻32個と一致します。

電子を軌道に詰めるときは、次の3つの決まりに従います。

  • 構築原理（アウフバウ原理）：電子はエネルギーの低い軌道から順に入る。エネルギーの順序はおおむね (n＋l) の小さい順で、たとえば 4s（n＋l ＝ 4）は 3d（n＋l ＝ 5）より先に埋まる。そのため軌道の埋まる順序は 1s → 2s → 2p → 3s → 3p → 4s → 3d → 4p → … となる
  • パウリの排他原理：1つの軌道に入れる電子は最大2個までで、その2個はスピンの向きが互いに逆（ms が ＋1/2 と −1/2）でなければならない。言い換えると、同じ原子の中で4つの量子数がすべて一致する電子は2つと存在しない
  • フントの規則：同じ副殻の中では、電子はまず別々の軌道にスピンをそろえて1個ずつ入り、軌道が一巡してから対を作り始める

なお、電子配置を書くときは埋まった内側の軌道を希ガスの元素記号で省略することがあります。たとえば鉄の配置は [Ar] 4s2 3d6 のように書けます。また、遷移元素では 4s と 3d のエネルギーが近く、クロムや銅のように単純な順序からずれる例外や、イオンになるときは 4s の電子から先に失われるといった注意点があります。

解き方の手順

  1. n から l の範囲を決める。l は 0 から n−1 までです。l の値を見て s・p・d・f のどの軌道かを読みます。
  2. 軌道の数を数える。副殻ごとに軌道は 2l＋1 個あります。主殻全体では n2 個です。
  3. 電子の最大数を求める。1軌道に2個まで（パウリの排他原理）なので、軌道数×2 が最大数です。主殻では 2n2 個になります。
  4. 電子配置を書くときはエネルギーの低い順に詰める。1s → 2s → 2p → 3s → 3p → 4s → 3d → … の順に、副殻の上限（s は2、p は6、d は10）まで入れ、最後に電子の総数が原子番号と一致するか検算します。
  5. 不対電子を数えるときはフントの規則で配置する。同じ副殻では別々の軌道に1個ずつ入れてから対にし、1個だけ入った軌道の数が不対電子の数です。

例題

問題1：主量子数 n ＝ 3 の主殻に含まれる軌道の種類と数を挙げ、入れる電子の最大数を答えよ。問題2：量子数の組（n, l, ml, ms）として、(2, 1, 0, ＋1/2) と (2, 2, 0, −1/2) はそれぞれ許されるか判定せよ。問題3：鉄（原子番号26）の電子配置を軌道表記で書き、不対電子の数を答えよ。

答えと解説を見る
  1. 問題1：n ＝ 3 では l ＝ 0, 1, 2 が取れます。l ＝ 0 は 3s 軌道で1個、l ＝ 1 は 3p 軌道で 2l＋1 ＝ 3個、l ＝ 2 は 3d 軌道で 2l＋1 ＝ 5個です。軌道は合計 1＋3＋5 ＝ 9個（＝ n2 ＝ 32）で、電子の最大数は 9×2 ＝ 18個（＝ 2n2 ＝ 2×32）です。
  2. 問題2：(2, 1, 0, ＋1/2) は、l ＝ 1 が n−1 ＝ 1 以下で、ml ＝ 0 が −1〜＋1 の範囲内なので許されます（2p 軌道の電子の1つです）。(2, 2, 0, −1/2) は、l が最大でも n−1 ＝ 1 までしか取れないため、l ＝ 2 は許されません。n ＝ 2 の主殻に d 軌道は存在しません。
  3. 問題3：電子26個をエネルギーの低い順に詰めると、1s に2個、2s に2個、2p に6個、3s に2個、3p に6個、4s に2個、ここまでで 2＋2＋6＋2＋6＋2 ＝ 20個。残り6個が 3d に入ります。電子配置は 1s2 2s2 2p6 3s2 3p6 4s2 3d6（合計 2＋2＋6＋2＋6＋2＋6 ＝ 26個で原子番号と一致）です。不対電子は 3d の6個に注目し、フントの規則で5個の d 軌道に1個ずつ入ると5個、6個目はどれか1つの軌道で対を作るので、不対電子は 5−1 ＝ 4個です。この不対電子の多さが、鉄が強磁性を示すことと関係しています。

答え：問題1は 3s が1個・3p が3個・3d が5個の計9軌道、電子の最大数は18個。問題2は (2, 1, 0, ＋1/2) は可、(2, 2, 0, −1/2) は不可。問題3は 1s2 2s2 2p6 3s2 3p6 4s2 3d6、不対電子は4個。電子配置を書いたら、上付き数字の合計が原子番号と一致するかを必ず検算してください。

現場での使われ方

量子化学計算による分子・材料の設計

分子の中の電子がどの軌道にどう広がるかをコンピュータで計算する量子化学計算は、新しい医薬品の候補化合物の性質予測や、触媒・電池材料の設計に使われています。分子軌道の形とエネルギーが分かると、反応が進みやすい場所や結合の強さを実験前に見積もることができます。原子軌道と量子数の考え方は、その計算の出発点です。

NMR と MRI ― スピン量子数の応用

原子核のスピンを利用する核磁気共鳴（NMR）は、有機化合物の構造を決める標準的な分析手法として化学の現場で日常的に使われています。同じ原理を人体の断層撮影に応用したものが医療の MRI です。電子や原子核がもつスピンという量子数レベルの性質が、そのまま分析・医療の技術になっています。

分光分析と元素の指紋

電子が軌道の間を移るとき、そのエネルギー差に等しい光が吸収・放出されます。原子ごとに軌道のエネルギーが違うため、スペクトルは元素ごとの「指紋」になり、試料に含まれる元素を調べる発光分析・吸光分析の原理になっています。炎色反応で元素ごとに色が違うのも、軌道間の遷移による発光です。

考え出した人

エルヴィン・シュレーディンガー（1887〜1961、オーストリアの物理学者）、ヴォルフガング・パウリ（1900〜1958、オーストリア出身の物理学者）、フリードリヒ・フント（1896〜1997、ドイツの物理学者）

1926年にオーストリアのエルヴィン・シュレーディンガーが波動方程式（シュレーディンガー方程式）を発表し、水素原子に適用すると、主量子数・方位量子数・磁気量子数が解の条件として自然に現れることが分かりました。電子が決まった軌道を回るボーアの模型に代わり、電子は軌道（オービタル）という確率の広がりとして存在する、という現在の描像はここから生まれました。排他原理は、オーストリア出身のヴォルフガング・パウリが1925年に提唱したもので、スペクトルの観測結果を整理する中で「同じ量子状態に電子は1つだけ」という規則にたどり着きました。電子のスピンは同じ頃にオランダの若手研究者ウーレンベックとハウトスミットが提案し、パウリの理論に組み込まれました。同じ副殻での電子の入り方を決めるフントの規則は、ドイツのフリードリヒ・フントが1920年代に原子スペクトルの解析から経験則としてまとめたものです。量子数は、観測されるスペクトルと周期表の並びを説明するために、物理と化学の境界で積み上げられた概念だといえます。
