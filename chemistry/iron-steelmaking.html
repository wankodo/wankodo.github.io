鉄と製鉄・鋼・合金

化学の考え方辞典 ― 無機化学（高校化学・3年）

化学ツール集トップ ＞ 無機化学 ＞ 鉄と製鉄・鋼・合金

高校化学・3年 無機化学

どんな時に使えるか 高炉で鉄鉱石を一酸化炭素で還元して銑鉄を取り出し、転炉で炭素を減らして鋼に変える仕組みと、炭素の量や加える金属で鉄の性質がどう変わるかを読み解くときに使う。炭素が多いほど硬くてもろく、少ないほど粘り強く、クロムなどを加えた合金は目的に合わせて設計される。

どんな問題に使うか

鉄鉱石から金属の鉄を取り出す還元の反応と、炭素の量やほかの金属の配合で変わる鉄材料の性質を扱うときの考え方です。次のような場面で使います。

  • 高炉の中で起こる反応（コークスの燃焼、一酸化炭素の生成、酸化鉄の還元）の反応式を書く・完成させる問題
  • 石灰石を入れる理由と、スラグが不純物を取り除く働きを説明する問題
  • 銑鉄・鋳鉄・鋼を、炭素の含有量と性質（硬さ・もろさ・粘り強さ）で区別する問題
  • ステンレス鋼がさびにくい理由など、合金の設計の考え方を説明する問題

土台は中学で学んだ還元（酸化物が酸素を奪われる反応）です。高炉の還元は、酸化銅を炭素で還元して銅を取り出す実験を、はるかに大きな規模で、一酸化炭素を使って行うものだと考えるとつながります。

公式・考え方

高炉の原料とコークスの働き

製鉄の原料は、鉄鉱石（主成分は酸化鉄(III) Fe2O3 などの酸化鉄）、コークス（石炭を蒸し焼きにした、炭素を主成分とする燃料）、石灰石 CaCO3 です。これらを高炉の上部から入れ、下部から熱風（高温の空気）を送り込みます。コークスには、炉を高温にする燃料と、酸化鉄から酸素を奪う還元剤を作る原料という、2つの役割があります。

炉の下部ではコークスが燃えて二酸化炭素ができ、大きな熱が出ます。

C ＋ O2 → CO2

できた二酸化炭素は、上へ行く途中で高温のコークスと反応して、還元剤である一酸化炭素 CO になります。

CO2 ＋ C → 2CO

酸化鉄の段階的な還元

一酸化炭素は、炉の上部から下部へ下りてくる酸化鉄から少しずつ酸素を奪います。還元は一気には進まず、Fe2O3 → Fe3O4 → FeO → Fe と、酸素の割合が段階的に減っていきます。各段階の代表的な反応式は次の通りです（いずれも、左辺と右辺で各原子の数がそろっていることを確認してください）。

3Fe2O3 ＋ CO → 2Fe3O4 ＋ CO2
Fe3O4 ＋ CO → 3FeO ＋ CO2
FeO ＋ CO → Fe ＋ CO2

全体をまとめると、酸化鉄(III)が一酸化炭素に還元される反応は次の式で表せます。一酸化炭素は酸素を受け取って二酸化炭素になる（酸化される）ので、ここでも酸化と還元が同時に起こっています。

Fe2O3 ＋ 3CO → 2Fe ＋ 3CO2

炉の下部では温度が非常に高くなり、できた鉄は溶けた状態で炉の底にたまります。この溶けた鉄を取り出したものが銑鉄（せんてつ）です。

石灰石とスラグの働き

鉄鉱石には、岩石分の不純物（主成分は二酸化ケイ素 SiO2）が含まれています。石灰石は、この不純物をスラグとして取り除くために入れます。石灰石は炉の中で熱分解して酸化カルシウム CaO になります。

CaCO3 → CaO ＋ CO2

酸化カルシウムが二酸化ケイ素と反応してできるケイ酸カルシウム CaSiO3 がスラグです。

CaO ＋ SiO2 → CaSiO3

スラグは溶けた鉄より密度が小さいため、鉄の上に浮きます。そのため不純物を抱え込んだまま鉄と分けて取り除くことができ、さらに鉄の表面をおおって酸化を防ぐ働きもします。

※ ここで紹介する実験・製法を実際に行うときは、学校の授業や専門家の指導のもとで、安全に十分注意し、自己責任で行ってください。

銑鉄・鋳鉄・鋼と転炉での製鋼

高炉から出た銑鉄は、炭素を約4％含んでいます（含有量はいずれも質量パーセントの目安です）。炭素が多い鉄は硬い反面、もろくて割れやすい性質があります。銑鉄を溶かし直して型に流し込んで固めたものが鋳鉄（ちゅうてつ）で、炭素量は約2〜4％です。複雑な形に作りやすい一方、強い衝撃には弱い性質を生かして使われます。

銑鉄の炭素を約2％以下まで減らすと、硬さと粘り強さをあわせ持つ鋼（こう、はがね）になります。この工程が製鋼で、代表的な設備が転炉です。転炉では、溶けた銑鉄に純粋な酸素を吹き込みます。すると炭素が酸素と化合して一酸化炭素や二酸化炭素となって取り除かれ、ケイ素やリンなどの不純物も酸化されてスラグに移ります。炭素をどこまで減らすか、どんな元素を残す・加えるかを調整することで、用途に合った鋼を作り分けます。

合金の設計

金属にほかの元素を加えて性質を改良したものを合金といいます。鉄の合金で代表的なのがステンレス鋼で、鉄にクロム Cr とニッケル Ni を加えた合金です（クロム約18％・ニッケル約8％を含むものが代表例です）。クロムは表面に薄くて緻密な酸化物の膜を作るため、内部が酸素や水に触れにくくなり、さびにくくなります。

合金の設計の基本は、「足りない性質を、加える元素で補う」ことです。鋼にマンガンやクロムを加えて硬さや耐摩耗性を上げる、ニッケルを加えて粘り強さや耐食性を上げる、といった具合です。鉄以外の合金でも考え方は同じで、たとえばアルミニウムに銅やマグネシウムを加えたジュラルミンは、軽さはそのままに強度を上げた合金として知られます（アルミニウム側のくわしい話は関連項目の「アルミニウムとその製錬」で扱います）。

各言葉の意味は次の通りです。

  • コークス：石炭を蒸し焼きにした炭素主体の燃料。高炉では燃料と還元剤（CO）の原料を兼ねる
  • スラグ：石灰石由来の CaO が不純物の SiO2 などと反応してできた、溶けた鉄に浮く副産物
  • 銑鉄：高炉で得られる、炭素を約4％含む鉄。硬いがもろい
  • 鋳鉄：銑鉄などを溶かして型に流し込んだ鉄。炭素量は約2〜4％
  • 鋼：炭素を約2％以下に減らした鉄。硬さと粘り強さをあわせ持つ
  • 転炉：溶けた銑鉄に酸素を吹き込んで炭素や不純物を酸化し、鋼を作る炉

解き方の手順

  1. 高炉の反応は「下から上へ」で追う。下部でコークスが燃える（C ＋ O2 → CO2）→ CO2 がコークスと反応して CO ができる → CO が酸化鉄を還元する、という流れで整理します。
  2. 還元は段階で書く。Fe2O3 → Fe3O4 → FeO → Fe の順に酸素が減ることを確認し、各式で原子の数が左右でそろうか検算します。
  3. 石灰石の話はスラグで締める。CaCO3 → CaO ＋ CO2、続いて CaO ＋ SiO2 → CaSiO3（スラグ）とつなげ、「鉄より軽く浮くので分離できる」までセットで答えます。
  4. 鉄材料は炭素量で見分ける。約4％なら銑鉄、約2〜4％で型に流したものなら鋳鉄、約2％以下なら鋼、と炭素量から判断し、「炭素が多いほど硬くてもろい」という性質と結びつけます。
  5. 合金は「何を加えて、何が良くなるか」で答える。ステンレス鋼なら「Cr と Ni を加える → 表面の酸化物の膜でさびにくくなる」のように、元素と効果をペアにします。

例題

問題1：高炉内の反応式を完成させよ。（ア）CO2 ＋ C → （　　）（イ）Fe2O3 ＋ 3CO → 2Fe ＋ （　　）問題2：炭素の含有量が（ア）約4％で硬くてもろい鉄、（イ）約0.5％で硬さと粘り強さをあわせ持つ鉄は、それぞれ何と呼ばれるか。問題3：高炉に石灰石を入れる目的を、スラグという言葉を使って説明せよ。また、スラグができる反応式 CaO ＋ SiO2 → （　　）を完成させよ。問題4：ステンレス鋼がさびにくい理由を、加えられている元素に触れて説明せよ。

答えと解説を見る
  1. 問題1：（ア）は二酸化炭素が高温のコークスと反応する式で、生成物は一酸化炭素 2CO です。係数は C が左辺2個・右辺2個、O が左辺2個・右辺2個でそろいます。（イ）は酸化鉄(III)の還元のまとめの式で、生成物は二酸化炭素 3CO2 です。Fe は2個、O は左辺 3＋3＝6個・右辺 3×2＝6個、C は3個でそろいます。
  2. 問題2：（ア）炭素を約4％含む鉄は銑鉄です。炭素が多いため硬い反面、もろくなります。（イ）炭素を約2％以下に減らした鉄は鋼で、約0.5％はその範囲に入ります。転炉で銑鉄に酸素を吹き込み、炭素を酸化して取り除くことで作られます。
  3. 問題3：石灰石から生じる酸化カルシウム CaO が、鉄鉱石中の不純物である二酸化ケイ素 SiO2 と反応してスラグ（ケイ酸カルシウム CaSiO3）を作り、不純物をスラグとして取り除くためです。完成した式は CaO ＋ SiO2 → CaSiO3 で、Ca・Si・O（3個）の数が左右でそろいます。スラグは溶けた鉄より密度が小さく浮くので、鉄と分離できます。
  4. 問題4：ステンレス鋼にはクロム Cr（とニッケル Ni）が加えられています。クロムが表面に薄くて緻密な酸化物の膜を作り、内部の鉄が酸素や水に触れるのを防ぐため、さびにくくなります。

答え：問題1は（ア）2CO、（イ）3CO2。問題2は（ア）銑鉄、（イ）鋼。問題3は不純物 SiO2 をスラグ CaSiO3 として取り除くため（式の空欄は CaSiO3）。問題4はクロムが表面に緻密な酸化物の膜を作るため。高炉の反応は「CO を作る → CO が還元する → スラグで不純物を取る」の3段で押さえるのが要点です。

現場での使われ方

製鉄所の高炉と転炉

実際の製鉄所では、高さ数十メートルの高炉で鉄鉱石・コークス・石灰石を連続的に投入し、溶けた銑鉄を昼夜休まず取り出しています。銑鉄は転炉へ運ばれ、酸素を吹き込んで炭素量を調整し、自動車のボディー用、建築用など用途別に成分を変えた鋼が作られます。この記事の反応の流れそのものが、製鉄所の工程の骨格です。

建材・レール・自動車の鋼

ビルや橋の鉄骨、鉄道のレール、自動車の車体には、炭素量や合金元素を用途に合わせて調整した鋼が使われます。硬さが要る場所、曲げや衝撃に耐える粘り強さが要る場所で、成分の違う鋼が使い分けられています。

ステンレス鋼の製品

台所の流し台や鍋、医療器具、化学プラントの配管など、水や薬品に触れてもさびにくさが求められる場所ではステンレス鋼が使われます。クロムの作る酸化物の膜がさびを防ぐという性質を、そのまま製品の寿命に生かした例です。

スラグの再利用

高炉で生じるスラグは捨てられるだけのものではなく、冷やして固めたものがセメントの原料や道路の路盤材などに利用されています。不純物を取り除く副産物まで資源として使うことが、製鉄の現場で行われています。

考え出した人

ヘンリー・ベッセマー（1813〜1898、イギリスの技術者）

製鉄そのものは古代から各地で行われてきた技術で、特定の1人が考え出したものではありません。その中で、銑鉄から鋼を大量に作る方法の転機を作ったのが、イギリスの技術者ヘンリー・ベッセマー（1813〜1898）です。ベッセマーは1850年代に、溶けた銑鉄に空気を吹き込むと、炭素などの不純物が酸化して取り除かれ、鋼が得られる転炉法（ベッセマー法）を考案しました。吹き込む気体を空気から純粋な酸素に変えた現在の転炉は、この方法の発展形です。高炉で銑鉄を作り、転炉で鋼に変えるという今の製鉄の二段構えは、この時代に形が整いました。
