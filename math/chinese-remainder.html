大学 数と式 計算機あり

どんな時に使えるかRSA暗号の復号を高速化する実装（CRT-RSA）に使われ、実際の暗号ライブラリに組み込まれている。余りの情報から元の数を復元する仕組みは、誤り訂正や並列計算（剰余数系）の土台にもなっている。

どんな問題に使うか

「3で割ると2余り、5で割ると3余る数」のように、いくつかの数で割った余りの条件（連立合同式）を同時に満たす数を求める問題です。余りの情報だけから、もとの数を復元するのが狙いです。

  • x ≡ a1 (mod m1)、x ≡ a2 (mod m2) のような連立合同式を解く問題
  • 「○で割ると△余り、□で割ると◇余る数をすべて求めよ」という余りの条件から数を復元する問題
  • 法（割る数）同士が互いに素でない場合に、解があるかどうかを判定する問題
  • 大きな数の計算を、小さい法ごとの計算に分解して組み立てる問題

法が互いに素なら解は必ず1つ（法の積を法として）に定まります。互いに素でない場合でも、余りの差が法の最大公約数で割り切れれば解があり、この「逐次合成」で機械的に求められます。

公式・考え方

x ≡ a1 (mod m1)，　x ≡ a2 (mod m2)

定理（互いに素な場合）：m1 と m2 が互いに素なら、上の連立合同式には解があり、解は mod m1m2 でただ1つに定まります。法が3つ以上でも、2つずつ合成していけば同じです。

解がある条件（一般の場合）：g ＝ gcd(m1, m2) とすると、解があるのは a2 − a1 が g で割り切れるときに限ります。その場合、解は mod lcm(m1, m2) でただ1つです。

逐次合成の考え方：1つ目の条件を満たす数は x ＝ a1 ＋ m1t の形に書けます。これを2つ目の条件に代入すると m1t ≡ a2 − a1 (mod m2) という t についての合同式になり、両辺を g で割って拡張ユークリッドの互除法で逆元を求めれば t が決まります。

解き方の手順

  1. 余りを 0 以上、法未満に正規化する。余りが法以上や負の場合は、法の倍数を足し引きして範囲内に直す（合同式としては同じ条件）。
  2. g ＝ gcd(m1, m2) を求め、a2 − a1 が g で割り切れるか確認する。割り切れなければ「解なし」で終了。
  3. x ＝ a1 ＋ m1t と置き、t の合同式を立てる。m1t ≡ a2 − a1 (mod m2) を g で割り、(m1/g) t ≡ (a2 − a1)/g (mod m2/g) とする。
  4. 拡張ユークリッドの互除法で (m1/g) の mod (m2/g) での逆元を求め、t を決める。t は mod (m2/g) で1つに定まる。
  5. 合成した解 x ＝ a1 ＋ m1t を mod lcm(m1, m2) で書き直す。3つ目の条件があれば、この解を新しい1つ目の条件として同じ手順を繰り返す。

例題

問題（『孫子算経』の古典問題）：3で割ると2余り、5で割ると3余り、7で割ると2余る数を求めよ。

答えと解説を見る

連立合同式 x ≡ 2 (mod 3)、x ≡ 3 (mod 5)、x ≡ 2 (mod 7) を解きます。法 3, 5, 7 は互いに素なので、解は mod 105 でただ1つです。

  1. まず x ≡ 2 (mod 3) と x ≡ 3 (mod 5) を合成する。x ＝ 2 ＋ 3t と置くと 3t ≡ 1 (mod 5)。3 の mod 5 での逆元は 2（3×2 ＝ 6 ≡ 1）なので t ≡ 2 (mod 5)、よって x ≡ 8 (mod 15)。
  2. 次に x ≡ 8 (mod 15) と x ≡ 2 (mod 7) を合成する。x ＝ 8 ＋ 15t と置くと 15t ≡ −6 ≡ 1 (mod 7)。15 ≡ 1 (mod 7) なので t ≡ 1 (mod 7)、よって x ≡ 23 (mod 105)。

答え：x ≡ 23 (mod 105)、すなわち 23 ＋ 105k（k は整数）。最小の正の解は 23（検算：23 ＝ 3×7 ＋ 2、23 ＝ 5×4 ＋ 3、23 ＝ 7×3 ＋ 2）。

現場での使われ方

RSA暗号の復号の高速化（CRT-RSA）

RSA暗号の復号は大きな法 n ＝ pq のもとでのべき乗計算で、計算が重いのが難点です。そこで秘密鍵の持ち主だけが知る素数 p, q ごとに mod p と mod q で別々に計算し、最後に中国剰余定理で組み立てる実装が広く使われています。各法が約半分の桁数になるため、復号や署名の生成が大幅に速くなります。OpenSSL などの実際の暗号ライブラリに組み込まれている手法です。

剰余数系による並列計算

大きな数を、互いに素な小さな法での余りの組として表す「剰余数系（RNS）」では、足し算・掛け算を法ごとに独立して並列に実行でき、最後に中国剰余定理で元の数に戻します。桁あふれの心配なく大きな数の演算を高速化できるため、信号処理や暗号演算のハードウェア実装で使われます。

誤り訂正符号とのつながり

余りの情報から元のデータを復元するという発想は、リード・ソロモン符号などの誤り訂正の考え方とも通じます。中国剰余定理そのものを使う符号（剰余符号）もあり、一部のデータが壊れても残りの余りから元の数を復元できる仕組みに応用されています。

考え出した人

中国の数学書『孫子算経』（3〜5世紀頃）に、原問題「3で割ると2余り、5で割ると3余り、7で割ると2余る数を求める」とその解法が載っています。一般的な解法を確立したのは南宋の秦九韶（1208〜1261）で、著書『数書九章』（1247）の中で「大衍求一術」と呼ばれる方法を与え、法が互いに素でない場合まで含めて連立合同式を解く手順を示しました。
