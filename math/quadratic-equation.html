二次方程式

数学解法辞典 ― 方程式（中学・高校）

数学ツール集トップ ＞ 方程式 ＞ 二次方程式

中学・高校 方程式 計算機あり

どんな時に使えるか ロケットや砲弾の弾道計算、橋のアーチやパラボラアンテナの形の設計など、放物線が関わる場面で使う。ボールを投げたときの高さや、面積から一辺の長さを求める問題もこの仲間。

どんな問題に使うか

二次方程式は、x2 を含む方程式（ax2 ＋ bx ＋ c ＝ 0、a ≠ 0）のことです。次のような場面で使います。

  • 面積が分かっている長方形や正方形の、一辺の長さを求める問題
  • ボールを投げたときの高さや、地面に落ちるまでの時間を求める問題（物の動きは放物線を描く）
  • 二次関数のグラフと x 軸の交点を求める問題
  • 2つの数の積や和が条件として与えられ、一方の数を求める問題

「面積」「放物線」「高さ」のように、量が2乗で関わる場面では、二次方程式が現れます。

公式・考え方

解き方は大きく3つあります。簡単な順に試すのが基本です。

1. 因数分解を使う

左辺を (x ＋ p)(x ＋ q) の形に因数分解できれば、積が 0 になるのは各因数が 0 のときなので、x ＝ −p、−q と解が読めます。まずこの方法で解けないかを試します。

2. 平方完成を使う

x2 ＋ bx の部分を (x ＋ ○)2 の形に作り替える方法です。(x ＋ ○)2 ＝ 数 の形になれば、平方根をとって解けます。解の公式を導くときにも使う、基本になる考え方です。

3. 解の公式を使う

x ＝ (−b ± √(b2 − 4ac)) / 2a

因数分解できない場合でも、解の公式に a・b・c をあてはめれば必ず解けます（実数の範囲で解がある場合）。

判別式で解の個数が分かる

解の公式の √ の中身 D ＝ b2 − 4ac を判別式といいます。D ＞ 0 なら解は2つ、D ＝ 0 なら解は1つ（重解）、D ＜ 0 なら実数の解はありません。解く前に、解が何個あるかを見通せます。

解き方の手順

  1. ax2 ＋ bx ＋ c ＝ 0 の形に整理する。右辺を 0 にして、a・b・c を読み取ります。
  2. 因数分解できないか試す。できれば、各因数を 0 と置いて解を読みます。
  3. できなければ解の公式を使う。まず判別式 D ＝ b2 − 4ac を計算し、解の個数を確認してから公式にあてはめます。
  4. 問題の条件に合う解を選ぶ。長さや面積の問題では、負の解は条件に合わないことがあります。2つの解のうち、場面に合う方を答えにします。

例題

問題：縦が横より2m長い長方形の花壇がある。面積が24m2 のとき、横の長さは何mか。

答えと解説を見る

横の長さを x m とすると、縦は (x ＋ 2) m です。面積は横 × 縦なので、方程式が立てられます。

  1. 面積の式を立てる：x(x ＋ 2) ＝ 24
  2. 展開して整理する：x2 ＋ 2x − 24 ＝ 0
  3. 因数分解する：掛けて −24、足して 2 になるのは 6 と −4 なので、(x ＋ 6)(x − 4) ＝ 0
  4. 各因数を 0 と置く：x ＋ 6 ＝ 0 から x ＝ −6、x − 4 ＝ 0 から x ＝ 4
  5. 長さは正の数なので、x ＝ −6 は条件に合わない。よって x ＝ 4。

答え：4m（縦は 6m で、4 × 6 ＝ 24m2 になる）。

現場での使われ方

弾道計算

投げたボールや発射された砲弾は、重力の影響で放物線を描いて飛びます。高さは時間の二次式で表されるため、「どの高さに達するか」「いつ地面に落ちるか」は二次方程式を解いて求めます。ロケットや砲弾の弾道計算も、この考え方が土台です。

橋のアーチやパラボラアンテナの設計

橋のアーチや、電波を集めるパラボラアンテナの反射面は、放物線（二次関数の曲線）の形をしています。放物線の形を決めたり、特定の高さでの幅を求めたりする計算では、二次方程式が使われます。

面積から辺の長さを求める場面

土地や部屋、材料などの面積が決まっているとき、縦と横の関係（「縦は横より○m長い」など）から一辺の長さを求める計算は、例題と同じ二次方程式になります。設計や見積もりの現場で現れる計算です。
