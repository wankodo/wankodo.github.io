関数の凹凸と第2次導関数

数学解法辞典 ― 微分・積分（高校）

数学ツール集トップ ＞ 微分・積分 ＞ 関数の凹凸と第2次導関数

高校 微分・積分 計算機あり

どんな時に使えるかグラフが上に凸か下に凸かは、第2次導関数の符号で決まる。経済学で『量を増やすほど追加の満足度が減る』限界効用逓減は上に凸の形そのもので、機械学習では損失関数が下に凸であることが大域的な最適解にたどり着ける保証になる。薬の用量と効き方の関係の読み取りにも、凹凸と変曲点の考え方が使われている。

どんな問題に使うか

関数のグラフが「上に凸」か「下に凸」かを区間ごとに調べ、凹凸が切り替わる点（変曲点）を求める問題です。第1次導関数がグラフの「増減」を決めるのに対して、第2次導関数はグラフの「曲がり方」を決めます。

  • 第2次導関数の符号から、区間ごとの凹凸を答える問題
  • 変曲点の座標を求める問題
  • 増減と凹凸を合わせて増減表を完成させ、グラフの概形を描く問題
  • 第2次導関数の符号と接線・グラフの位置関係を考える問題

極値を求めるだけの問題と違い、こちらは「グラフがどう曲がっているか」まで含めて概形を仕上げるのが目的です。

公式・考え方

関数 f(x) を2回微分したものを第2次導関数といい、f′′(x) と書きます。第2次導関数は、第1次導関数（接線の傾き）がどれだけの速さで変化しているかを表します。傾きが増えていくグラフは下向きに膨らみ、傾きが減っていくグラフは上向きに膨らむ、という対応が基本です。

f′′(x) ＞ 0 の区間では、グラフは下に凸 ／ f′′(x) ＜ 0 の区間では、グラフは上に凸

グラフの凹凸が切り替わる点を変曲点といいます。変曲点では f′′(x) ＝ 0 になることが必要ですが、それだけでは十分ではありません。f′′(x) ＝ 0 でも、その前後で f′′ の符号が変わらなければ変曲点にはなりません。たとえば f(x) ＝ x⁴ では f′′(x) ＝ 12x² で、x ＝ 0 のとき f′′ ＝ 0 ですが、前後とも f′′ ＞ 0 のままなので (0, 0) は変曲点ではありません。

変曲点 ＝ f′′(x) ＝ 0 かつ、その前後で f′′ の符号が切り替わる点

グラフの概形は、第1次導関数と第2次導関数を組み合わせて完成します。f′(x) の符号で増減を、f′′(x) の符号で凹凸を調べ、増減表に両方を書き込むと、極値の位置だけでなく曲がり方まで決まった概形が描けます。

解き方の手順

  1. f′(x) と f′′(x) を求める。元の関数を2回続けて微分する。
  2. f′′(x) ＝ 0 となる x を求める。ここが変曲点の候補になる。
  3. 候補の前後で f′′ の符号を調べる。符号が切り替わっていれば変曲点、変わらなければ変曲点ではない。
  4. 区間ごとの凹凸を答える。f′′ ＞ 0 の区間は下に凸、f′′ ＜ 0 の区間は上に凸。
  5. 変曲点の y 座標を求める。候補の x を元の関数に代入し、点の座標として答える。
  6. 必要なら増減表にまとめる。f′ の符号（増減）と f′′ の符号（凹凸）を合わせて、グラフの概形を描く。

例題

問題：関数 f(x) ＝ x³ − 6x² ＋ 5 の凹凸を調べ、変曲点を求めよ。

答えと解説を見る

f′(x) ＝ 3x² − 12x、f′′(x) ＝ 6x − 12 です。f′′(x) ＝ 0 となるのは x ＝ 2 のときです。

x ＜ 2 では f′′(x) ＜ 0 なので上に凸、x ＞ 2 では f′′(x) ＞ 0 なので下に凸です。x ＝ 2 の前後で符号が切り替わっているので、ここが変曲点になります。

f(2) ＝ 8 − 24 ＋ 5 ＝ −11 です。

答え：x ＜ 2 で上に凸、x ＞ 2 で下に凸。変曲点は (2, −11)

現場での使われ方

経済学の限界効用逓減

同じものをたくさん消費するほど、1単位増えたときの追加の満足度（限界効用）は小さくなっていく、というのが経済学の限界効用逓減の法則です。効用を量の関数としてグラフに描くと、増え方はだんだん緩やかになる上に凸の形になります。価格設定や税制の議論で「追加分への効き目がどう変わるか」を読むとき、この凹凸の見方が土台になっています。

機械学習で最適化がうまくいく保証

機械学習では、損失関数（予測の誤差を表す関数）を最小にするパラメータを探します。損失関数が下に凸な形をしていると、局所的な最小値がそのまま全体の最小値になるため、勾配を下っていく方法で大域的な最適解にたどり着けることが保証されます。線形回帰の二乗誤差などがこの性質を持っていて、逆にニューラルネットワークのように凸でない場合は、初期値によって結果が変わりうる難しさが生まれます。

薬の用量反応曲線を読む

薬の用量を増やしたとき効き目がどう変わるかを示す用量反応曲線は、少ない用量では効き目が急に立ち上がり、ある量を超えると効き目の伸びが鈍って頭打ちに近づく形になることが多くあります。この「伸び方が切り替わるあたり」を読むときに、曲線の凹凸や変曲点の考え方が、適切な用量の範囲を考える手がかりになります。

考え出した人

凹凸と第2次導関数の関係は、特定の誰か一人が考え出したものではありません。17世紀にニュートンとライプニッツが微積分を築き、その後、関数のグラフの形を導関数で読み解く方法が微分学の発展の中で少しずつ整えられていきました。第2次導関数の符号で曲がり方を判定する見方は、その積み重ねの上に確立した、微分学の基本的な道具の一つです。
