医薬品の化学

化学の考え方辞典 ― 有機化学（高校化学・3年）

化学ツール集トップ ＞ 有機化学 ＞ 医薬品の化学

高校化学・3年 有機化学

どんな時に使えるか 医薬品の多くは有機化合物であり、その働きは分子の構造、とくに官能基の種類と並び方で決まる。アスピリン（アセチルサリチル酸）は、サリチル酸のフェノール性ヒドロキシ基を無水酢酸でアセチル化して得られる化合物で、カルボキシ基とエステル結合をあわせもつ。構造式から官能基を読み取り、分子式とモル質量を押さえることが、医薬品を化学として理解する入口になる。

どんな問題に使うか

医薬品として知られる有機化合物を、構造式と官能基の観点から読み解くときの考え方です。次のような場面で使います。

  • アスピリンやサリチル酸などの構造式を見て、含まれる官能基（カルボキシ基、エステル結合、ヒドロキシ基など）を指摘する問題
  • 構造式から分子式を数え、モル質量や物質量を求める問題
  • サリチル酸からアスピリンを合成する反応で、分子のどの部分がどう変わったかを説明する問題
  • よく似た構造の化合物（サリチル酸、サリチル酸メチル、アスピリン）を、構造の違いから区別する問題
  • 光学異性体をもつ医薬品について、不斉炭素原子を見つける問題

この項目では医療上の効能を断定することはせず、「構造がどうなっていて、どんな反応で作られ、官能基がどう働きに関わるか」という化学の側面に軸を置きます。前提となるサリチル酸の性質は「フェノールと芳香族カルボン酸」、エステル化の基礎は「カルボン酸とエステル」で扱っています。

公式・考え方

アスピリン ― サリチル酸のアセチル化

サリチル酸は、ベンゼン環にカルボキシ基 −COOH とフェノール性ヒドロキシ基 −OH が隣り合って（オルト位に）付いた芳香族化合物で、分子式は C7H6O3 です。このヒドロキシ基を無水酢酸でアセチル化（アセチル基 CH3CO− を導入すること）すると、ヒドロキシ基がエステル結合 −OCOCH3 に変わり、アスピリン（アセチルサリチル酸）が得られます。副生成物は酢酸です。

サリチル酸 C7H6O3 ＋ 無水酢酸 C4H6O3 → アスピリン C9H8O4 ＋ 酢酸 C2H4O2

原子の数を両辺で比べると、C は 7＋4＝11 と 9＋2＝11、H は 6＋6＝12 と 8＋4＝12、O は 3＋3＝6 と 4＋2＝6 でそろいます。アスピリンの分子式 C9H8O4 からモル質量を計算すると、C＝12、H＝1.0、O＝16 を使って 12×9＋1.0×8＋16×4＝180 g/mol です。アスピリンは一般に解熱鎮痛薬の有効成分として知られ、その働きについては、体内で痛みや発熱に関わる物質プロスタグランジンの合成を担う酵素の働きを阻害することによる、と一般に説明されています。化学の観点で重要なのは、サリチル酸の −OH をエステルに変えるという小さな構造の変更が、化合物の性質（水への溶けやすさや体内での振る舞い）を変えるという点です。

※ ここで紹介する実験・製法を実際に行うときは、学校の授業や専門家の指導のもとで、安全に十分注意し、自己責任で行ってください。

サリチル酸と無水酢酸からアスピリンと酢酸ができる反応の構造式。変わるのはサリチル酸のフェノール性ヒドロキシ基の部分だけで、ベンゼン環とカルボキシ基はそのまま残ります。図中の CH3COO− は、環に近い側の O がエステル結合の酸素です。

サリチル酸メチルとパラセタモール

サリチル酸の仲間には、もう1つの代表的な化合物があります。サリチル酸メチルは、サリチル酸のカルボキシ基 −COOH の H がメチル基 −CH3 に置き換わったエステルで、分子式は C8H8O3 です。フェノール性ヒドロキシ基はそのまま残っています。アスピリンと比べると、「サリチル酸のどちらの −OH 側をエステルにしたか」が逆の関係にあり、構造の違いを読み比べる良い練習になります。サリチル酸メチルは、湿布薬などの外用剤の成分として配合されていることで知られます。

パラセタモール（アセトアミノフェン）は、ベンゼン環にヒドロキシ基 −OH とアミド結合 −NHCOCH3 が向かい合って（パラ位に）付いた化合物で、分子式は C8H9NO2 です。解熱鎮痛を目的とする医薬品の成分として広く知られますが、構造の上ではアスピリンと大きく違い、カルボキシ基もエステル結合ももたず、窒素を含むアミド結合をもつ点が特徴です。

サリチル酸メチルとパラセタモールの構造式。サリチル酸メチルはサリチル酸のカルボキシ基側をエステル化した形、パラセタモールはアミド結合をもち窒素を含む点がアスピリンとの大きな違いです。

官能基と働きの関係、光学異性体への入口

医薬品の分子は、体内の特定のタンパク質（酵素や受容体）などに結びついて働くことが多く、その結びつきやすさは分子の形と官能基の種類・位置で決まります。だから医薬品の開発では、骨格は保ったまま官能基を1つ変え、性質の変化を比べる、という進め方が基本になります。サリチル酸→アスピリンの変更は、その最も有名な例の1つです。

もう1つ重要なのが立体構造です。4つの異なる原子・原子団と結びついた炭素（不斉炭素原子）をもつ分子には、鏡に映した関係にある2つの光学異性体（鏡像異性体）が存在します。生体内のタンパク質も不斉な環境をもつため、光学異性体どうしで体内での振る舞いが異なる場合があることが知られており、医薬品では異性体を分けて作る・調べることが重要になります。例えば解熱鎮痛成分として知られるイブプロフェン（分子式 C13H18O2）は不斉炭素原子を1つもち、光学異性体の組が存在します。詳しくは「光学異性体と不斉炭素」で扱います。

イブプロフェンの構造式。ベンゼン環の向かい合う位置（パラ位）に2つの置換基が付き、右側の置換基の付け根の炭素（＊印）が、H、CH3、COOH、ベンゼン環側の4つの異なる原子団と結びついた不斉炭素原子です。

解き方の手順

  1. ベンゼン環と置換基を分けて見る。環に付いている原子団を1つずつ切り離し、それぞれが何の官能基かを当てます（−COOH はカルボキシ基、−COO− はエステル結合、環に直接付いた −OH はフェノール性ヒドロキシ基、−NHCO− はアミド結合）。
  2. 原子の数を数えて分子式を作る。環の炭素6個と水素（置換された位置の分だけ減る）に、置換基の原子を足し合わせます。炭素の手が4本にそろうかも検算します。
  3. モル質量を求める。原子量（H＝1.0、C＝12、N＝14、O＝16）を分子式に当てはめて合計し、物質量や理論収量の計算につなげます。
  4. 反応前後で変わった部分だけを比べる。合成反応では、骨格のうち変化した官能基だけに注目し、「どの基が何に変わったか」を言葉で表します。
  5. 不斉炭素原子がないか探す。4つの異なる原子・原子団と結びついた炭素があれば、光学異性体の存在を検討します。

例題

問題1：アスピリンの構造式（上の図）について、（1）含まれる官能基をすべて答えよ。（2）分子式を答えよ。（3）モル質量を求めよ。原子量は H＝1.0、C＝12、O＝16 とする。

答えと解説を見る

（1）ベンゼン環には −COOH と −OCOCH3 が付いています。−COOH はカルボキシ基、−OCOCH3 の −COO− の部分はエステル結合です。サリチル酸にあったフェノール性ヒドロキシ基は、アセチル化によってエステルに変わっているため残っていません。（2）環の C が6個・H が4個、−COOH が C1個・H1個・O2個、−OCOCH3 が C2個・H3個・O2個で、合計は C9H8O4 です。（3）モル質量は 12×9＋1.0×8＋16×4＝108＋8＋64＝180 g/mol です。

答え：（1）カルボキシ基とエステル結合。（2）C9H8O4。（3）180 g/mol。

問題2：サリチル酸メチルの構造式（上の図）について、（1）含まれる官能基をすべて答えよ。（2）分子式を答えよ。（3）アスピリンとの構造上の違いを、どちらの化合物もサリチル酸と関係づけて説明せよ。

答えと解説を見る

（1）ベンゼン環には −OH と −COOCH3 が付いています。環に直接付いた −OH はフェノール性ヒドロキシ基、−COOCH3 の −COO− の部分はエステル結合です。カルボキシ基そのものは、H が CH3 に置き換わってエステルになっているため含まれません。（2）環の C6個・H4個、−OH が H1個・O1個、−COOCH3 が C2個・H3個・O2個で、合計は C8H8O3 です。（3）アスピリンはサリチル酸のヒドロキシ基側をアセチル化してエステルにしたものでカルボキシ基が残り、サリチル酸メチルはサリチル酸のカルボキシ基側をメチルエステルにしたものでヒドロキシ基が残ります。同じサリチル酸から出発しても、変える場所が逆の関係です。

答え：（1）フェノール性ヒドロキシ基とエステル結合。（2）C8H8O3。（3）アスピリンは −OH 側、サリチル酸メチルは −COOH 側をエステル化したもの。

問題3：パラセタモールの構造式（上の図）について、（1）含まれる官能基をすべて答えよ。（2）分子式を答えよ。（3）カルボキシ基とエステル結合は含まれるか答えよ。

答えと解説を見る

（1）ベンゼン環には −OH と −NHCOCH3 がパラ位に付いています。−OH はフェノール性ヒドロキシ基、−NHCOCH3 の −NHCO− の部分はアミド結合です。（2）環の C6個・H4個、−OH が H1個・O1個、−NHCOCH3 が C2個・H4個（NH の H が1個と CH3 の H が3個）・N1個・O1個で、合計は C8H9NO2 です。窒素を含む点が、アスピリンやサリチル酸メチルとの違いです。（3）−COOH の形はなく、アミド結合の C＝O はエステル結合（−COO−）とは別物なので、カルボキシ基もエステル結合も含まれません。

答え：（1）フェノール性ヒドロキシ基とアミド結合。（2）C8H9NO2。（3）どちらも含まれない。

問題4：サリチル酸 1.38 g をすべてアスピリンに変えることができたとすると、得られるアスピリンは何 g か。また、アスピリン 0.90 g は何 mol か。サリチル酸のモル質量は 138 g/mol、アスピリンのモル質量は 180 g/mol とする。

答えと解説を見る

反応式ではサリチル酸1 mol からアスピリン1 mol が得られるので、物質量はそのまま引き継がれます。サリチル酸 1.38 g は 1.38÷138＝0.0100 mol なので、得られるアスピリンも 0.0100 mol で、質量は 0.0100×180＝1.80 g です（これが理論上の最大量＝理論収量です）。アスピリン 0.90 g の物質量は 0.90÷180＝0.0050 mol、つまり 5.0×10−3 mol です。

答え：理論収量は 1.80 g、アスピリン 0.90 g は 5.0×10−3 mol。

問題5：イブプロフェンの構造式（上の図）について、（1）不斉炭素原子はどれか答えよ。（2）アスピリンとサリチル酸メチルには光学異性体が存在するか答えよ。

答えと解説を見る

（1）右側の置換基 −CH(CH3)COOH の付け根の炭素（図の＊印）が、H、CH3、COOH、ベンゼン環側の原子団という4つの異なる原子・原子団と結びついているため、不斉炭素原子です。したがってイブプロフェンには、鏡像の関係にある1組の光学異性体が存在します。（2）アスピリンとサリチル酸メチルの炭素は、ベンゼン環の炭素（平面構造）と、同じ原子団を複数もつ炭素（CH3 の炭素など）だけで、4つの異なる原子団と結びついた炭素はありません。よってどちらにも光学異性体は存在しません。

答え：（1）−CH(CH3)COOH の CH の炭素。（2）どちらも存在しない。

現場での使われ方

製薬工場での合成と品質管理

アスピリンの工業的な製造は、サリチル酸をアセチル化するという、ここで学ぶ反応そのものを大規模に行うものです。工場では反応の進み具合だけでなく、できた製品の純度や、未反応のサリチル酸がどれだけ残っているかといった品質の確認が欠かせません。構造式から官能基を読み、モル質量から収量を見積もる計算は、製造と分析の実務の土台になっています。

医薬品の研究開発と構造の改良

新しい医薬品の開発では、効き目に関わる骨格は保ちながら、官能基を1つずつ変えた化合物を多数合成し、性質の違いを比べる方法が取られます。水に溶けやすいか、体内で分解されにくいかといった性質は官能基で大きく変わるため、「官能基と働きの関係」を読む力は研究開発の入口の知識です。また、光学異性体をもつ化合物では、異性体ごとに分けて合成・評価する工程が必要になる場合があります。

薬局と成分表示の読み取り

市販薬のパッケージには、アスピリン、アセトアミノフェン、イブプロフェン、サリチル酸メチルといった成分名が表示されています。これらはいずれも有機化合物の名前であり、構造式と結びつけて理解できると、「同じ解熱鎮痛の目的でも構造の違う成分がある」「外用剤にはサリチル酸の仲間が使われている」といった、成分表示の背景を化学の言葉で読み解けるようになります。

考え出した人

フェリックス・ホフマン（1868〜1946、ドイツの化学者）

アスピリンの合成に成功したのは、ドイツの製薬会社バイエルに勤めていた化学者フェリックス・ホフマン（1868〜1946）です。ホフマンは1897年、サリチル酸を無水酢酸でアセチル化する方法によって、純度の高いアセチルサリチル酸を得ることに成功しました。サリチル酸そのものは解熱鎮痛の作用をもつ物質として知られていましたが扱いに課題があり、そのヒドロキシ基をエステルに変えるという構造上の工夫が、製品化への道を開きました。バイエルはこの化合物を「アスピリン」の名で1899年に発売し、アスピリンは世界で最も広く知られる医薬品の1つになりました。「官能基を1つ変えて性質を改良する」という発想は、現代の医薬品開発にも通じる基本の考え方です。
