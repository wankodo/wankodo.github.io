酸化数

化学の考え方辞典 ― 酸化還元・電池と電気分解（高校化学基礎・1年）

化学ツール集トップ ＞ 酸化還元・電池と電気分解 ＞ 酸化数

高校化学基礎・1年 酸化還元・電池と電気分解 計算機あり

どんな時に使えるか 酸化数は、化合物やイオンの中の原子が、電子をどれだけ失ったり得たりしたかを表す目安の数で、電子の授受を数える物差しとして使う。決め方の規則で各原子に酸化数を付け、化合物全体では和が0、イオンでは和が電荷に等しくなることから未知の酸化数が求められ、反応前後の増減から酸化されたか還元されたかと電子の数が分かる。

どんな問題に使うか

酸素の出入りが見えにくい反応でも、電子の授受で酸化・還元を判定したいときに使う物差しです。次のような場面で使います。

  • KMnO4 の Mn や H2SO4 の S のように、化合物の中の特定の原子の酸化数を求める問題
  • NH4+ や SO42− のように、多原子イオンの中の原子の酸化数を求める問題
  • 反応の前後で酸化数がどう変わったかを見て、どの原子が酸化され、どの原子が還元されたかを判定する問題
  • 酸化数の変化量から、原子1個あたり何個の電子が移動したかを数える問題（半反応式を作る準備）

中学では酸化・還元を「酸素を得る・失う」で見ましたが、酸素を含まない反応（金属と金属イオンの反応など）にはその見方が使えません。酸化数を付けておけば、どんな反応でも電子の授受で統一して判定できます。

公式・考え方

酸化数とは、化合物やイオンを作っている原子について、「その原子が電子をどれだけ失った（または得た）状態にあるか」を表すために割り当てる数です。実際にその電荷を持っているわけではなく、電子の授受を数えるための約束事の数です。決め方には優先順位のある規則があります。

酸化数を決める規則（優先順位の高い順）

  1. 単体の中の原子は 0。Cu、O2、S など、単体を構成する原子の酸化数はすべて 0 です。
  2. 単原子イオンは、イオンの電荷に等しい。Na+ の Na は ＋1、Cl− の Cl は −1、Cu2+ の Cu は ＋2 です。
  3. 化合物中のフッ素 F は −1。電気陰性度が最大の元素なので、化合物中では常に −1 になります。
  4. 化合物中の水素 H は ＋1。ただし、金属との化合物（金属水素化物、例：NaH の H）は −1 です。
  5. 化合物中の酸素 O は −2。ただし、過酸化物（例：H2O2 の O）は −1、フッ素との化合物（例：OF2 の O）は ＋2 です。
  6. 1族（アルカリ金属）は ＋1、2族（アルカリ土類金属）は ＋2など、典型元素の金属は化合物中で決まった値を取ることが多いです。
  7. 残った原子は、和の規則から求める。化合物全体では酸化数の総和は 0、多原子イオンでは酸化数の総和はイオンの電荷に等しい。これが未知の酸化数を解くための式になります。

未知の原子が n 個あり、その酸化数を x、他の原子の酸化数の合計（個数×酸化数の総和）を S、全体の電荷を q とすると、関係は次の式です。

n × x ＋ S ＝ q
x ＝（q − S）÷ n

各記号の意味は次の通りです。

  • x：求めたい原子の酸化数（単位のない数。正・負・0 を取る）
  • n：化学式の中の、その原子の個数
  • S：他のすべての原子についての「個数×酸化数」の合計
  • q：全体の電荷。化合物では 0、多原子イオンではそのイオンの電荷（例：NH4+ なら ＋1、SO42− なら −2）

酸化数の増減と酸化・還元

反応の前後で酸化数を比べると、電子の授受がそのまま読み取れます。

  • 酸化数が増えた原子は、酸化された（電子を失った）。増えた分が、原子1個あたり失った電子の数です。
  • 酸化数が減った原子は、還元された（電子を受け取った）。減った分が、原子1個あたり受け取った電子の数です。
  • 酸化数が変わらない原子は、酸化も還元もされていない。
電子の授受数（原子1個あたり）＝ |反応後の酸化数 − 反応前の酸化数|

解き方の手順

  1. 分かる原子から先に付ける。規則の優先順位に従い、単体・単原子イオン・F・H・O・1族・2族など、値が決まる原子の酸化数を先に書き込みます。過酸化物や金属水素化物の例外に注意します。
  2. 他の原子の合計 S を出す。「個数×酸化数」を原子ごとに計算して合計します。
  3. 和の規則で式を立てる。化合物なら合計が 0、多原子イオンなら合計がイオンの電荷になるよう、n × x ＋ S ＝ q と書きます。
  4. x について解く。x ＝（q − S）÷ n で未知の酸化数が求められます。
  5. 反応を判定するときは前後を比べる。増えていれば酸化（電子を失う）、減っていれば還元（電子を受け取る）。変化量の絶対値が原子1個あたりの電子の授受数です。

例題

問題1：過マンガン酸カリウム KMnO4 の Mn の酸化数を求めよ。問題2：硫酸 H2SO4 の S の酸化数を求めよ。問題3：アンモニウムイオン NH4+ の N の酸化数を求めよ。問題4：亜鉛 Zn が Zn2+ になるとき、酸化数はどう変化し、電子を何個失うか。

答えと解説を見る
  1. 問題1：K は1族なので ＋1、O は −2。Mn の酸化数を x とすると、化合物全体の和は 0 なので、（＋1）＋ x ＋（−2）×4 ＝ 0。x ＝ 0 −（＋1 −8）＝ ＋7。
  2. 問題2：H は ＋1、O は −2。S の酸化数を x とすると、（＋1）×2 ＋ x ＋（−2）×4 ＝ 0。x ＝ 0 −（＋2 −8）＝ ＋6。
  3. 問題3：H は ＋1。N の酸化数を x とすると、多原子イオンでは和が電荷 ＋1 に等しいので、x ＋（＋1）×4 ＝ ＋1。x ＝ ＋1 −4 ＝ −3。
  4. 問題4：単体 Zn の酸化数は 0、Zn2+ の Zn は単原子イオンなので ＋2。酸化数は 0 → ＋2 と 2 増えたので、Zn は酸化され、原子1個あたり電子を 2 個失います。

答え：問題1は ＋7、問題2は ＋6、問題3は −3、問題4は 0 から ＋2 へ増えて酸化され、電子を 2 個失う。問題1〜3は下の計算機のモード1で、問題4はモード2で同じ入力で確かめられます。よくある間違いは、イオンの問題3で「和＝0」としてしまうことと、O の個数を掛け忘れることです。

現場での使われ方

酸化還元滴定の計算

過マンガン酸カリウム KMnO4 を使う滴定では、Mn の酸化数が ＋7 から ＋2 へ変化し、原子1個あたり電子を5個受け取ることが、反応する物質の量の関係（何 mol と何 mol が反応するか）を決めます。水質検査の COD（化学的酸素要求量）の測定など、分析の現場で使われる計算の土台です。

電池・電気分解の電極反応の整理

電池や電気分解では、どちらの電極で酸化が起こり、どちらの電極で還元が起こるかを酸化数の変化で判定します。電極反応を電子つきの半反応式で書く作業は、酸化数の増減を数えることから始まります。

金属の腐食と製錬の反応の読み取り

鉄がさびる腐食も、高炉で鉄鉱石から鉄を取り出す製錬も、酸化数の変化で追うことができます。どの原子が電子を失い、どの原子が受け取るかをそろえて見ることで、複雑な反応式の係数も酸化数の変化量のつり合いから決められます。

考え出した人

特定の考案者はいない（酸化数は、酸化・還元を電子の授受で捉え直す考え方が広がる中で、化学者たちの共通の約束事として20世紀にかけて整理されてきた概念）

酸化数には、特定の誰かが一つの法則として発見したという形の考案者はいません。もともと酸化・還元は「酸素を得る・失う」という見方で説明されていましたが、電子の存在が明らかになり、酸化・還元を「電子を失う・受け取る」現象として捉え直す考え方が広がると、酸素を含まない反応まで統一して扱うための物差しが必要になりました。そこで、化合物中の原子に一定の規則で数を割り当てる酸化数の約束事が、化学者たちの共通の決め方として整理されてきました。現在では国際純正・応用化学連合（IUPAC）も酸化状態（酸化数）の定義と決め方を定めており、世界共通の言葉として使われています。
