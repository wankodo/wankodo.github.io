中学2年 酸化還元・電池と電気分解

どんな時に使えるか 燃焼やさびのように、物質が酸素と化合する反応がどれか、逆に酸化物から酸素を取り去る反応がどれかを見分けたいときに使う。酸素と化合することを酸化、酸化物が酸素を奪われることを還元といい、この2つは1つの反応の中で同時に起こる。

どんな問題に使うか

反応の前後で酸素がどの物質からどの物質へ移ったかを追って、酸化と還元を見分けるときの考え方です。次のような場面で使います。

  • 燃焼や金属のさびが、なぜ酸化といえるのかを説明する問題
  • 酸化銅と炭素の反応で、酸化された物質と還元された物質を答える問題
  • 化学反応式を見て、酸素を受け取った物質と、酸素を失った物質を指摘する問題

中学理科では、酸化と還元をまず酸素の受け渡しで考えます。高校では電子の受け渡しでも考えるようになりますが、土台はこの「酸素がどこへ行ったか」です。

公式・考え方

酸化とは、物質が酸素と化合することです。たとえば銅を空気中で加熱すると、表面が黒い酸化銅に変わります。

2Cu ＋ O2 → 2CuO

物質が酸素と激しく化合して熱や光を出す酸化を、特に燃焼といいます。マグネシウムを空気中で燃やすと、まぶしい光を出して白い酸化マグネシウムになります。

2Mg ＋ O2 → 2MgO

鉄が空気中の酸素や水とゆっくり化合して赤茶色のさびができるのも酸化です。燃焼のように熱や光は目立ちませんが、酸素と化合している点は同じです。

逆に、還元とは、酸化物が酸素を奪われることです。黒い酸化銅の粉末に炭素の粉末を混ぜて加熱すると、赤茶色の銅が取り出せます。

2CuO ＋ C → 2Cu ＋ CO2

この反応では、酸化銅 CuO が酸素を奪われて銅 Cu に戻っているので、酸化銅は還元されたといいます。一方、炭素 C はその酸素を受け取って二酸化炭素 CO2 になっているので、炭素は酸化されたといいます。つまり、酸化と還元は別々に起こるのではなく、1つの反応の中で同時に起こります。一方の物質が酸素を受け取れば（酸化）、必ずもう一方の物質が酸素を失っています（還元）。

各言葉の意味は次の通りです。

  • 酸化：物質が酸素と化合すること。その物質は「酸化された」という
  • 還元：酸化物が酸素を奪われること。その酸化物は「還元された」という
  • 酸化物：物質が酸素と化合してできた化合物。酸化銅 CuO や酸化マグネシウム MgO など
  • 燃焼：熱や光を出しながら激しく進む酸化

解き方の手順

  1. 化学反応式を書く（または読み取る）。反応の前後で、どの物質に酸素がくっつき、どの物質から酸素が離れたかを確認します。
  2. 酸素を受け取った物質を探す。反応後に酸素と化合している物質が、酸化された物質です。
  3. 酸素を失った物質を探す。酸化物だったのに反応後に酸素を失っている物質が、還元された物質です。
  4. ペアで答える。酸化と還元は同時に起こるので、「○○が酸化され、△△が還元された」と両方をセットで答えます。片方しかない答えは、見落としがないか見直します。

酸化銅と炭素の実験では、加熱後に試験管の中に赤茶色の銅が残り、発生した気体を石灰水に通すと白くにごって二酸化炭素ができたことが分かります。

※ ここで紹介する実験・製法を実際に行うときは、学校の授業や専門家の指導のもとで、安全に十分注意し、自己責任で行ってください。

例題

問題1：マグネシウムを空気中で燃やすと、酸化マグネシウムができる（2Mg ＋ O2 → 2MgO）。酸化された物質は何か。問題2：酸化銅と炭素の混合物を加熱すると、銅と二酸化炭素ができる（2CuO ＋ C → 2Cu ＋ CO2）。酸化された物質と還元された物質はそれぞれ何か。問題3：銅の粉末を空気中で加熱すると、黒い酸化銅ができる（2Cu ＋ O2 → 2CuO）。この反応で酸化された物質は何か。また、この反応で還元された物質はあるか。

答えと解説を見る
  1. 問題1：マグネシウム Mg が酸素 O2 と化合して酸化マグネシウム MgO になっているので、酸化された物質はマグネシウムです。燃焼は激しい酸化でしたね。
  2. 問題2：酸化銅 CuO は酸素を奪われて銅 Cu に戻っているので、還元された物質は酸化銅です。炭素 C はその酸素を受け取って二酸化炭素 CO2 になっているので、酸化された物質は炭素です。
  3. 問題3：銅 Cu が酸素と化合して酸化銅 CuO になっているので、酸化された物質は銅です。この反応の相手は酸素そのもので、酸化物が酸素を奪われる反応は起きていないので、還元された物質はありません。

答え：問題1はマグネシウムが酸化された。問題2は炭素が酸化され、酸化銅が還元された。問題3は銅が酸化され、還元された物質はない。酸素の行き先を追えば、酸化と還元は迷わず見分けられます。

現場での使われ方

製鉄（高炉で鉄を取り出す）

鉄の原料である鉄鉱石は、鉄が酸素と化合した酸化鉄です。製鉄所の高炉では、コークス（炭素を主成分とする燃料）を燃やしてできる一酸化炭素が酸化鉄から酸素を奪い、金属の鉄を取り出します。酸化銅から炭素で銅を取り出す実験と同じ、還元の考え方を大きな規模で使った技術です。

さびを防ぐ工夫

鉄のさびは酸化なので、防ぐには酸素や水に触れさせなければよい、ということになります。鉄製品にペンキを塗る、油を塗る、さびにくい金属でめっきする（トタンやブリキ）といった方法はすべて、鉄が酸素と化合するのをさえぎる工夫です。

燃焼で熱を取り出す

ガスこんろやストーブ、自動車のエンジンなどは、燃料が酸素と化合する燃焼（酸化）で出る熱や力を利用しています。燃料が酸化されるときに大きなエネルギーが出ることが、暮らしの熱源の土台になっています。

考え出した人

アントワーヌ・ラボアジエ（1743〜1794、フランスの化学者）

「燃える」という現象の正体を、酸素との化合として明らかにしたのが、フランスの化学者アントワーヌ・ラボアジエ（1743〜1794）です。それまでは、物質が燃えると「燃素」という目に見えないものが逃げ出す、という考え方が広く信じられていました。ラボアジエは密閉した容器の中で物質を燃やし、質量をていねいに測る実験を重ねて、燃焼は物質が空気中の酸素と化合する反応であり、反応の前後で全体の質量は変わらないことを示しました。今、中学理科で「酸化＝酸素と化合すること」と学ぶのは、このラボアジエの理解が土台になっています。酸化の反対の還元も、酸化物から酸素が奪われる反応として、この枠組みの中で整理されました。
