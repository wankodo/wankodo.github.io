銅・銀と金属の精錬

化学の考え方辞典 ― 無機化学（高校化学・3年）

化学ツール集トップ ＞ 無機化学 ＞ 銅・銀と金属の精錬

高校化学・3年 無機化学

どんな時に使えるか 銅は黄銅鉱などの鉱石から粗銅を作り、電解精錬で純度を高める。電解精錬では粗銅を陽極、純銅を陰極として硫酸銅（II）水溶液を電気分解し、陽極では銅が溶け出し、陰極では純粋な銅が析出する。イオン化傾向の小さい銀や金は溶けずに陽極泥として沈み、貴金属として回収される。銀は電気・熱の伝導性が金属で最大で、臭化銀などのハロゲン化銀は光で分解する感光性をもち、写真フィルムに使われる。

どんな問題に使うか

銅と銀という代表的な金属について、鉱石から純粋な金属を取り出す精錬の仕組みと、化合物や単体の性質の使われ方を説明するときの項目です。次のような場面で使います。

  • 銅の電解精錬で、粗銅と純銅をどちらの電極につなぐか、各電極で起こる反応を電極反応式で書く問題
  • 粗銅に含まれる不純物（亜鉛・鉄・銀・金など）が、電解精錬でどこへ行くかをイオン化傾向から説明する問題
  • 硫酸銅（II）や酸化銅など、銅の化合物の色や反応を答える問題
  • 臭化銀の感光性をもとに、写真の現像・定着がなぜ必要かを説明する問題

土台になるのは、電気分解で陰極に還元・陽極に酸化が起こることと、金属ごとに異なるイオン化傾向です。生成物の判定の基本は電気分解の生成物と優先順位、順序そのものは金属のイオン化傾向で扱っています。この項目では、その知識を「金属を純粋に取り出す技術」と「銀の感光性を使う写真」に当てはめます。

公式・考え方

銅の製錬：黄銅鉱から粗銅へ

銅の主原料は、黄銅鉱 CuFeS2 を多く含む銅鉱石です。鉱石から銅分を濃縮した精鉱を、高温の炉で酸素を含む気体と反応させる自溶炉法などで溶かし、鉄分をスラグ（かす）として分離して、硫化銅（I）Cu2S を主成分とする中間物（マット）を得ます。これを転炉でさらに酸化すると、純度 98〜99％ 程度の粗銅が得られます。転炉での反応の骨格は、教科書では次のように表されます。

2Cu2S ＋ 3O2 → 2Cu2O ＋ 2SO2
Cu2S ＋ 2Cu2O → 6Cu ＋ SO2

粗銅には、鉄・亜鉛・鉛・ニッケルなどのほか、銀や金などの貴金属もわずかに含まれています。このままでは電線などに求められる純度に届かないため、次の電解精錬で純度を高めます。ここでは工業的な製錬の流れの概要にとどめます。

銅の電解精錬

電解精錬では、陽極（電源の正極側）に粗銅の厚板、陰極（電源の負極側）に純銅の薄板を入れ、電解液として硫酸銅（II）CuSO4 水溶液（硫酸で酸性にしたもの）を使います。各電極の反応は次の通りです。

陽極： Cu → Cu2+ ＋ 2e−（粗銅が溶け出す）
陰極： Cu2+ ＋ 2e− → Cu（純粋な銅が析出）

不純物の行き先は、イオン化傾向で決まります。

  • 銅よりイオン化傾向の大きい金属（亜鉛 Zn、鉄 Fe、ニッケル Ni など）：陽極で銅と一緒にイオンになって溶け出しますが、陰極では Cu2+ の方が優先して還元されるため、金属として析出せず、溶液中にとどまります
  • 銅よりイオン化傾向の小さい金属（銀 Ag、金 Au、白金 Pt など）：陽極でも溶けず、粗銅が溶けるにつれて電極の下に沈殿します。この沈殿を陽極泥といい、貴金属を回収する原料になります

陽極で溶け出す銅の量と陰極で析出する銅の量はほぼ等しいので、電解液中の Cu2+ の濃度はほぼ一定に保たれます。こうして純度 99.99％ 程度の純銅（電気銅）が得られます。各記号の意味は次の通りです。

  • e−：電子。酸化（陽極）の式では右辺に、還元（陰極）の式では左辺に書く
  • 陽極泥：電解精錬で陽極の下にたまる沈殿。銀・金・白金などの貴金属を含む
  • イオン化傾向：金属が水溶液中で電子を放出して陽イオンになろうとする性質の大きさ。Zn・Fe は銅より大きく、Ag・Au は銅より小さい

銅の化合物

  • 硫酸銅（II）CuSO4：五水和物 CuSO4・5H2O は青色の結晶です。加熱すると水和水を失って白色の無水物になり、水を加えると再び青色に戻るため、水の検出に使われます。水溶液に水酸化ナトリウム水溶液を加えると、青白色の水酸化銅（II）Cu(OH)2 が沈殿します：Cu2+ ＋ 2OH− → Cu(OH)2
  • 酸化銅：酸化銅（II）CuO は黒色、酸化銅（I）Cu2O は赤色の固体です。水酸化銅（II）を加熱すると、黒色の酸化銅（II）と水に分解します：Cu(OH)2 → CuO ＋ H2O
  • 炎色反応：銅の化合物を炎の中に入れると、炎が青緑色になります。銅イオンの検出や、花火の色付けの考え方につながる反応です

銀の性質と写真の化学

銀 Ag は、金属の中で電気伝導性・熱伝導性が最大で、展性・延性にも優れます。一方で、硫黄を含む気体や温泉水などに触れると、黒色の硫化銀 Ag2S ができて黒ずみます。硝酸銀 AgNO3 は光に当たると分解しやすいため、褐色瓶に保存されます。

写真に使われるのは、臭化銀 AgBr などのハロゲン化銀の感光性です。ハロゲン化銀は光が当たると分解し、金属銀を生じます。

2AgBr → 2Ag ＋ Br2（光による分解）

フィルムや印画紙では、臭化銀の微結晶をゼラチンに混ぜた乳剤が支持体に塗られています。撮影で光が当たった部分では、目に見えないほどわずかに銀が生じます（潜像）。ここから写真ができるまでの考え方は、次の2段階です。

  • 現像：現像液（還元剤を含む液）で処理すると、光が当たって潜像のできた臭化銀の結晶が優先して還元され、黒色の金属銀になります。当たらなかった結晶はほとんど還元されないため、光の強弱が黒さの濃淡として増幅されます。光が当たった部分ほど黒くなるので、フィルム上では明暗が逆転した像（ネガ）ができます
  • 定着：現像後も、光の当たらなかった臭化銀が残ったままでは、光に当てるたびに分解して像が消えてしまいます。そこでチオ硫酸ナトリウム Na2S2O3 水溶液（ハイポ）で処理し、未反応の臭化銀を水に溶ける錯イオンにして溶かし去ります：AgBr ＋ 2S2O32− → [Ag(S2O3)2]3− ＋ Br−。これで像が光に対して安定します

解き方の手順

  1. 電極のつなぎ方を確認する。電解精錬では、純度を上げたい粗銅を陽極（電源の正極側）、純銅を取り出す側を陰極（電源の負極側）につなぎます。「溶かしたい側が陽極、付けたい側が陰極」が原則です。
  2. 両極の電極反応式を書く。陽極では銅が電子を放出して溶け出し（Cu → Cu2+ ＋ 2e−）、陰極では Cu2+ が電子を受け取って析出します（Cu2+ ＋ 2e− → Cu）。原子の数と電荷が両辺でそろうか確認します。
  3. 不純物をイオン化傾向で仕分ける。銅よりイオン化傾向の大きい金属は「溶けるが析出しない（溶液中にとどまる）」、小さい金属は「溶けずに陽極泥になる」と判定します。
  4. 写真の問題は「感光→現像→定着」の順で考える。光でハロゲン化銀が分解して潜像ができ、現像で当たった結晶だけが銀になって増幅され、定着で残りのハロゲン化銀を取り除いて像を固定する、という流れで説明します。

例題

問題1：銅の電解精錬では、粗銅と純銅の薄板をそれぞれどちらの電極につなぐか。また、各電極で起こる反応を電極反応式で書け。問題2：粗銅に含まれる亜鉛 Zn と銀 Ag は、電解精錬のあと、それぞれどこへ行くか。イオン化傾向を使って説明せよ。問題3：電解精錬を続けても、電解液中の Cu2+ の濃度がほぼ変わらないのはなぜか。問題4：写真フィルムで、撮影しただけでは像が見えず、現像と定着の両方が必要なのはなぜか。臭化銀の反応式も使って説明せよ。問題5：硫酸銅（II）水溶液に水酸化ナトリウム水溶液を加えると何が起こるか。また、生じた沈殿を加熱するとどうなるか。反応式も書け。

答えと解説を見る
  1. 問題1：粗銅は陽極（電源の正極側）、純銅の薄板は陰極（電源の負極側）につなぎます。陽極では銅が酸化されて溶け出します：Cu → Cu2+ ＋ 2e−。陰極では Cu2+ が還元されて純粋な銅が析出します：Cu2+ ＋ 2e− → Cu。どちらの式も、原子の数（Cu が両辺1個）と電荷（陽極は左辺0・右辺＋2−2＝0、陰極は左辺＋2−2＝0・右辺0）がそろっています。
  2. 問題2：亜鉛は銅よりイオン化傾向が大きいので、陽極で Zn2+ となって銅と一緒に溶け出します。しかし陰極では Cu2+ の方が優先して還元されるため、亜鉛は金属として析出せず、溶液中にとどまります。銀は銅よりイオン化傾向が小さいので陽極でも溶けず、粗銅が溶けるにつれて陽極の下に陽極泥として沈殿し、貴金属として回収されます。
  3. 問題3：陽極で粗銅から溶け出す銅の量と、陰極で Cu2+ が還元されて析出する銅の量が、同じ電気量に対して等しいからです。両極の反応はどちらも電子2個の出入りで銅1個が動くため、溶液中の Cu2+ は出入りが釣り合って、濃度はほぼ一定に保たれます。
  4. 問題4：撮影時の光では、臭化銀は 2AgBr → 2Ag ＋ Br2 と分解しますが、生じる銀は目に見えないほどわずか（潜像）です。現像では、潜像のできた結晶が優先して還元されて黒色の金属銀になり、像が目に見える濃淡に増幅されます。定着では、光の当たらなかった未反応の臭化銀をチオ硫酸ナトリウム水溶液で錯イオンにして溶かし去ります。定着をしないと、残った臭化銀が光で分解し続けて像が黒く消えてしまうため、両方の処理が必要です。
  5. 問題5：青白色の水酸化銅（II）Cu(OH)2 が沈殿します：Cu2+ ＋ 2OH− → Cu(OH)2。この沈殿を加熱すると分解して、黒色の酸化銅（II）CuO と水になります：Cu(OH)2 → CuO ＋ H2O。

答え：問題1は粗銅が陽極・純銅が陰極で、陽極 Cu → Cu2+ ＋ 2e−、陰極 Cu2+ ＋ 2e− → Cu。問題2は亜鉛が溶液中にとどまり、銀が陽極泥になる。問題3は両極で出入りする銅の量が等しいから。問題4は現像で潜像を銀の像に増幅し、定着で未反応の臭化銀を取り除くため。問題5は青白色の Cu(OH)2 が沈殿し、加熱で黒色の CuO になる。電解精錬の問題は「電極の判定→電極反応式→不純物の仕分け」の順で、写真の問題は「感光→現像→定着」の順で考えると整理できます。

現場での使われ方

電気銅と電線・電子機器

電解精錬で作られる純度 99.99％ 程度の電気銅は、電気伝導性が高いため、電線・ケーブル、モーターや変圧器の巻線、電子機器の配線やプリント基板の銅箔などに広く使われます。不純物が多いと電気抵抗が増えて伝導性が落ちるため、銅の用途の多くはこの精錬の純度に支えられています。また、電解精錬の副産物である陽極泥は、銀・金・白金族などの貴金属の重要な回収源になっています。

硫酸銅（II）の利用

硫酸銅（II）は、ぶどうなどの病害防除に使われるボルドー液（硫酸銅（II）と消石灰から作る農薬）の原料として知られます。また、五水和物の青色結晶が加熱で白色になり水で青色に戻る性質は、水の存在を確かめる検出に使われます。銅の化合物の青色は、炎色反応の青緑色とあわせて、銅イオンを見分ける手がかりになります。

銀の用途と写真フィルム

銀は電気・熱の伝導性が金属で最大であることから、電気接点やはんだ、電子部品などに使われ、装飾品や食器にも用いられます。臭化銀の感光性は、写真フィルムや印画紙、医療用の X 線フィルムの乳剤に使われてきました。デジタルカメラが主流になった現在でも、映画用フィルムや芸術写真では銀塩写真が使われ続けており、現像・定着という化学処理の流れは写真技術の基礎になっています。

考え出した人

ルイ・ダゲール（1787〜1851、フランスの画家・発明家）

銀の感光性を実用的な写真技術にした先駆者が、フランスの画家・発明家ルイ・ダゲール（1787〜1851）です。1839年に公表された彼のダゲレオタイプは、銀でめっきした銅板の表面にヨウ化銀の感光層を作り、露光後に水銀蒸気で現像し、チオ硫酸ナトリウム水溶液で定着する方式でした。支持体が銅板、感光材がハロゲン化銀、仕上げが定着、という構成は、この項目で扱う銅と銀の化学がそのまま写真の原点になったことを示しています。その後、感光材は臭化銀をゼラチン乳剤に分散させたフィルムへと発展し、銀塩写真の基本の流れ（感光・現像・定着）が確立しました。
