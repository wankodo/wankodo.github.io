中学・高校 関数 計算機あり

どんな時に使えるか 車のブレーキをかけてから止まるまでの距離は、速度の2乗に比例して伸びる。車の安全設計や、投げた物の軌道の計算に使う。頂点を求めると、一番高くなる点や最大・最小が分かる。

どんな問題に使うか

二次関数は、y が x の2乗に比例する部分を含む関数です。グラフは放物線と呼ばれる山型（または谷型）の曲線になります。次のような場面で使います。

  • y ＝ ax2 ＋ bx ＋ c のグラフの頂点や軸を求める問題
  • 最大値・最小値を求める問題（頂点が手がかりになる）
  • 投げた物の高さや軌道、面積の最大値など、増えてから減る（減ってから増える）変化の問題
  • 放物線と直線の交点など、二次方程式とつながる問題

公式・考え方

y ＝ ax2 ＋ bx ＋ c　（a ≠ 0）

a の符号で開き方が変わります。a ＞ 0 なら放物線は上に開き（谷型で、頂点が最小）、a ＜ 0 なら下に開き（山型で、頂点が最大）ます。|a| が大きいほど、放物線は細くなります。

平方完成で頂点と軸を求める方法

式を y ＝ a(x − p)2 ＋ q の形に変形するのが平方完成です。この形になれば、頂点は (p, q)、軸は直線 x ＝ p と読み取れます。頂点の x 座標は −b ÷ (2a) でも求められます。

y ＝ a(x − p)2 ＋ q → 頂点 (p, q)、軸 x ＝ p

解き方の手順

  1. x2 と x の項を、x2 の係数 a でくくる。定数項 c は外に残します。
  2. かっこの中を平方完成する。x の係数の半分を取り、その2乗を足して引き、(x − p)2 の形を作ります。
  3. 定数項を整理する。外に出た数を計算して q を出します。
  4. 頂点と軸を読み取る。y ＝ a(x − p)2 ＋ q から、頂点 (p, q) と軸 x ＝ p を答えます。a の符号で上に開くか下に開くかも確認します。

例題

問題：ボールを投げてからの高さが、y ＝ −x2 ＋ 4x で表せる（x は投げてからの秒数、y は高さ m）。ボールが一番高くなるのは何秒後で、その高さは何mか。

答えと解説を見る

最高点は放物線の頂点です。平方完成して頂点を求めます。

  1. x の項を −1 でくくる：y ＝ −(x2 − 4x)
  2. 平方完成する：x の係数 −4 の半分は −2、その2乗は4なので、y ＝ −{(x − 2)2 − 4} ＝ −(x − 2)2 ＋ 4
  3. 頂点を読み取る：頂点は (2, 4)

答え：2秒後に4m。a ＝ −1 ＜ 0 で下に開く放物線なので、頂点が最高点になります。

現場での使われ方

車の制動距離と安全設計

車がブレーキをかけてから止まるまでの制動距離は、速度の2乗に比例して伸びることが知られています。速度が2倍になると制動距離は約4倍になるため、制限速度や車間距離の設計では、この2乗の関係が安全の土台になっています。

物の軌道

投げたボールや発射された物の軌道は、重力の影響で放物線を描きます。初速度と角度から軌道を計算するのも二次関数の応用で、最高点や届く距離は頂点と交点の計算から分かります。

パラボラアンテナや噴水の形

パラボラアンテナの反射面は放物面で、軸に平行に入ってきた電波を焦点の1点に集めます。噴水の水の弧も放物線で、形を決める計算に二次関数が使われます。

この解法を計算機で試す → 二次関数 計算機：a・b・c を入れると、平方完成の手順つきで頂点と軸を計算し、放物線のグラフを表示します。
